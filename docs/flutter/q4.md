# Q4：StatefulWidget 与 StatelessWidget 的区别

| 特性 | StatelessWidget | StatefulWidget |
|------|----------------|----------------|
| 状态 | 不可改变，创建后不变 | 可变，通过 State 对象管理 |
| 何时重建 | 父 Widget 变化或传入的参数变化时重建 | 调用 `setState()` 时触发重建 |
| 生命周期 | 只有 `build` 方法 | 拥有完整的 State 生命周期 |
| 适用场景 | 静态内容（文本、图标） | 交互、动画、表单等 |

`StatefulWidget` 本身仍不可变，但其关联的 `State` 对象包含可变数据。当 `State.setState()` 调用，Flutter 会重建该 Widget。
