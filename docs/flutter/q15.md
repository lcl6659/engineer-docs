# Q15：Flutter 中如何与原生平台（iOS/Android）通信？

通过 **Platform Channel** 三种方式：

- **`MethodChannel`**：调用方法并返回结果，最常用。
- **`EventChannel`**：持续事件流（如传感器）。
- **`BasicMessageChannel`**：连续双向消息编码。

**步骤**：
1. Dart 端：创建 `MethodChannel('通道名')`，调用 `invokeMethod`。
2. 原生端：在 MainActivity/AppDelegate 里注册同名通道，实现 `MethodCallHandler` 处理调用。
3. 双方序列化通过标准编解码器（StandardMessageCodec）传输。
