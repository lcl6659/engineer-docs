# Q17：Flutter 性能优化有哪些方法？

- **构建优化**：
  - 使用 `const` 构造减少重建。
  - 合理拆分组件，减少 `build` 范围。
  - 用 `RepaintBoundary` 隔离重绘区域。
- **渲染优化**：
  - 避免不必要的 `Opacity`，用对应控件替代。
  - `ListView.builder` 处理长列表。
  - 利用 `Keys` 精确复用。
- **内存**：及时释放 `Controller` 和 `Stream`，使用 `dispose`。
- **调试工具**：DevTools 分析 build 次数、重绘区域、内存。
- **异步**：compute 或 Isolate 处理大数据，防卡顿。
