# Q26：Flutter 如何实现混合开发？Add-to-App 是怎样的？

混合开发允许在已有的原生应用（iOS/Android）中**嵌入 Flutter 页面**，或反之。

**Add-to-App 方案**：
- 将 Flutter 模块作为原生项目的依赖引入（CocoaPods/Gradle）。
- 启动 FlutterEngine，然后在原生页面中通过 `FlutterViewController`（iOS）或 `FlutterFragment`/`FlutterActivity`（Android）显示 Flutter 界面。
- 多个 Flutter 页面可共享同一个 FlutterEngine 以减少资源占用，也可为每个页面创建独立引擎。

**导航与通信**：
- 原生 → Flutter：通过 Platform Channel 传递参数跳转到指定路由。
- Flutter → 原生：同样通过 Channel 通知原生执行跳转，或者 Flutter 内部使用 Navigator 管理自己的路由栈。

**注意事项**：
- 内存管理：合理管理引擎生命周期，避免内存泄漏。
- 状态同步：确保原生和 Flutter 间的数据一致。
- 性能：首次启动引擎有冷启动时间，可预初始化引擎优化体验。
