# Q31：Flutter 中如何处理安全性问题？

- **网络安全**：使用 HTTPS，证书校验（Dio 中配置），避免中间人攻击。
- **本地存储**：敏感数据使用 `flutter_secure_storage`（Keychain/Keystore），不要明文存放于 SharedPreferences。
- **代码混淆**：生产环境启用 Dart 代码混淆（`--obfuscate`），增加逆向难度。
- **Web 安全**：避免 XSS（Flutter Web 渲染方式不同，但仍需注意 URL 注入等），合理使用 CSP。
- **依赖安全**：定期审计 pub.dev 包漏洞，保持更新。
- **认证**：存储 token 安全，使用 OAuth2/OIDC，定时刷新。
