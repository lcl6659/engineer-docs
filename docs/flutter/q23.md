# Q23：什么是 Element 树？它与 Widget 树和 RenderObject 树的关系？

Flutter 运行时维护三棵树：

- **Widget 树**：开发者编写的轻量配置，不可变，每次重建都会创建新的 Widget 树。
- **Element 树**：Widget 的实例化对象，是框架层的核心，负责管理 Widget 的生命周期和 RenderObject 的关联。Element 持有 `widget` 引用和 `renderObject` 引用。
- **RenderObject 树**：负责布局和绘制的对象。

**关系**：
1. 框架根据 Widget 树创建/更新 Element 树（通过 `Widget.createElement()`）。
2. Element 根据 Widget 是否变化决定创建、更新或移除 RenderObject。
3. 当 Widget 重建，框架比较新旧 Widget 及其 Key，决定是否复用 Element 及其 RenderObject，从而只进行必要的更改。

理解这三棵树对性能分析至关重要，可以解释为何 `const` Widget 和 `Key` 能优化性能。
