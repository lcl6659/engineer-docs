# Q21：Flutter 的渲染流水线（Rendering Pipeline）是怎样的？

Flutter 的渲染流水线是将 Widget 树转化为屏幕像素的过程，每帧主要经历以下阶段：

1.  **构建（Build）**  
    从根 Widget 开始，递归调用 `build()` 方法，生成新的 Widget 树。此阶段仅构造轻量的配置描述。

2.  **布局（Layout）**  
    根据 Widget 树生成对应的 **RenderObject 树**，然后自上而下传递约束（Constraints），自下而上返回尺寸（Size），最终确定每个渲染对象的位置和大小。

3.  **绘制（Paint）**  
    根据布局信息，将 RenderObject 树绘制到 **Layer 树**上。每个 RenderObject 调用 `paint()` 方法在 Canvas 上绘制。

4.  **合成（Composite）**  
    将各个 Layer 按顺序合成为最终图像。Flutter 支持多层合成，可把不同部分交给 GPU 单独处理，例如滚动时只需移动 Layer 而无需重绘。

5.  **光栅化（Rasterize）**  
    引擎层将合成的 Layer 树光栅化为 GPU 纹理，最终提交到屏幕。

**优化点**：利用 `RepaintBoundary` 可将子树隔离到独立 Layer，避免外层变化导致不必要的重绘；`const` 构造函数可让 Widget 不被重建。
