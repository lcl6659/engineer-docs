# Q9：Flutter 布局模型是怎么样？常用的布局 Widget 有哪些？

Flutter 布局基于 **盒约束模型**，从父向子传递约束（Constraints），子根据约束返回自己的大小，父决定位置。

- **约束传递**：父告诉子最小和最大宽高限制，子在此范围内决定尺寸。
- 布局步骤：向下传递约束 → 子布局 → 向上传递大小 → 父决定位置。

**常用布局 Widget**：
- `Row` / `Column`：线性布局（主轴/交叉轴对齐，`Expanded` 填满剩余空间）。
- `Stack`：层叠布局，通过 `Positioned` 定位。
- `Flexible` / `Expanded`：分配可伸缩空间。
- `Wrap`：自动换行流式布局。
- `Align` / `Center`：单子对齐。
- `Padding`、`SizedBox`、`AspectRatio` 等约束调整。
