# Q20：如何自定义绘制（CustomPainter）？

继承 `CustomPainter` 并实现 `paint` 和 `shouldRepaint`。

```dart
class MyPainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    canvas.drawRect(/*...*/);
  }
  @override
  bool shouldRepaint(covariant CustomPainter oldDelegate) => false;
}
```
通过 `CustomPaint` Widget 使用，传入 painter 和 size。结合 `RepaintBoundary` 控制重绘。
