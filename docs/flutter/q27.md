# Q27：Platform Channel 的编解码过程及自定义类型

默认使用 **StandardMessageCodec**，支持以下类型：null、int、double、String、Uint8List、List、Map。

当需传递自定义对象时：
- 实现 `StandardMessageCodec` 或 `MessageCodec` 子类，并注册序列化逻辑。
- 或使用 `Pigeon` 工具生成类型安全的通道代码，自动序列化。

**编解码流程**：
1. Dart 端调用 `invokeMethod` 时，将方法名和参数按标准编解码器编码为二进制消息。
2. 原生端收到二进制后按相同规则解码，执行对应方法。
3. 返回值同样编码传回。
4. Dart 端解码得到结果，返回 Future 完成。
