# Q32：Flutter Web 的渲染模式有哪些？各有什么优劣？

- **HTML 渲染模式**：将 Flutter 控件转为 HTML + CSS + Canvas。优点：兼容性好、包体小。缺点：性能不如 CanvasKit，部分效果受限。
- **CanvasKit 渲染模式**：使用 WebAssembly 版本的 Skia 引擎，直接在 Canvas 上绘制。优点：与移动端像素级一致，性能好。缺点：首次加载体积大（约 2MB）。
- **自动（auto）模式**：桌面端浏览器默认用 CanvasKit，移动端浏览器默认用 HTML。

可以根据场景选择，首屏加载时间敏感可选 HTML，要求极致一致选 CanvasKit。
