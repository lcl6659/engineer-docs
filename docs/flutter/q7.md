# Q7：什么是 InheritedWidget？它的作用和使用场景

`InheritedWidget` 是一种特殊的 Widget，能够**高效地在子树中传播数据**，避免逐级传递 props。

- 工作原理：当 `InheritedWidget` 重建时，会遍历依赖它的子 Widget，并调用其 `didChangeDependencies`。
- 子组件通过 `context.dependOnInheritedWidgetOfExactType<T>()` 建立依赖。
- 典型应用：
  - `Theme.of(context)`
  - `MediaQuery.of(context)`
  - 状态管理库的底层（如 Provider 就是基于 InheritedWidget）。
