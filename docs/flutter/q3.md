# Q3：什么是 Widget？Flutter 中的一切皆为 Widget 的含义是什么？

Widget 是 Flutter 中 UI 的基本构建模块，描述了在给定当前配置和状态下的视图信息（类似 React 的虚拟 DOM）。

- **不可变性**：Widget 本身是不可变的，只是一个轻量的描述（配置+子 Widget 引用）。当需要更新 UI 时，会创建新的 Widget 树。
- **组合而非继承**：通过嵌套 Widget 来构建 UI。
- Widget 有三类：
  - **组合 Widget**（如 `Container`、`Column`）组合其他 Widget 无自身绘制。
  - **渲染 Widget**（如 `Opacity`、`ClipRRect`）影响渲染树。
  - **叶子 Widget**（如 `Text`、`Image`）直接与 RenderObject 关联。
