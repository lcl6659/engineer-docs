# Q33：如何测试 Flutter 应用？测试类型有哪些？

- **单元测试**：测试单个函数、方法或类，依赖少。使用 `test` 包。
- **Widget 测试**：在测试环境中渲染 Widget，验证 UI 外观和交互。使用 `flutter_test`，可 pump Widget，查找特定组件，模拟手势。
- **集成测试**：在真实设备或模拟器上运行，测试完整用户流程。使用 `integration_test` 包。
- **黄金测试（Golden Tests）**：像素级比对 UI 截图，防止意外的视觉变化。

**最佳实践**：遵循测试金字塔，多写单元和 Widget 测试。状态管理逻辑单独提取便于单元测试。
