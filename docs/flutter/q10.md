# Q10：Flutter 中如何处理手势和事件？

通过 **GestureDetector** 和 **RawPointer** 等处理触摸。

- **`GestureDetector`**：包装 Widget，提供一系列手势回调（`onTap`, `onDoubleTap`, `onLongPress`, `onPan...` 等）。内部使用竞技场机制区分手势。
- **手势识别流程**：按下 → 移动 → 抬起，由 `GestureRecognizer` 解析。
- **事件传递**：命中测试（Hit Test）从根向下，找到最深的可响应 Widget。
- 如果多个手势冲突，竞争 arena 决定谁胜出。
- 也支持`Listener` 监听原始指针事件，以及 `AbsorbPointer` / `IgnorePointer` 控制子组件是否接收事件。
