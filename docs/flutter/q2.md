# Q2：Flutter 的架构分层是怎样的？

Flutter 架构分三层：

1.  **框架层（Framework）**：纯 Dart 实现，位于最上层，提供：
    - 基础类和构建基石（`Foundation`）
    - 渲染树（`Rendering`）
    - Widget 层（`Widgets`）
    - Material 和 Cupertino 风格库
    开发者主要与此层交互。

2.  **引擎层（Engine）**：C/C++ 实现，提供了 Skia/Impeller 渲染、Dart 运行时、平台通道、事件处理等底层能力。通过 `dart:ui` 暴露给框架层。

3.  **嵌入层（Embedder）**：平台相关代码，负责将 Flutter 嵌入具体平台，绘制到屏幕上，处理输入法、生命周期等。

这种分层使得 Flutter 能独立于平台，实现统一渲染。
