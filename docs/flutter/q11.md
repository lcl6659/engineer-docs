# Q11：Flutter 中的路由和导航是如何工作的？

使用 **Navigator**（栈管理）进行导航。

- **基本路由**：`Navigator.push(context, MaterialPageRoute(builder: ...))` 入栈；`Navigator.pop(context)` 出栈。
- **命名路由**：通过 `MaterialApp` 的 `routes` 表或 `onGenerateRoute` 配置。
  - `Navigator.pushNamed(context, '/detail')`。
- **路由传参**：通过 `ModalRoute.of(context)?.settings.arguments` 获取参数。
- **2.0 路由（Router）**：使用 `Router` 和 `RouteInformationParser`，支持 Web URL 深度链接和复杂导航栈，通常用 `GoRouter` 等第三方库简化。
- **嵌套导航**：`Navigator` 可放在任何位置，实现多栈。
