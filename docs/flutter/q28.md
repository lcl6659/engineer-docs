# Q28：原生页面和 Flutter 页面间如何共享状态？

可以通过以下方式同步状态：

- **Platform Channel 双向通信**：Flutter 主动监听原生状态变化事件（EventChannel）；原生也可通过 MethodChannel 主动通知 Flutter。
- **共享存储**：共同访问数据库（如 SQLite）、SharedPreferences/UserDefaults、文件系统等，但需同步刷新。
- **全局状态管理 + Channel 桥接**：将原生变化转化为 Flutter 状态管理库（如 Provider）的数据更新；反之亦然。
- **FFI（Foreign Function Interface）**：直接调用 C/C++ 代码，绕过 Channel 的开销，适用于高频交换。

常用渠道：登录态、主题切换、网络状态变化等。
