# Q13：Provider 的工作原理是什么？如何优化性能？

- **原理**：Provider 扩展了 `InheritedWidget`，在 Widget 树上提供数据。后代组件通过 `context.watch<T>()` 读取并监听变动，当 `ChangeNotifier` 通知变化时，依赖重建。
- **使用**：
  - `ChangeNotifierProvider` 提供 `ChangeNotifier` 模型。
  - `Consumer<T>` 或 `context.watch<T>` 读取并重建。
- **性能优化**：
  - 使用 `context.select<T, R>()` 只监听特定属性。
  - 使用 `Consumer` 限定重建范围。
  - 将提供者放在合适层级，避免不必要的高层重建。
