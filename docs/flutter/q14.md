# Q14：Flutter 动画系统简介

动画基于 **Animation** 和 **Widget** 结合：

- **Animation**：泛型 `Animation<T>` 负责插值与状态监听，通常由 `AnimationController` 驱动。
- **AnimationController**：控制动画时长、方向等（`forward`、`repeat`），需 `TickerProvider`。
- **Tween**：定义起始和结束值。
- **AnimatedWidget**：如 `AnimatedBuilder`，监听动画并重建某部分。
- **隐式动画**（`AnimatedXXX`）：如 `AnimatedOpacity`、`AnimatedContainer`，只需改变属性即自动过渡。
- **Hero 动画**：跨页面共享元素过渡。
- **路由过渡动画**：自定义 `PageRouteBuilder`。
