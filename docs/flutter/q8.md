# Q8：Key 在 Flutter 中的作用与类型

`Key` 用于在 Widget 重建时**帮助框架识别同一层级的 Widget 是否可复用**，避免不必要的状态丢失或重建。

**类型**：
- `ValueKey`：基于值相等（如 `ValueKey('home')`）。
- `ObjectKey`：基于对象同一性。
- `UniqueKey`：每次都是唯一，会强制重建。
- `GlobalKey`：全局唯一，用于直接访问 Widget 的 State 或 RenderObject，或跨 Widget 持有状态。

**使用场景**：
- 列表删除/移动/增加时保持状态对应。
- 使用 `GlobalKey` 获取表单验证状态、获取子组件尺寸位置。
