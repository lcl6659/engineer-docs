# Q25：为什么不建议在 `build` 方法中执行复杂计算？

`build` 方法在每个帧中可能被多次调用（由于上级 Widget 重建或自身 `setState`），并且必须快速完成以保持 60fps。复杂计算会阻塞 UI 线程，导致掉帧、卡顿。

**优化措施**：
- 将复杂计算移出 `build`，只在数据变化时计算并缓存。
- 使用 `Selector`（Provider）等只监听必要数据，避免无关变化触发 `build`。
- 使用 `const` 构造函数和 `RepaintBoundary` 缓解重建压力。
- 对于真正 CPU 密集的任务，通过 `compute()` 在独立 Isolate 执行，不阻塞 UI 线程。
