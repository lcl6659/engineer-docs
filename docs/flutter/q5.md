# Q5：StatefulWidget 的生命周期方法有哪些？

创建时（挂载）：
1. `createState()`：创建 `State` 对象。
2. `initState()`：**一次性初始化**，如订阅流。
3. `didChangeDependencies()`：当依赖的 InheritedWidget 变化时调用。
4. `build()`：构建 Widget 树。

更新时：
- `didUpdateWidget(oldWidget)`：父组件重建时比较新旧 Widget。
- `setState()` 触发重建，调用 `build`。

销毁时：
- `dispose()`：释放资源，取消订阅。
- `deactivate()`：从树中移除时调用，可能重新插入。

其他：
- `reassemble()`：开发阶段热重载触发。
