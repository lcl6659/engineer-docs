# Q30：如何构建适配移动端、桌面端和 Web 的自适应 UI？

Flutter 提供了多种机制实现响应式与自适应：

- **LayoutBuilder**：根据父容器约束动态布局。
- **MediaQuery**：获取屏幕尺寸、方向、像素比例等。
- **Breakpoint 设计**：针对不同宽度范围定制布局（单列、双列等）。
- **Platform 检测**：`Theme.of(context).platform` 或 `defaultTargetPlatform` 来加载不同风格的组件（Material / Cupertino），或显示不同交互元素（如桌面端的悬停效果、右键菜单）。
- **库支持**：`flutter_platform_widgets`、`responsive_framework` 等简化。
- **Web 特定处理**：注意导航行为和 URL 匹配，使用 Router；减少 Web 端不可用的插件。

设计时遵循“适应、响应、平台特化”原则，尽量使用同一套代码，特殊差异通过条件导出或文件替换实现。
