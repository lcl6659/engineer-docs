# Q1：Flutter 是什么？它的核心特点有哪些？

Flutter 是 Google 开源的 **UI 工具包**，使用 **Dart** 语言，通过一套代码库构建跨平台（iOS、Android、Web、桌面）的原生编译应用。

**核心特点**：

- **自绘引擎（Skia/Impeller）**：不依赖原生控件，直接在画布上绘制 UI，保证跨平台一致性。
- **热重载（Hot Reload）**：亚秒级将代码变更注入正在运行的应用，极大提升开发效率。
- **组件化（Widgets）**：一切皆为 Widget，组合构建复杂界面。原生提供 Material Design 和 Cupertino 组件。
- **高性能**：Dart 支持 AOT 编译，获得接近原生的性能；不作桥接的 UI 渲染管线。
- **快速启动**：通过 Dart 的 JIT 加速开发周期。
- **生态丰富**：官方导航、状态管理、测试、国际化等支持，以及庞大的社区包。
