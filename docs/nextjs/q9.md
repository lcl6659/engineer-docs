# Q9：什么是 Middleware（中间件）？它的使用场景？

Middleware 是在请求完成之前运行的代码，可以**拦截并修改请求/响应**。它基于标准的 Web API（Request/Response）。

**常见用途**：
- **身份验证**：检查 cookie/token，无权限则重定向到登录页。
- **国际化和重定向**：根据请求头或国家重写 URL。
- **A/B 测试**：流控部分用户到不同页面。
- **请求改写和头修改**：添加安全头、URL 重写等。

**注意**：Middleware 运行在 Edge Runtime，API 受限，不能直接使用 Node.js 模块。

示例（检查认证）：
```javascript
// middleware.js
import { NextResponse } from 'next/server';
export function middleware(request) {
  if (!request.cookies.has('token')) {
    return NextResponse.redirect(new URL('/login', request.url));
  }
}
export const config = { matcher: '/dashboard/:path*' };
```
