# Q8：Next.js 的 Layout、Loading、Error 文件的作用是什么？

App Router 中，每个路由段文件夹都能包含一些特殊文件，用于共享 UI 与处理状态：

- **`layout.js`**：包裹子页面和子布局的共享 UI，导航切换时**布局保持不变**（状态不丢失）。可嵌套，根布局必须存在且包含 `<html>` 和 `<body>`。
- **`template.js`**：类似布局，但每次导航都会重新挂载，适用于需要重置状态的场景（如页面切换动画）。
- **`loading.js`**：页面或布局加载时显示的瞬时加载状态（基于 Suspense 的 fallback）。常结合流式加载提升感知速度。
- **`error.js`**：捕获该路由段子组件的运行时错误，显示降级 UI，不会影响上层布局。必须为客户端组件。
- **`not-found.js`**：当路由中抛出 `notFound()` 或访问不存在路由时显示 404 UI。
