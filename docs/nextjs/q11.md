# Q11：Next.js 的图片优化（`next/image`）有哪些优势？

`next/image` 组件是对原生 `<img>` 的增强，实现了大量自动优化：

- **懒加载**：默认采用原生 `loading="lazy"`，视野外的图片按需加载。
- **尺寸优化**：根据设备自动提供合适尺寸的图片（通过 `srcset` 和 `sizes`）。
- **格式转换**：自动转换为 WebP 或 AVIF 等现代格式，减小文件体积。
- **防止布局偏移**：要求提供 `width`/`height` 或 `fill`，预留空间避免 CLS（累积布局偏移）。
- **CDN 优化**：图片由内置 Image Optimization API 处理，可缓存到全球 CDN。
- **模糊占位符**：通过 `placeholder="blur"` 提供低质量图像预览。
