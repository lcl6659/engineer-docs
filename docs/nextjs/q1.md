# Q1：Next.js 是什么？它解决了什么问题？

Next.js 是一个基于 React 的**全栈开发框架**，允许使用 React 构建 Web 应用，并内置了大量开箱即用的功能。

**核心解决的问题**：
- **服务端渲染（SSR）与静态生成（SSG）**：弥补了纯客户端渲染（CSR）在首屏性能、SEO 上的不足。
- **文件系统路由**：通过 `pages` 或 `app` 目录约定，自动生成路由，无需额外配置路由库。
- **性能优化**：内置图片优化、代码分割、预取等策略。
- **开发体验**：零配置起步，支持热更新、TypeScript、ESLint 等。
- **全栈能力**：可在同一项目中编写 API 路由（或 Server Actions），构建完整应用。
