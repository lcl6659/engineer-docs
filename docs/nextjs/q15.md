# Q15：如何自定义错误页面，如 404、500？

**App Router**：
- `app/not-found.js`：当调用 `notFound()` 或路由不匹配时显示。
- `app/error.js`：捕获当前路由段子树的运行时错误。
- `app/global-error.js`（生产环境）：根级错误边界，需要包含 `<html>` 和 `<body>`，在根布局出错时显示。
- 也可以按路由段放置 `error.js` 实现局部错误处理。

**Pages Router**：
- `pages/404.js` 和 `pages/500.js` 自定义相应页面。
- 也可以在 `pages/_error.js` 中统一处理错误状态码。
