# Q14：`next/dynamic` 有什么用？

`next/dynamic` 是 Next.js 的动态导入封装，常用于代码分割和组件懒加载。

```javascript
import dynamic from 'next/dynamic';

const HeavyComponent = dynamic(() => import('../components/HeavyComponent'), {
  loading: () => <p>Loading...</p>,
  ssr: false // 可禁用服务端渲染
});
```

它支持自定义加载指示器，并可选择完全禁用 SSR，适用于那些依赖浏览器 API 的元素，或对首屏无用的重型组件。
