# Q2：Next.js 的文件系统路由是如何工作的？

Next.js 根据 `pages` 或 `app` 目录的文件结构自动创建路由。

**Pages Router（`pages` 目录）**：
- `pages/index.js` → `/`
- `pages/about.js` → `/about`
- `pages/posts/[id].js` → `/posts/:id`（动态路由）
- `pages/posts/[...slug].js` → 捕获所有路径（`/posts/a/b/c`）

**App Router（`app` 目录）**：
- `app/page.js` → 对应路由的页面 UI，与 `layout.js`、`loading.js`、`error.js` 等共同构成路由段。
- 文件夹用于定义路由段，如 `app/dashboard/page.js` → `/dashboard`
- 动态路由：`app/products/[id]/page.js` → `/products/1`

**文件命名约定**：`page.js`、`layout.js`、`loading.js`、`error.js`、`not-found.js`、`route.js`（API 路由）。
