# Q20：如何处理 CSS 样式？Next.js 支持哪些样式方案？

- **全局样式**：在 `app/layout.js` 中导入 `globals.css` 使用。
- **CSS Modules**：`*.module.css` 文件，自动生成唯一类名，避免冲突。
- **Tailwind CSS**：官方推荐，安装后通过配置文件即可使用。
- **CSS-in-JS**：需要配置客户端组件包裹，主流库如 `styled-components` 需额外的 `StyledComponentsRegistry`（因 RSC 不支持样式注入）。
- **Sass**：内置支持 `.scss`。
