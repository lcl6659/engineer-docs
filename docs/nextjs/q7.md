# Q7：`'use client'` 和 `'use server'` 分别代表什么？

- **`'use client'`**：声明一个文件为**客户端组件**。在组件顶部添加此指令后，该组件及其引入的子组件都将在客户端渲染，可以使用状态、事件处理、浏览器 API。需要交互的 UI 必须标为客户端组件。
- **`'use server'`**：声明一个异步函数为 **Server Action**，它只在服务端执行。可以放在独立文件顶部，也可以直接在函数体处使用。用于处理表单提交、操作数据库等，不需要手动创建 API 路由。

**核心原则**：尽可能把组件放在服务端（毕竟直接访问后端），只在需要交互时使用 `'use client'`。
