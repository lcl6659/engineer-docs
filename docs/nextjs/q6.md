# Q6：在 App Router 中，如何获取数据？什么是 React Server Components？

**数据获取**：
- 在 App Router 中，**服务器组件默认就是异步的**，可以直接在组件内部使用 `async/await` 调用 `fetch`，不再需要 `getServerSideProps` 等方法。
- 利用 `fetch` 的缓存和重新验证选项：`fetch(url, { cache: 'force-cache' | 'no-store' })`，或 `next: { revalidate: 60 }`。
- 通过 `generateStaticParams` 为动态路由预生成静态页面。

**React Server Components（RSC）**：
- 是 React 18 推出的新组件类型，**默认在服务端渲染**，不会被发送到客户端，因此可以安全地直接访问数据库、文件系统等后端资源。
- 减少客户端打包体积，提升性能。
- 与客户端组件（`'use client'`）结合使用：客户端组件用于交互（状态、事件），服务器组件用于数据获取和无交互 UI。
- 数据可以直接从服务器组件流向客户端组件，无需创建 API 层。
