# Q17：Next.js 国际化（i18n）如何实现？

**Pages Router**：在 `next.config.js` 中配置 `i18n` 字段，支持子路径路由和域路由，自动 locale 检测。

**App Router**（推荐）：
- 使用动态路由处理 locale：如 `app/[lang]/page.js`。
- 借助 `middleware.js` 检测请求头或 cookie 进行重定向，实现自动语言切换。
- 搭配词典文件或 `next-intl` 等库管理翻译内容。
- 结合 `generateStaticParams` 预渲染所有 locale 的静态页面。
