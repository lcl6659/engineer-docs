# Q3：Pages Router 与 App Router 的主要区别

| 特性 | Pages Router | App Router（推荐） |
|------|-------------|---------------------|
| 基础概念 | 每个文件就是一个页面 | 每个文件夹代表路由段，包含 `page`、`layout` 等文件 |
| 数据获取 | `getServerSideProps`、`getStaticProps`、`getStaticPaths` | React Server Components + `async` 组件，直接 `fetch` 数据 |
| 布局 | 需要手动封装或使用 `_app` 共享 | 嵌套 `layout.js`，支持自动局部布局复用 |
| 流式加载 | 不支持 | 支持 `loading.js`、`Suspense`、流式 SSR |
| Server Actions | 不支持 | 原生支持，通过 `'use server'` 在服务端执行函数 |
| 路由分组 | 自定义 `_app` 或 HOC | 通过 `(group)` 文件夹不影响 URL 的布局分组 |
| 并行路由 | 不支持 | 支持 `@slot` 并行路由 |
| 拦截路由 | 不支持 | 支持 `(.)` `(..)` 拦截路由 |

新项目推荐使用 **App Router**，它基于 React 18 的并发特性和服务器组件。
