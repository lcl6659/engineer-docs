# Q16：Server Actions 是什么？如何使用？

Server Actions 是可以在 React 组件中直接调用的服务器端异步函数，简化了表单提交和数据变更，无需手动创建 API 路由。

**定义**：在一个函数中使用 `'use server'` 指令，或将其放在带有 `'use server'` 的文件中。
```javascript
// app/actions.js
'use server'
export async function createPost(formData) {
  // 直接操作数据库
}
```

**使用**：
- 作为表单的 `action`：`<form action={createPost}>`，支持渐进式增强（无 JS 也能提交）。
- 在客户端组件中通过 `transition` 或普通调用触发。

可以配合 `revalidatePath` 或 `revalidateTag` 刷新缓存数据。
