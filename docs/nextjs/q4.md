# Q4：Next.js 支持哪些渲染方式？分别是什么？

Next.js 支持四种渲染策略，可以在同一应用中混合使用：

1. **客户端渲染（CSR）**：和传统 React 一样，浏览器先加载空壳 HTML 和 JS，然后在客户端渲染 UI。适合后台管理、不需要 SEO 的页面，通过 `'use client'` 声明。

2. **服务端渲染（SSR）**：每次请求都在服务端生成 HTML 并返回。适用于需要实时数据、个性化的页面。
   - Pages Router：`getServerSideProps`
   - App Router：在服务器组件中直接 `fetch`，默认就是动态渲染。

3. **静态站点生成（SSG）**：构建时（`next build`）就提前生成 HTML，可以缓存在 CDN 上。非常适合博客、文档、产品介绍等变化不频繁的页面。
   - Pages Router：`getStaticProps`
   - App Router：默认会尝试静态化，除非使用动态函数如 `cookies()`、`headers()`，或显式设置 `export const dynamic = 'force-static'`。

4. **增量静态再生成（ISR）**：构建后仍然可以按需更新静态页面。设置一个时间间隔（revalidate），过期后第一次请求触发后台重新生成。兼顾静态的速度和动态的实时性。
