# Q19：怎样在 Next.js 中实现身份验证？

方式多样，本质上与任何 Web 应用类似，但可利用 Middleware 和 Server Components：

- **会话/Cookie 模式**：用户登录后，服务端设置 HttpOnly cookie，Middleware 检查 cookie 保护路由，Server Components 可读取 cookie 获取用户。
- **JWT 模式**：令牌存于 cookie 或内存，服务端校验。
- **NextAuth.js / Auth.js**：流行库，支持多种 OAuth 提供商，内置 CSRF 防护，无状态认证等。
- 在客户端，可用 `useSession` 等 Hooks，在服务端可直接调用 `auth()` 获取会话。
