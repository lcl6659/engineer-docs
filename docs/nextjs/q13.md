# Q13：如何优化 Next.js 应用的性能？

- **使用服务端组件**：尽量减少客户端 JS 体积。
- **静态生成（SSG/ISR）**：将可以不与请求耦合的页面预渲染。
- **图片和字体优化**：使用 `next/image` 和 `next/font`。
- **流式加载与 Suspense**：用 `loading.js` 或 `<Suspense>` 分段传输内容，降低 TTFB 感知。
- **Middleware 缓存**：合理设置缓存头。
- **CDN 部署**：使用 Vercel 等平台自动边缘缓存。
- **代码分割与懒加载**：动态导入大型库或非首屏组件 `next/dynamic`。
- **数据库/API 优化**：使用缓存的 `fetch`，在服务端缓存数据库查询。
