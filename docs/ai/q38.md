# Q38：如何根据场景选择合适的大模型？

**代码/Agent 开发**：
- 高端长程编程/自主代理 → Claude Opus 4.7（性价比最优通用编程代理）
- Computer Use 自动化 → GPT-5.4 Pro 或 GPT-5.5
- 国内开源/性价比 → DeepSeek-V4 Pro、Kimi K2.6、Qwen 3.6

**内容创作与日常对话**：
- 全面均衡、办公场景 → GPT-5.4（文档、表格、演示文稿支持）
- 中文内容质量 → Qwen 3.6、DeepSeek-V4

**多模态场景**：
- 音视频分析、PDF还原 → Gemini 3.1 Pro（多模态维度最全）
- 图像理解深度 → Claude Opus 4.7（支持 3.75MP 高分辨率图像）

**科研推理**：
- 高难度科学问题 → Gemini 3 Deep Think、OpenAI o3
- STEM / 竞赛数学 → DeepSeek-V4 Pro + 推理模型

**大规模部署（成本优先）**：
- 极致低成本 → DeepSeek-V4 Flash、Gemini 2.5 Flash-Lite、Qwen-Flash

**私有化部署**：
- 开源阵营 → Meta Llama 4 系列、DeepSeek-V4、Qwen 3.6、Kimi K2.6
