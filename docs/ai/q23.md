# Q23：常见的开源大模型有哪些？如何选择？

**国际主流**：
- **Llama 系列**（Meta）：Llama 2, Llama 3, Llama 4，开源友好，社区生态丰富。
- **Mistral / Mixtral**（Mistral AI）：混合专家模型（MoE），性能强。
- **Gemma**（Google）：轻量级开源模型。
- **Falcon**（TII）：曾经的开源王者之一。

**中文及国内**：
- **Qwen（通义千问）**（阿里）：性能优越，多尺寸开源。
- **DeepSeek**：强大推理能力，DeepSeek-R1 等。
- **ChatGLM**（智谱）：双语对话模型。
- **Baichuan**（百川智能）：中文优化。
- **Yi**（零一万物）：长上下文能力强。

**选择考量**：参数量、许可证、语言支持（中文）、推理速度、硬件需求、是否有指令微调版本、社区活跃度。
