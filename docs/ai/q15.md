# Q15：GPT 系列模型的演进和核心区别

GPT（Generative Pre-trained Transformer）是**仅解码器**架构的自回归语言模型。

- **GPT-1**：基于 Transformer 解码器，单向（从左到右）预训练语言模型，证明了生成式预训练+微调的有效性。
- **GPT-2**：参数扩大（15 亿），强调无监督多任务学习能力（zero-shot），未对特定任务微调也表现良好。
- **GPT-3**：巨大参数（1750 亿），首次提出上下文学习（In-context Learning）和 few-shot 概念，无需微调即可通过提示完成任务。
- **GPT-4**：多模态（文本+图像输入），更强大的推理、代码生成和多语言能力，具体实现细节未公开。

核心趋势：参数规模指数增长、从微调范式转向提示工程、模型通用性增强。
