# Q9：什么是卷积神经网络（CNN）？它的核心组件有哪些？

CNN 是专门处理网格状数据（如图像）的深度学习架构。

**核心组件**：
- **卷积层**：用多个可学习的滤波器（卷积核）滑动提取局部特征（边缘、纹理等）。
- **池化层**：下采样，降低特征图尺寸，减少参数，提供平移不变性（如最大池化、平均池化）。
- **激活函数**：通常是 ReLU。
- **全连接层**：将提取的特征用于分类或回归。
- **批归一化（Batch Normalization）**：加速训练，稳定模型。

经典架构：LeNet、AlexNet、VGG、ResNet（引入残差连接解决深层网络退化问题）、Inception、EfficientNet。
