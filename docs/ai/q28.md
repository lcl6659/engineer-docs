# Q28：怎样部署和推理优化大语言模型？

大模型部署需要解决显存和延迟问题，常用方法：

- **模型量化**：使用低精度格式（如 INT8、INT4、NF4）存储权重，减少显存占用和加速推理。工具：bitsandbytes、GPTQ、AWQ。
- **剪枝**：移除模型中不重要的权重或结构。
- **知识蒸馏**：用小模型学习大模型的输出分布（如使用较大的 teacher 模型训练 student 模型）。
- **推理框架**：vLLM（PagedAttention 高效管理 KV 缓存）、Text Generation Inference（TGI）、TensorRT-LLM、llama.cpp 等。
- **FlashAttention**：优化注意力计算的内存访问模式，加速训练和推理。
- **KV 缓存优化**：多轮对话时缓存 key-value 状态，避免重复计算。
