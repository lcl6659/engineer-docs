# Q21：什么是提示工程？有哪些常用技巧？

提示工程是设计和优化给 LLM 的输入提示，以引导模型生成期望输出的实践。

**常用技巧**：
- **少样本提示（Few-shot）**：在提示中提供几个示例（输入-输出对），帮助模型理解任务格式。
- **思维链（Chain-of-Thought，CoT）**：引导模型分步骤推理，尤其在复杂推理任务中效果显著（如加一句“让我们一步一步思考”）。
- **角色扮演**：为模型设定角色（如“你是一位资深律师”），影响模型的回答风格和准确性。
- **约束和格式指定**：明确要求输出结构（JSON、列表）、语言、长度等。
- **自我一致性（Self-Consistency）**：多次采样使用 CoT，取最一致的答案，提高推理鲁棒性。
