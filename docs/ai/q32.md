# Q32：Gemini 3 系列有哪些版本？各版本定位如何？

Google 通过 Gemini 3 系列构建了覆盖"科研探索—专业开发—日常使用"的完整产品矩阵。

**Gemini 3 Pro**（2026 年初）：
- 作为 Gemini 3 基座模型提供核心能力，主打多模态统一与长上下文处理。
- 支持"Thinking"模式：在回答前进行更深层推理。

**Gemini 3 Deep Think**（2026 年 2 月）：
- 由 Google 与顶尖科学家**深度共创**的推理增强版本。
- 专门优化真实科研场景——处理边界模糊、无唯一标准答案、且数据杂乱不全的复杂问题。
- 性能超越 GPT-5.2 和 Claude Opus 4.6。

**Gemini 3.1 Pro**（2026 年 2 月）：
- 基于 Deep Think 技术基础的**迭代增强版**，进一步提升核心推理能力。
- **多模态能力全维度领先**：支持文本、图像、视频、音频、PDF 结构化还原、Google 生态深度集成。
- 在 ARC-AGI-2 基准测试中得分 **77.1%**，在多款旗舰模型中领先。
- 1M 上下文但**最大输出为 65k Token**（约 GPT-5.4 和 Opus 4.7 的一半）。

**定位差异**：
- Deep Think → 科研推理专用，面向最难问题
- 3.1 Pro → 全模态旗舰，多场景均衡
- 3 Pro → 基座模型，高效推理
