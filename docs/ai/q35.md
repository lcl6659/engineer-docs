# Q35：各家大模型的价格对比如何？

截至 2026 年 4 月，各主流大模型 API 定价（每百万 Token，单位：美元）：

**顶级旗舰级（输出 $25–$180/百万Token）**：
- GPT-5.4 Pro：$30/$180（输入/输出）——当前定价最高的通用旗舰，Pro版输出是Opus 4.7的7.2倍
- Claude Opus 4.7：$5/$25 ——通用场景性价比最均衡的选择
- o3 / o4-mini（推理模型）：$10/$40；单价昂贵但输出含思考过程
- GPT-5.4 标准版（非 Pro）：$2.50/$15，适合大多数非极限任务场景

**均衡旗舰级（输出 $5–$15/百万Token）**：
- Claude Sonnet 4.6：$3/$15
- Gemini 2.5 Pro：$1.25/$10
- GPT-4.1：$2/$8

**极致性价比级（输出 $0.40–$2.50/百万Token）**：
- DeepSeek-V4 Flash：约 $0.28（缓存命中后）/ 输出约 $0.28
- Gemini 2.5 Flash-Lite：$0.10/$0.40
- Gemini 2.5 Flash：$0.30/$2.50
- Qwen-Flash：$0.05/$0.40

**定价策略的核心差异**：OpenAI 高位高质走"技术溢价"路线；Anthropic 提供位阶清晰的产品线（Opus $25 vs Sonnet $15 vs Haiku 更低价）；Google 和阿里以极高的性价比和大生态锁定用户；DeepSeek 在价格上"无节操低价"，Pro 仅24元人民币输出 / 百万Token，对国内市场造成巨大冲击。
