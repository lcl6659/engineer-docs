# Q36：编程能力（Coding）谁更强？

编程与 Agentic Coding 是当前大模型能力分化最明显的维度，也是开发者选型的核心参考。

**国际旗舰对比（截至 2026 年 4 月）**：
- **Claude Opus 4.7**：Agentic Coding 当前最优通用模型，长程工程任务可靠性高，工具调用错误率降低 2/3，SWE-bench 72.7%（Sonnet 4.6 达成）。
- **GPT-5.5（最新旗舰）**：Terminal-Bench 较上代 +7.6pp 编程质变，100 万 Token 实质性可用 + verifier 自我修正循环。
- **GPT-5.4 Pro**：原生 Computer Use + SWE-bench Pro 57.7%，在 Agent 工作流中优势显著。
- **Gemini 3.1 Pro**：多模态编程能力突出，但在纯代码 SWE-bench 上略低于 Opus 和 GPT。

**国内开源模型**：
- **Kimi K2.6**：Terminal-Bench 2.0 (66.7)、SWE-Bench Pro (58.6)、HLE-Full (54.0) 均为开源领先。
- **DeepSeek-V4 Pro**：开源模型首位（Agentic Coding 专项评测），世界知识接近顶尖闭源模型。
- **Qwen 3.6 Max-Preview**：六大主流编程基准最佳成绩，智能体编程业界领先。

**一句话评估**：算法代理性编程（多步自主工程）看 Anthropic；广谱编程+通用任务看 OpenAI；高性价比代码生成和国内落地实战看国产开源。
