# Q26：Transformer 中的层归一化（Layer Normalization）和批归一化（Batch Normalization）有何不同？

- **批归一化（BN）**：对一个 batch 里同一特征维度的所有样本进行归一化。依赖 batch 大小，不适合小 batch 或序列长度变化场景。
- **层归一化（LN）**：对单个样本的所有特征维度进行归一化，不依赖 batch 统计量。因此在 NLP Transformer 中成为标准，能处理变长序列，训练和推理行为一致。

Transformer 原始设计中使用的是 **Post-LN**（层归一化放在残差连接之后）；后来 **Pre-LN**（层归一化放在自注意力/前馈网络之前）因训练更稳定而成为主流。
