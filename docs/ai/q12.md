# Q12：Transformer 架构的核心原理是什么？自注意力和多头注意力机制如何工作？

Transformer 完全基于注意力机制，放弃了循环结构，使用 **编码器-解码器** 结构（也可只用编码器或只用解码器）。

**核心创新**：自注意力机制，允许每个位置都与序列中的所有其他位置交互，直接全局建模依赖关系。

**自注意力计算过程**：
1. 从输入向量生成三个向量：查询（Query）、键（Key）、值（Value）。
2. 计算注意力分数：`Score = Q * K^T`。
3. 缩放：`Score / sqrt(d_k)` 防止点积过大，使 softmax 梯度稳定。
4. 通过 softmax 得到注意力权重。
5. 权重乘以值向量 V，加权求和得到输出。

**多头注意力**：并行运行多组独立的注意力（头），每个头关注不同的表示子空间，然后将结果拼接，使模型能捕获丰富的语义信息。

**位置编码**：由于 Transformer 没有循环/卷积，必须显式注入位置信息，通常用正弦位置编码或可学习的位置嵌入。
