# Q22：什么是 AI Agent？它由哪些核心模块构成？

AI Agent 是能够自主感知环境、做出决策并执行行动以实现目标的智能体，常由 LLM 作为“大脑”。

**核心模块**：
- **任务规划**：将复杂目标分解为子任务，制定执行步骤（如 ReAct、Plan-and-Execute 模式）。
- **记忆**：
  - 短期记忆：上下文（对话历史）。
  - 长期记忆：外部知识库或向量存储。
- **工具使用**：调用外部 API、搜索引擎、代码解释器、计算器等，扩展 LLM 能力边界。
- **行动**：根据规划执行具体操作，观察结果并调整。

著名的框架：LangChain、AutoGPT、MetaGPT、CrewAI。
