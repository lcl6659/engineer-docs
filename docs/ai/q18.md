# Q18：什么是低秩适应（LoRA）和量化 LoRA（QLoRA）？它们如何实现高效微调？

LoRA（Low-Rank Adaptation）是一种参数高效微调（PEFT）技术：

- 思想：大模型微调时，权重更新矩阵通常是低秩的。因此不直接更新原始权重，而是注入低秩分解矩阵（A 和 B），只训练这两个小矩阵。
- 优点：极大减少可训练参数量（常仅为原始参数的数百分之一），可合并回原权重不增加推理延迟，支持多任务切换。

**QLoRA**：
- 将 LoRA 与 **量化** 相结合。首先将预训练模型量化为 4 位（NormalFloat4），冻结参数；然后在此基础上训练 LoRA 适配器。
- 效果：在单个消费级 GPU 上微调 650 亿参数模型成为可能，显存和计算成本大幅降低。
