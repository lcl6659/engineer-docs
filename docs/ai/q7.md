# Q7：什么是激活函数？常见的激活函数有哪些？

激活函数为神经网络引入非线性，使其能拟合复杂函数。

- **Sigmoid**：输出 (0, 1)，常用于二分类输出层，但易梯度消失。
- **Tanh**：输出 (-1, 1)，中心为0，梯度消失问题稍好。
- **ReLU**：`max(0, x)`，简单高效，缓解梯度消失，但存在“死神经元”问题（梯度为0后不再激活）。
- **Leaky ReLU / PReLU**：给负半轴一个小的斜率避免死神经元。
- **Softmax**：将向量转为概率分布，多分类输出层标准选择。
- **GELU**：在 Transformer 等当代大模型中广泛使用，是 ReLU 的平滑版本。
