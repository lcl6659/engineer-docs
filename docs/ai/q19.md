# Q19：RAG（检索增强生成）是什么？它的架构和优势是什么？

RAG 是一种结合**信息检索**与**大语言模型生成**的框架，用于解决 LLM “幻觉” 问题和知识截止日期问题。

**基本架构**：
1. **索引**：将外部知识库（文档、知识库、向量数据库等）切分并编码为向量索引。
2. **检索**：用户查询到来时，将查询编码为向量，从索引中检索出最相关的 k 个文档片段。
3. **增强**：将检索到的文档片段和原始查询一起作为 prompt 传给 LLM。
4. **生成**：LLM 基于提供的上下文生成回答。

**优势**：
- 无需重新训练模型即可访问最新或私有知识。
- 显著降低幻觉，因为模型被“根植”于真实文档。
- 可解释性增强，能指出答案出处。
