# Q31：Claude 4 系列有哪些版本？Opus 4.6 和 Opus 4.7 有什么区别？

Anthropic 的 Claude 4 系列于 2025–2026 年间密集迭代，在编程和 Agent 执行领域确立了坚实地位。

**Claude 4 系列架构**：
- **Claude Opus 4**（旗舰级）：面向最复杂任务，含 Opus 4、4.5、4.6、4.7 等迭代版本
- **Claude Sonnet 4**（均衡级）：高性能与成本效率的平衡点
- **Haiku**（轻量级）：高性价比快速推理

**Claude Opus 4.6**（2026 年 2 月）：
- 在 Agent 编程和 Computer Use 场景确立为当时的"最优模型"。
- 128k Token 最大输出，1M 上下文窗口，定价 $5/$25（输入/输出 每百万Token）。
- SWE-bench 综合得分 72.7%（Sonnet 4.6 达成）。

**Claude Opus 4.7**（2026 年 4 月）——核心升级：
- **Agentic Coding 跨越式提升**：在自主编程、多步工具调用、长程迭代修正等场景大幅超越 4.6。
- **工具调用错误率降低 2/3**：长序列工作流可靠性显著提升。
- **字面指令遵循强化**：对精确格式和约束要求的遵从度更高。
- **视觉解析 3 倍分辨率**：支持 3.75MP 的高分辨率图像，XBOW 视觉测试识别率跃升至 98.5%。
- **定价不变**：$5/$25，被视为通用场景性价比最均衡的选择。
- Agent 多步任务成功率提升 14%，特别适合长期运行的自主流程。

**定位总结**：Claude Opus 4.7 是 Anthropic"让模型更可靠、更可控"理念的最新体现。
