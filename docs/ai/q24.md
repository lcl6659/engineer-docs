# Q24：模型评估指标有哪些？如何评价大模型的性能？

根据任务不同：
- **分类任务**：准确率、精确率、召回率、F1 分数、AUC-ROC。
- **生成任务**：
  - **困惑度（Perplexity）**：衡量语言模型对测试数据的预测能力，越低越好。
  - **BLEU**：机器翻译和摘要评估，基于 n-gram 精确匹配。
  - **ROUGE**：主要用于摘要评估，基于召回率。
  - **METEOR**：结合精确率和召回率，考虑同义词。
- **综合大模型评估集**：
  - **MMLU**：大规模多任务语言理解，涵盖 57 个学科。
  - **HumanEval**：代码生成能力评估。
  - **HellaSwag、ARC**：常识推理。
  - **Chatbot Arena（LMSYS）**：众包人类偏好比较，Elo 排名。
