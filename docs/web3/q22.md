# Q22：什么是跨链桥（Bridge）？有哪几种类型？

跨链桥是一种连接独立区块链的协议，允许**资产和数据在不同的区块链之间转移**。

**主要类型**：
1. **锁定&铸造型**：在源链锁定资产，在目标链铸造等价包装资产。典型如 WBTC（比特币在以太坊上的包装）。
2. **销毁&铸造型**：在源链销毁资产，在目标链铸造资产。
3. **原子交换型**：双方直接在链间交换资产，无需中间包装代币。
4. **流动性网络型**：通过中间节点的流动性池实现资产交换。

**风险**：
- 跨链桥是黑客攻击的重灾区（如 2022 年 Wormhole 和 Ronin Bridge 被盗事件）。
- 中心化桥存在托管风险。
- 不同链的资产可能存在流动性分散问题。
