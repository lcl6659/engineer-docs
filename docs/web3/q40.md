# Q40：Solidity 中的常见 gas 优化技巧

1. **减少存储操作**：用 `memory` 缓存 storage 变量，避免重复读。
2. **使用 `immutable` 和 `constant`**：编译时确定的变量内联，比存储便宜。
3. **短电路优化**：条件语句中将最可能失败的判断放前面。
4. **无符号整数与安全数学**：使用 `unchecked` 块避免溢出检查（需确保安全）。
5. **优化 `for` 循环**：`++i` 优于 `i++`，使用 `unchecked` 增量，避免边界检查重复。
6. **合并读写**：一次性读取多个变量到局部变量。
7. **使用 `calldata`** 取代 `memory` 参数（不可变数据）。
8. **使用事件而非存储**：记录只需链下可见的信息。
9. **删除存储变量**：使用 `delete` 退还 gas 补贴。
10. **选择合适的数据结构**：mapping 比数组更 gas 高效。
