# Q11：什么是 NFT？它的核心价值和常见应用场景有哪些？

NFT（非同质化通证）是基于区块链技术的**非同质化数字资产**，用来标注数字内容作品的所有权。每个 NFT 具有独一无二的编码，使其具备稀缺性和可交易性。

**核心价值**：
- **数字所有权确权**：通过区块链记录谁拥有某个数字资产。
- **稀缺性**：可限制发行数量，创造稀缺价值。
- **创作者经济**：支持版税功能，创作者可在二级市场转售中获得持续收益。

**常见应用场景**：
- 数字艺术品（如 Beeple 的作品）
- 游戏道具（如 Axie Infinity）
- 虚拟土地（如 The Sandbox、Decentraland）
- 域名（如 ENS）
- 音乐、视频、门票等。
