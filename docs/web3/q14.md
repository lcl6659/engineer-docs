# Q14：以太坊交易从发送到上链的完整流程？

1. **创建交易**：用户通过钱包构建交易（包含发送方、接收方、金额、Gas 参数等）。
2. **签名交易**：使用发送方私钥对交易进行签名。
3. **广播交易**：交易被广播到以太坊网络的交易池（mempool）。
4. **验证与打包**：矿工/验证者从 mempool 中选择交易（通常优先选择 Gas Price 高的），执行交易并打包进区块。
5. **区块广播**：新区块被广播到全网，其他节点验证区块和其中交易的有效性。
6. **达成共识**：区块被网络接受，交易状态最终确认。
7. **事件触发**：如果合约发出事件（Event），监听该事件的前端应用会收到通知并更新 UI。
