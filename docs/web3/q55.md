# Q55：ERC-6551（Token Bound Accounts）是什么？如何使用？

ERC-6551 为任何 ERC-721 NFT 分配一个**独立的智能合约账户**，该账户由 NFT 所有，可持有资产和执行交易。

- **注册表**：一个单例合约（Registry），`createAccount` 返回一个确定性地址（基于 NFT 合约+tokenId+salt）。
- **账户**：为每个 NFT 创建的代理合约，执行逻辑并持有资产。
- **应用**：NFT 可拥有其他 NFT、代币、参与 DeFi、积累链上声誉；游戏角色可自建装备背包。
- **关键优势**：无需更改现有 ERC-721 合约，向后兼容。
