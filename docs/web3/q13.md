# Q13：什么是 Layer 1 和 Layer 2？为什么需要 Layer 2？

- **Layer 1（L1）**：区块链的第一层，是整个生态系统的核心基础设施，独立处理并验证所有交易。如比特币、以太坊、Solana。
- **Layer 2（L2）**：建立在 L1 之上的扩容解决方案，将大量交易在链下处理，然后批量提交到主链，以减轻主链负担。如 Arbitrum、Optimism、Polygon zkEVM。

**为什么需要 L2**：
- 主链交易速度慢、Gas 费高（尤其在网络拥堵时）。
- L2 通过链下计算和批处理大幅提升吞吐量、降低费用。
- L2 最终依赖 L1 的安全性，继承了主链的去中心化。
