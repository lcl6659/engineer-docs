# Q49：Cosmos IBC（Inter-Blockchain Communication）协议是如何工作的？

IBC 是 Cosmos 生态中最主要的跨链通信协议，允许独立区块链直接安全地通信。

- **核心依赖**：两个链必须有快速的最终确定性（如 Tendermint 共识），并运行 IBC 模块。
- **连接建立**：链 A 和链 B 通过轻客户端互相验证对方的状态（跟踪区块头和验证者集）。
- **通道与包**：在两条链上打开通道，通过发送包含数据、超时和序列的数据包实现跨链资产转移或消息。
- **中继器**：中继器（Relayer）负责将消息从链 A 提交给链 B，无信任要求，只是搬运工。
- **安全模型**：无需第三方信任，完全依赖两条链自身的验证者安全。
