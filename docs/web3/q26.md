# Q26：什么是 The Graph？在 DApp 开发中的作用是什么？

The Graph 是一个**去中心化的索引协议**，用于组织和查询区块链数据。它好比区块链世界的搜索引擎，让开发者能够快速高效地获取链上数据。

**工作原理**：
- **子图（Subgraph）**：开发者定义的数据索引规则，描述了要索引哪些智能合约、哪些事件和如何存储数据。
- **索引器**：运行节点，根据子图定义从区块链抓取并处理数据。
- **查询**：DApp 前端通过 GraphQL 查询子图的 API 获取结构化数据。

**为什么需要 The Graph**：
- 直接从链上查询数据效率低下，需要对区块逐一扫描。
- 复杂的数据查询（如聚合、关联、历史趋势）在链上几乎不可能完成。
- The Graph 将原始链上数据预处理为结构化的、可高效查询的形式。

截至 2025 年，The Graph 网络已处理超过 1.26 万亿次查询，覆盖 90+ 区块链网络，是 Web3 最核心的数据基础设施之一。
