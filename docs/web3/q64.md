# Q64：什么是 EIP-7702？从背景到定位：为什么以太坊需要它？

EIP-7702 的背景在于，以太坊传统模型将账户严格划分为：由私钥控制、不能包含代码的 EOA，以及能执行代码但无法主动发起交易的合约账户（CA）。这种二元划分带来了显著的摩擦：
*   **操作割裂**：简单操作如"批准并兑换"至少需要两笔独立交易。
*   **支付死板**：Gas 费必须且只能用 ETH 支付。
*   **容错率低**：私钥丢失即意味着账户内所有资产的永久损失。

EIP-7702 应运而生，其核心目标是**打破 EOA 与智能合约账户（CA）之间的界限**，让现有的普通地址直接获得智能合约的编程能力，告别"一失万无"的账户模式。
