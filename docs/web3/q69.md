# Q69：目前 EIP-7702 的应用和市场采纳情况如何？

EIP-7702 已于 **2025 年 5 月 7 日** 在以太坊主网的 Pectra 升级中正式激活上线，并迅速获得了广泛支持：
*   **主流钱包全面支持**：**OKX Wallet**、**Bitget Wallet** 以及 **TokenPocket** 均已对 EIP-7702 提供了原生支持，用户可以直接在钱包内将现有地址升级为智能账户。
*   **基础设施工具齐备**：像 **Gelato** 提供了智能钱包服务，**Pimlico** 提供了相关的开发文档和测试网支持，**Etherspot** 和 **Thirdweb** 均发布了 EIP-7702 SDK，帮助开发者在应用中集成智能账户功能；此外，Flutter 开发者也能在 pub.dev 上找到 `eip7702` 包来构建支持该特性的移动端 DApp。
*   **多链生态扩展**：除了以太坊主网，**BNB Chain（BSC）**也已通过其 Pascal 硬分叉集成了 EIP-7702。
