# Q47：简述 StarkNet 的 Cairo 语言与 Solidity 的主要区别

Cairo 是 StarkWare 为 STARK 证明系统设计的编程语言，专为高效生成可验证计算而优化。

- **设计思想**：Cairo 是冯·诺依曼架构的，将程序编译为多项式，其执行可被 STARK 证明。
- **不可变性**：Cairo 中的变量默认不可变（类似 function 式语言），存储操作显式为 `write`。
- **无 EVM 兼容性**：不直接兼容 EVM 字节码，需从 Solidity 重写合约。
- **Cairo 1.0**：转型为类似 Rust 的语法，引入所有权系统和 trait，提升安全性。
- **优势**：证明生成效率更高，适合高吞吐应用。
