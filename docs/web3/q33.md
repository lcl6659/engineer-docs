# Q33：Solidity 中的 `fallback` 和 `receive` 函数分别是什么？

这两个函数是当合约收到以太币或调用未匹配的函数选择器时触发的特殊函数。

- **`receive() external payable`**：仅当 `msg.data` 为空（纯转账）时触发。一个合约最多一个 `receive` 函数。
- **`fallback() external [payable]`**：当调用不存在的函数选择器，或 `msg.data` 不为空但无匹配函数时触发。可声明为 `payable` 以接收以太币。

**触发条件**：
- 纯 ETH 转账（`msg.data` 为空）：
  1. 如果 `receive()` 存在，则调用之。
  2. 若不存在，调用 `fallback()`（如果声明为 `payable`）。
- 调用不存在的函数（`msg.data` 非空），直接调用 `fallback()`，除非它是 `payable` 才可能在调用时附带 ETH。

**常见用途**：代理合约（`fallback` 将所有调用委托给实现合约）、接收捐赠或退款。
