# Q39：`create`、`create2` 操作码的区别

两者都用于从合约中部署新合约，区别在于地址确定方式：

- **`create`**：新合约地址 = `keccak256(rlp([sender, nonce]))`，只依赖于部署者和 nonce。
- **`create2`**：新合约地址 = `keccak256(0xff + sender + salt + keccak256(init_code))`，依赖于部署者、指定的盐（salt）和合约初始化代码。

**`create2` 优势**：
- 可**预计算**合约地址，在所有链上部署到同一地址（因为可以控制盐）。
- 常用于反事实部署、确定性代理工厂。
- 通过 `bytes32 salt` 和相同 `init_code` 保证部署到相同地址。

**注意**：`create2` 因碰撞风险（试图覆盖已有地址）需谨慎使用。
