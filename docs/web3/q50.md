# Q50：Polkadot 的跨链消息传递（XCMP）与共享安全模型

Polkadot 是一个分片多链网络，中继链（Relay Chain）提供统一的共享安全。

- **平行链（Parachain）** 通过插槽连接到中继链，共享验证者集合，因此平行链间可信任彼此的状态。
- **XCMP（Cross-Consensus Message Passing）**：平行链间的消息传递协议，消息通过中继链路由，但不存储在链上（仅中继）。
- **共享安全**：所有平行链由同一组验证者保护，这使得跨链通信无需额外的信任假设。
- 相比 IBC，Polkadot 的跨链交互更原生，但平行链需租用插槽，成本较高。
