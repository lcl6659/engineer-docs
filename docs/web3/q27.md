# Q27：什么是 EIP 和 ERC？有什么区别？

- **EIP（Ethereum Improvement Proposal，以太坊改进提案）** ：对以太坊网络提出改进建议的标准化文档，涵盖核心协议、客户端 API、智能合约标准等方方面面。
- **ERC（Ethereum Request for Comments，以太坊征求意见请求）** ：专门针对**应用层标准**的 EIP 子集，主要定义代币标准、接口规范等。

**区别**：
- EIP 范围更广，包括协议层改进（如 EIP-1559 改变 Gas 费机制）。
- ERC 特指应用层标准（如 ERC-20 同质化代币标准、ERC-721 NFT 标准）。
- 所有 ERC 都是 EIP，但不是所有 EIP 都是 ERC。
