# Q28：什么是抢跑（Front-Running）？如何防范？

抢跑是利用交易在 mempool 中可见但尚未上链的时间窗口进行的不公平行为。

**攻击方式**：
- 攻击者监控 mempool，发现有价值的交易（如大额买入）。
- 攻击者以更高 Gas Price 发送一个同类交易，让自己的交易先被矿工打包。
- 攻击者的交易先执行（抢跑），从而获得套利或导致受害者的交易失败。

**防范方法**：
- **滑点保护**：设置可接受的价格偏差范围。
- **Commit-Reveal 方案**：先提交哈希承诺，待交易上链后再揭示实际内容。
- **使用私有 mempool**：通过 Flashbots 等服务，将交易直接发送给矿工而不暴露在公共 mempool 中。
- **使用暗池**：将交易隐藏在暗池中，避免被抢跑。
