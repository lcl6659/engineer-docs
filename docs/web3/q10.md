# Q10：什么是 DeFi（去中心化金融）？它与传统金融（CeFi）有什么区别？

DeFi 是**去中心化金融**的英文缩写，指在以太坊等可编程公有区块链网络上搭建的，以加密货币价值锚定、借贷、互换等类金融活动为功能目标的系列智能合约和应用程序。

**与 CeFi 的主要区别**：
- **CeFi**：依赖银行、交易所等中心化中介，有 KYC/AML 要求，用户委托资产。
- **DeFi**：完全由智能合约执行，无需中介，无需许可，任何人可参与。用户自己保管资产（非托管）。
- **透明性**：DeFi 所有交易可查，CeFi 内部账本不公开。
- **风险**：DeFi 面临智能合约风险和黑客攻击，CeFi 面临挪用资产、平台跑路风险。
