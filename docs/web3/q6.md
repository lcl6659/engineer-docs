# Q6：什么是智能合约？它有什么特点和潜在风险？

智能合约是部署在区块链上的一段**自动执行的代码**，当预设条件被触发时，合约会自动执行约定的条款。

**特点**：
- **自动执行**：无需人工干预，条件满足即触发。
- **去信任化**：无需第三方中介担保，代码即法律。
- **不可篡改**：一旦部署，合约逻辑无法被单方面修改。
- **透明可查**：所有代码和交易记录公开。

**潜在风险**：
- **代码漏洞**：如重入攻击、整数溢出等，最著名的案例是 2016 年 The DAO 事件，攻击者成功窃取了数百万 ETH。
- **逻辑漏洞**：合约业务逻辑设计缺陷。
- **预言机风险**：依赖外部数据源的准确性。
- **法律不确定性**：智能合约的法律地位尚不明确。
- **升级困难**：不可篡改性导致升级困难，或不当升级导致风险。
