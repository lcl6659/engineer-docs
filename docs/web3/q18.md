# Q18：什么是预言机（Oracle）？为什么智能合约需要它？

预言机是将**链下数据传递到链上**的桥梁。由于区块链是封闭系统，智能合约无法直接访问外部世界的数据（如资产价格、天气、比赛结果等），预言机解决了"链上世界与链下世界如何连接"的问题。

**Chainlink** 是最主流的去中心化预言机网络，提供：
- 去中心化数据馈送：为 DeFi 提供价格数据。
- 可验证随机函数（VRF）：提供安全的链上随机数。

**为什么需要预言机**：智能合约的执行逻辑需要外部数据触发（如"ETH 价格低于 1500 时清算抵押仓位"），但合约本身无法直接读取交易所的价格数据，必须通过预言机获取。
