# Q23：什么是去中心化身份（DID）？它如何实现自主身份（SSI）？

去中心化身份标识符（DID）是一种**全球唯一、可加密验证的字符串**，通常记录在区块链等去中心化账本上。与传统身份不同，DID 由用户自行生成，完全摆脱了对单一机构的依赖。

**DID 的格式**遵循 `did:<method>:<unique-identifier>` 结构（如 `did:example:123456789abcdef`），其中 `example` 是所用区块链或协议的方法，`123456789abcdef` 是具体标识符。

DID 的核心理念是**自主身份（SSI）**，其实现方式为：
- **无需中心机构**：DID 完全由用户自己创建和管理，所有注册与更新都在去中心化账本上完成。
- **加密验证机制**：每个 DID 都绑定一对公私钥，用户持有私钥进行签名以证明身份归属，对应的公钥发布在 DID 文档中供第三方验证。
- **DID 文档**：每个 DID 都关联一个包含公钥、验证方法和服务端点的文档，可存储在链上或分布式存储系统中。
- **可验证凭证（VC）**：由可信机构签发的声明，供用户在需要时出示，而无需泄露全部个人信息。

与中心化身份相比，DID 具有安全性更强、跨平台可携带、支持选择性披露等显著优势。
