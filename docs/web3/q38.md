# Q38：Solidity 中的继承和多继承的线性化是如何解决的？

Solidity 使用 **C3 线性化**（类似于 Python）确定方法的搜索顺序。当存在多继承时，必须保证基类合约之间没有菱形冲突，编译器会检查所有直接基类是否有相同的根本基类。

- **关键字**：`is` 继承，`virtual` 允许覆盖，`override` 显式覆盖。
- **菱形问题**：如果 A 继承 B 和 C，B 和 C 又继承 D，则 A 只含一个 D，通过 C3 线性化确定唯一调用顺序。
- **继承顺序**：必须按“最像基类”到“最派生”的顺序排列，例如 `contract A is B, C`，B 比 C 更“基”。
- **抽象合约**：包含未实现的函数（`virtual` 无体），不能实例化，需子合约实现。
