# Q30：什么是 MetaMask？EIP-1193 标准是什么？

**MetaMask** 是以太坊生态最流行的**浏览器扩展钱包**，允许用户在浏览器中管理以太坊账户、签名交易、与 DApp 交互。它充当了用户与区块链之间的桥梁。

**核心功能**：
- 创建/导入以太坊账户（生成/导入私钥和助记词）。
- 连接到不同的以太坊网络（主网、测试网、自定义 RPC）。
- 签署交易并发送到网络。
- 在 DApp 中作为"登录"方式。
- 资产管理和代币显示。

**EIP-1193** 是 JavaScript Ethereum Provider API 标准，定义了钱包与 DApp 之间的通信接口。主要规定：
- `window.ethereum` 作为注入浏览器的 Provider 对象。
- `eth_requestAccounts` 请求连接钱包。
- `eth_chainId` 获取当前网络 ID。
- 事件监听：`accountsChanged`、`chainChanged`。
- 这使得不同钱包（MetaMask、Coinbase Wallet、Trust Wallet 等）可以遵循统一的 API 标准，DApp 无需为每个钱包单独适配。
