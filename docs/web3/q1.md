# Q1：什么是 Web3？与 Web1、Web2 的主要区别是什么？

Web3 是互联网的第三代愿景，核心是基于区块链技术构建一个**去中心化、用户拥有数据主权**的网络。

**三个时代的对比**：
- **Web1（只读）**：静态网页，信息单向流动，用户主要是内容消费者（如早期的门户网站）。
- **Web2（读写）**：动态网页，用户生成内容（UGC），平台中心化，用户数据被平台掌控（如社交媒体、电商）。
- **Web3（读写+拥有）**：基于区块链的去中心化应用（DApps），用户通过私钥拥有数据，强调所有权和治理权。

**核心区别**在于中心化与去中心化、数据所有权归属、经济模式（平台经济 vs 通证经济）。在 Web3 中，用户通过私钥真正拥有自己的数字资产和身份。
