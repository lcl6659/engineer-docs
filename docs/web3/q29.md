# Q29：Web3 前端与传统 Web2 前端开发有哪些不同？

**相同点**：
- 仍使用 React、Vue、Next.js 等主流框架。
- 仍需要关注用户体验、响应式设计、性能优化等。

**不同点**：
- **数据来源**：Web2 从 REST API / GraphQL 读数据，Web3 从区块链直接读取或通过 The Graph 索引读取。
- **身份认证**：Web2 使用邮箱/密码、OAuth；Web3 通过钱包签名认证。
- **交易处理**：Web3 需要处理交易签名、Gas 估算、交易状态跟踪、交易失败处理等。
- **状态管理**：Web3 需要同步链上状态和本地状态，处理交易确认等待时间。
- **安全考虑**：Web3 前端需要防范钓鱼、恶意合约地址等。
- **用户体验**：Web3 存在签名弹窗、交易等待等独特交互模式。
