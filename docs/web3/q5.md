# Q5：什么是以太坊？它和比特币的主要区别是什么？

**以太坊**是一个去中心化的、开源的区块链平台，支持**智能合约**功能。它不仅是数字货币网络，更是一个全球性的去中心化应用平台。

**与比特币的主要区别**：
- **比特币**：主要作为数字黄金和价值储存手段，功能相对单一（点对点电子现金系统）。
- **以太坊**：支持智能合约和去中心化应用（DApps），是一个可编程的区块链平台。
- **账户模型**：比特币使用 UTXO 模型，以太坊使用账户/余额模型。
- **出块时间**：比特币约 10 分钟，以太坊约 12-14 秒。
- **编程语言**：以太坊智能合约主要使用 Solidity 编写。
