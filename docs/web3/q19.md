# Q19：什么是去中心化存储？IPFS 和 Arweave 有什么区别？

去中心化存储通过分布式网络架构提供抗审查、高冗余的数据存储方案。

**IPFS（星际文件系统）** 是一个去中心化的文件存储和分发协议，通过**内容寻址**（Content Addressing）而非位置寻址来定位文件。相同内容的文件永远有相同的哈希值，这在技术上保证了内容的不可篡改性。在 Web3 开发中，IPFS 主要用于存储 NFT 元数据、前端静态资源和各类应用数据。

**关键区别**：
- **存储持久性**：IPFS 本身不保证文件永久存在，需要节点主动 Pin 住内容；Arweave 通过一次性支付实现永久存储。
- **经济模型**：IPFS 的激励层 Filecoin 基于存储合约；Arweave 基于永久存储捐赠模型。
- **适用场景**：IPFS 更适合动态更新的数据，Arweave 适合永久存档（如历史记录、NFT 永久元数据）。
