# Q35：如何实现可升级合约？透明代理和 UUPS 模式有何区别？

可升级合约通过**代理模式**实现，代理合约持有状态，逻辑合约通过 `delegatecall` 执行。

**透明代理（Transparent Proxy）**：
- 代理合约同时处理升级和管理员调用，普通用户和 admin 调用路径不同。
- 升级、管理功能仅 admin 可调用，普通调用全部委托给实现合约。
- 实现简单，但每次调用需检查 `msg.sender == admin` 增加 Gas。

**UUPS（Universal Upgradeable Proxy Standard）**：
- 升级逻辑放在实现合约中，而非代理。代理仅委托并调用实现合约内的升级函数。
- 更轻量（代理合约更小），但实施稍复杂，需确保实现合约始终包含升级函数。

**共同注意**：
- 使用标准存储槽（EIP-1967）避免冲突。
- 初始化使用初始化器而非构造函数（代理的构造函数不会影响存储）。
- 使用 OpenZeppelin 的 `ProxyAdmin` 管理。
