# Q43：什么是 zkEVM？它有哪些类型？

zkEVM（Zero-Knowledge Ethereum Virtual Machine）是在 ZK-Rollup 中完全兼容 EVM 的执行环境，能够在保持兼容性的同时生成有效性证明。

**类型划分**（按与 EVM 兼容程度）：
1. **完全等效（Type 1）**：完全兼容 EVM（所有操作码、预编译、存储结构），如 Taiko、Scroll。
2. **字节码等效（Type 2）**：兼容 EVM 字节码，但修改了部分数据结构（如状态根），如 Polygon zkEVM。
3. **语言等效（Type 3）**：支持 Solidity 等高级语言，但可能修改部分操作码和 gas 模型。
4. **自定义 zkVM（Type 4）**：完全不兼容 EVM，使用自定义虚拟机，如 StarkNet 的 Cairo。

当前趋势是追求更高兼容性的 Type 1/2，以方便现有 DApp 迁移。
