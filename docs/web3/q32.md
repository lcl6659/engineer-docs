# Q32：`delegatecall` 是什么？它的用途和风险？

`delegatecall` 是一种特殊的合约调用，它在**调用者合约的上下文中**执行被调用合约的代码。这意味着被调用合约的代码可以使用调用者合约的存储、`msg.sender` 和 `msg.value`。

**主要用途**：
- **可升级合约**：代理合约通过 `delegatecall` 将逻辑委托给实现合约，从而可更换逻辑而保持存储不变。
- **库（Library）**：合约库代码通过 `delegatecall` 在调用者的存储空间中执行。

**风险**：
- **存储冲突**：若被调用合约的存储布局与调用者不一致，会覆盖或破坏关键数据。
- **安全隐患**：可能引入恶意代码，所以必须谨慎控制被调用合约地址。
- **状态污染**：被调合约可以任意修改调用者合约的状态。

**防范**：使用透明的代理模式（如 EIP-1967）和升级管理工具（OpenZeppelin Upgrades），确保存储槽位不冲突。
