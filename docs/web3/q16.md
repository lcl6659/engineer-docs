# Q16：什么是重入攻击（Reentrancy Attack）？如何防范？

当合约在更新其状态之前对另一个合约进行外部调用时，就会发生重入攻击。被调用的合约可以回调到原始合约，导致重复执行某些逻辑（如反复提款）。

**经典案例**：2016 年 The DAO 事件，攻击者利用 `withdraw` 函数中先发送 ETH 后更新余额的逻辑漏洞，重复调用 `withdraw` 窃取约 360 万 ETH。

**防范方法**：
1. **检查-效果-交互（Checks-Effects-Interactions）模式**：先更新状态，再与外部合约交互。
2. **使用重入锁（ReentrancyGuard）**：`nonReentrant` 修饰器。
3. **避免使用 `call.value`**：使用 `transfer` 或 `send`（有 Gas 限制，但当前不建议）。
4. **Pull over Push**：让用户主动提取资金，而非合约发送资金。
