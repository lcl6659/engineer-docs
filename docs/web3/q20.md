# Q20：什么是零知识证明（ZKP）？在区块链中有什么应用？

零知识证明是一种密码学技术，允许一方（证明者）向另一方（验证者）证明某个陈述为真，而**不透露任何超出该陈述真实性之外的信息**。

**核心特性**：
- **完整性**：如果陈述为真，诚实的证明者可以说服验证者。
- **可靠性**：如果陈述为假，任何证明者都无法欺骗验证者。
- **零知识性**：验证者除了知道陈述为真外，不获得任何其他信息。

**区块链应用**：
- **隐私交易**：隐藏交易金额和地址（如 Zcash）。
- **ZK-Rollups**：Layer 2 扩容方案，通过 ZKP 验证链下交易的有效性（如 zkSync、StarkNet）。
- **去中心化身份（DID）**：证明年龄、国籍等属性而不泄露具体信息。
- **隐私投票**：DAO 治理中的匿名投票。
