# Q56：ERC-4337（账户抽象）的核心原理（已在 Web3 部分提及，此处补充技术细节）

ERC-4337 引入 **UserOperation** 和 **Bundler**。

- **UserOperation**：伪交易对象，包含 `sender`、`nonce`、`initCode`、`callData`、`gasLimits`、`paymasterAndData` 等字段。
- **Bundler**：类似区块构建者，从 UserOperation 内存池中选择打包，通过 EntryPoint 合约执行。
- **EntryPoint**：单一执行合约，处理验证和付款。
- **Paymaster**：可赞助 gas，允许第三方支付交易费用。
- **验证与执行分离**：`validateUserOp` 验证账户，`execute` 执行操作，这允许自定义验证逻辑。
