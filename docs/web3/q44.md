# Q44：ZK-Rollup 的交易流程是怎样的？

1. **用户提交交易**：将交易发送到 L2 的排序器（Sequencer，可能是中心化的）。
2. **排序与打包**：排序器按顺序执行交易，生成 L2 状态根和批次数据。
3. **证明生成**：Prover（证明者）根据批次数据生成有效性证明（如 zk-SNARK）。
4. **提交到 L1**：排序器（或中继）将交易数据（calldata）和有效性证明提交到 L1 的 Rollup 合约。
5. **L1 验证**：Rollup 合约验证证明和状态转换。证明有效则更新 L1 上的状态根。
6. **最终确认**：一旦 L1 区块被确认，L2 状态更新即被最终确认。
