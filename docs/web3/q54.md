# Q54：ERC-4626 是什么？解决什么问题？

### ERC 常见协议（扩展）

ERC-4626 是**收益代币的金库标准**，扩展了 ERC-20，为收益聚合器、借贷协议等提供统一的 API。

- **核心功能**：`deposit`、`redeem`、`withdraw`、`mint` 等，以及用于预览功能的 `previewDeposit` 等方法。
- **资产（asset）**：金库管理的底层代币。
- **份额（shares）**：代表金库中份额的代币（通常 ERC-20）。
- **解决的问题**：不同 DeFi 协议的金库操作差异巨大，ERC-4626 简化了集成，前端可以轻松添加任意遵循标准的金库。
