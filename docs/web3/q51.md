# Q51：LayerZero 是如何实现全链互操作性的？其安全假设是什么？

LayerZero 是一个全链互操作协议，通过**超轻节点**和独立的预言机/中继器架构实现跨链通信。

- **工作原理**：
  - 用户应用（UA）在源链上调用 LayerZero 终端发送消息。
  - LayerZero 依赖两个外部实体：**预言机**（如 Chainlink）转发区块头，**中继器**转发交易证明。
  - 目标链的端点验证区块头和交易证明匹配，然后执行消息。
- **安全假设**：假设预言机和中继器不会勾结作恶。用户可以选择信任的组合。
- **优势**：支持任意链快速集成，无需运行全节点，轻量高效。
- **挑战**：依赖外部预言机，可能存在勾结风险。LayerZero 通过不可升级的端点合约来部分缓解。
