# Q37：`assembly` 和内联汇编在 Solidity 中如何使用？有什么风险？

内联汇编允许在 Solidity 中嵌入 **Yul**（中间语言），直接操作 EVM 字节码级别的操作（内存、存储、调用等）。

**用途**：
- 极端 Gas 优化（绕过 Solidity 安全检查）。
- 直接使用 EVM 特性：`create2`、`mload`、`sstore`、`calldatacopy` 等。
- 实现 Solidity 难以实现的低级功能。

**风险**：
- 绕过 Solidity 类型安全检查，易引入漏洞。
- 操作栈、内存、存储需手动管理，错误可能导致静默破坏数据。
- 代码可读性差，维护困难。
- 必须配合详细文档和严格测试。

示例（用 `return` 部分数据）：
```solidity
function getBytes(uint offset, uint length) public view returns (bytes memory) {
    bytes memory result = new bytes(length);
    assembly {
        calldatacopy(add(result, 0x20), offset, length)
        return(0, add(add(result, 0x20), length))
    }
}
```
