# Q36：Solidity 中的事件（Event）和日志（Log）的原理与索引

事件是 Solidity 提供的日志功能，用于将数据记录在区块链交易收据中。事件数据存储在交易日志中，不存储在合约存储中，因此更便宜。

- **声明**：`event Transfer(address indexed from, address indexed to, uint256 value);`
- **触发**：`emit Transfer(msg.sender, to, amount);`
- **索引参数**：最多三个参数可标记 `indexed`，它们会被哈希并存入日志的 topics 数组，方便链下过滤。非索引参数存于 data 部分。
- **用途**：前端监听事件更新 UI、The Graph 索引事件构建查询、链下监控。
- **成本**：事件比存储便宜，但不可以从合约内部读取（仅链下使用）。
