# Q4：什么是共识机制？PoW 和 PoS 有什么区别？

共识机制是区块链网络中所有节点对数据状态达成一致的规则。

**工作量证明（PoW）**：
- 矿工通过解决复杂的数学问题竞争记账权，首先找到解的矿工获得奖励。
- 优点：安全性极高，经历长期验证。
- 缺点：能源消耗大，交易处理速度慢。
- 代表：比特币。

**权益证明（PoS）**：
- 验证者根据其持有的加密货币数量被随机选择来创建区块。
- 优点：能源消耗极低，交易速度更快，更环保。
- 缺点：可能存在"富人更富"的担忧。
- 代表：以太坊（2022 年合并后从 PoW 转向 PoS）。

**关键区别**：PoW 靠算力竞争，PoS 靠资产质押竞争。PoS 不需要大量硬件和电力，因此更可持续。
