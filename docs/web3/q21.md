# Q21：什么是账户抽象（Account Abstraction，ERC-4337）？

账户抽象（ERC-4337）是一种让用户能够使用**智能合约钱包**作为主账户的提案，将账户的控制逻辑与签名验证解耦，在不改变共识层的情况下实现账户抽象。

ERC-4337 的核心创新在于引入了一个名为 **UserOperation** 的伪交易对象和一个独立的 **Bundler**（打包者）层。UserOperation 不会被广播到公共 mempool，而是被发送到专用的 Alt Mempool，由 Bundler 进行捆绑和验证，然后通过单一的入口点合约（EntryPoint）提交到区块链上执行。

**带来的好处**：
- **社交恢复**：丢失私钥可通过预先设置的方式恢复账户。
- **gas 代付**：DApp 可以替用户支付 gas 费，降低新用户的进入门槛。
- **批量交易**：一笔交易中执行多个操作。
- **自定义签名算法**：不限于 ECDSA 签名，可使用手机、硬件安全模块等更方便的方式签名。
- **定期支付**：设置定期自动扣款。
