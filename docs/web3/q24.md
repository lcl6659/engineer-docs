# Q24：DApp 常见的技术栈是什么？常用的开发工具和框架有哪些？

一个典型的 Web3 DApp 技术栈包括：

**智能合约开发**：
- **语言**：Solidity（以太坊）、Rust（Solana/NEAR）
- **框架**：Hardhat、Foundry、Truffle
- **测试**：Hardhat Test、Foundry Test、Waffle

**前端开发**：
- **框架**：React / Next.js、Vue
- **区块链交互**：Ethers.js、Web3.js、Viem、Wagmi
- **钱包集成**：RainbowKit、Web3Modal、ConnectKit

**后端与数据**：
- **节点服务**：Infura、Alchemy、QuickNode
- **数据索引**：The Graph（Subgraph）
- **去中心化存储**：IPFS、Arweave
- **预言机**：Chainlink

**开发流程**：编写合约 → 编译 → 部署到测试网 → 前端交互 → 测试 → 审计 → 主网上线。
