# Q9：ERC-20、ERC-721、ERC-1155 分别是什么？有什么区别？

- **ERC-20（同质化代币标准）**：所有代币完全相同，可互换。如 USDT、UNI、LINK。核心函数：`transfer`、`approve`、`transferFrom`、`balanceOf`、`totalSupply`。
- **ERC-721（非同质化代币标准 / NFT）**：每个代币独一无二，不可互换。每个 Token 有唯一的 `tokenId`。如 CryptoKitties、Bored Ape Yacht Club。
- **ERC-1155（多代币标准）**：一个合约可以同时管理同质化代币、非同质化代币和半同质化代币。更节省 Gas，支持批量转账。常用于游戏道具等场景。

**区别总结**：ERC-20 是同质化的（每个代币一样），ERC-721 是非同质化的（每个独一无二），ERC-1155 是混合标准，两者都支持。
