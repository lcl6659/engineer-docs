# Q13：命名空间（Namespace）与模块的区别

- **命名空间**（`namespace`，原名内部模块）：用于组织全局代码，避免全局作用域污染。可通过 `/// <reference path="..." />` 引入。

  ```typescript
  namespace Util {
    export function log(msg: string) { console.log(msg); }
  }
  ```

- **模块**（ESModules / CommonJS）：文件级别的代码隔离，使用 `import` / `export`。是组织代码的主要方式。

现代 TypeScript 推荐使用 ES 模块，命名空间主要用于声明文件或遗留项目。
