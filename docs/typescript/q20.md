# Q20：模板字面量类型（Template Literal Types）

TypeScript 4.1 新增，允许像字符串模板一样构造类型。

```typescript
type World = 'world';
type Greeting = `hello ${World}`; // "hello world"
```

- 可与联合类型组合，构造事件名等精确字符串类型，例如：

```typescript
type EventName = `on${Capitalize<string>}`;
```

- 内置字符串工具类型：`Uppercase<T>`、`Lowercase<T>`、`Capitalize<T>`、`Uncapitalize<T>`。
- 用于精确类型化和约束，如 CSS 属性名、事件名。
