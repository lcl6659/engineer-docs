# Q1：什么是 TypeScript？它和 JavaScript 的关系是什么？带来了哪些好处？

TypeScript 是 JavaScript 的一个**超集**，在 JS 的基础上增加了静态类型系统。任何合法的 JavaScript 代码也是合法的 TypeScript 代码（有时需调整配置）。

**核心优势**：
- **静态类型检查**：在编译阶段就能发现类型错误，避免许多运行时 bug。
- **强大的代码提示与自动补全**：IDE 支持大幅提升开发效率。
- **大型项目可维护性**：类型即文档，重构更安全。
- **面向对象编程增强**：接口、泛型、装饰器等特性让架构设计更清晰。
- **逐步采用**：可以按文件渐进式迁移，也可与 JS 项目共存。

TypeScript 最终会被编译为纯 JavaScript，不改变运行时行为。
