# Q6：联合类型和交叉类型是什么？如何使用？

- **联合类型 (`|`)**：值可以是几种类型中的任一种。
  ```typescript
  let value: string | number;
  value = 'hello'; // ok
  value = 100;     // ok
  ```

- **交叉类型 (`&`)**：同时合并多个类型的所有属性。
  ```typescript
  interface A { a: string }
  interface B { b: number }
  type C = A & B; // { a: string; b: number }
  ```

交叉类型常用于 `mixins` 或组合类型。
