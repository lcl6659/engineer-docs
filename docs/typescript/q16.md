# Q16：TypeScript 中的“严格模式”包含了哪些检查？

在 `tsconfig.json` 中启用 `"strict": true` 会一次性开启以下所有规则：

- `strictNullChecks`：不允许 `null`/`undefined` 赋值给其他类型（除非显式联合）。
- `noImplicitAny`：禁止隐式 `any`。
- `strictFunctionTypes`：更严格的函数类型兼容性检查。
- `strictBindCallApply`：对 `bind`/`call`/`apply` 参数严格检查。
- `strictPropertyInitialization`：确保类属性在构造函数中初始化（影响 `--strictNullChecks`）。
- `noImplicitThis`：禁止 `this` 隐含 `any`。
- `alwaysStrict`：在生成代码中添加 `'use strict'`。
