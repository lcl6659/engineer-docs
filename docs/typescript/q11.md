# Q11：TypeScript 中类的使用以及访问修饰符

```typescript
class Animal {
  public name: string;      // 公有，默认
  private age: number;      // 仅本类访问
  protected type: string;   // 本类及子类访问
  readonly species: string; // 只读，不可修改
  constructor(name: string) { this.name = name; }
}
```

- TS 为类提供了完整的 ES6+ 支持加上类型。
- 抽象类 `abstract class` 不能直接实例化，可定义抽象方法，子类必须实现。
- 可配合接口 `implements` 保证类符合特定结构。
