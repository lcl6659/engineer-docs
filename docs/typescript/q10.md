# Q10：`keyof` 和 `typeof` 在类型层面的使用

- **`keyof T`**：获取 `T` 所有属性名组成的联合类型。
  ```typescript
  interface User { name: string; age: number }
  type UserKeys = keyof User; // 'name' | 'age'
  ```

- **`typeof`（类型查询）**：在 TS 中可用于获取已有变量或值的类型。
  ```typescript
  let obj = { a: 1, b: 'hello' };
  type ObjType = typeof obj; // { a: number; b: string }
  ```

常常一起用于动态约束，如泛型约束：`` `<T, K extends keyof T>` ``。
