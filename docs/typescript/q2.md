# Q2：TypeScript 的基本类型有哪些？

- **原始类型**：`string`、`number`、`boolean`、`null`、`undefined`、`symbol`、`bigint`。
- **特殊类型**：`any`（跳过类型检查）、`unknown`（安全版的 any）、`void`（无返回值）、`never`（永不存在的值）。
- **对象类型**：`object`、`array`（`number[]` 或 `Array<number>`）、`tuple`（元组 `[string, number]`）。
- **枚举**：`enum`（数字枚举、字符串枚举）。
- **联合类型**：`string | number`。
- **函数类型**：`(a: number) => void`。
