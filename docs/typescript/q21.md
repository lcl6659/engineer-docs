# Q21：类型兼容性 —— 结构化类型（鸭子类型）

TypeScript 使用结构化类型系统，比较的是形状（结构），而不是声明的名字。

```typescript
interface Point { x: number; y: number }
let p: Point = { x: 1, y: 2 };
let s = { x: 1, y: 2, z: 3 };
p = s; // ✅ OK，因为 s 至少包含 x 和 y
```

- 对象类型检查是“至少匹配”。
- 函数兼容性检查参数（双变 or 协变，取决于 strictFunctionTypes）和返回值（协变）。
- 类兼容性也按结构，但 private/protected 成员会要求来自同一声明。
