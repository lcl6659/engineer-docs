# Q7：泛型（Generics）是什么？有哪些用法？

泛型允许在声明时不指定具体类型，而是在使用时传入，实现可复用的组件/函数。

**基础示例**：
```typescript
function identity<T>(arg: T): T {
  return arg;
}
identity<string>('hello');
```

**常见应用**：
- 泛型接口：`interface ApiResponse<T> { data: T }`
- 泛型类：`class Stack<T> { ... }`
- 泛型约束：`<T extends HasLength>` 限制类型必须有指定属性。
- 在 React 中用的 `useState<string>()`。
