# Q18：装饰器是什么？有哪些类型？

装饰器是**实验性**特性（需开启 `experimentalDecorators`），用于类、方法、属性、参数上添加元数据或修改行为，本质是一个特殊函数。

- **类装饰器**：`function sealed(target: Function) {}`
- **方法装饰器**：`function log(target, propertyKey, descriptor) {}`
- **属性装饰器**：观测属性
- **参数装饰器**：在依赖注入中标识参数

常用库：`reflect-metadata` 实现元编程，Angular 大量使用，Next.js 也用类装饰器（如 `@Bind`）。由于 JS 原生装饰器 Stage 3 变动，可能需要关注最新标准。
