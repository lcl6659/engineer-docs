# Q19：`as const` 断言的作用

`as const` 使 TypeScript 推断出最窄的字面量类型，且所有属性标记为 `readonly`。

```typescript
const config = {
  api: 'https://api.example.com',
  retry: 3
} as const;
// 类型：{ readonly api: "https://api.example.com"; readonly retry: 3 }
```

- 不再被推断为 `{ api: string; retry: number }`，而是精确字面量。
- 适用于常量配置、Redux action type 等需要精确类型推断的场景。
- 常与 `typeof` 结合生成状态机类型。
