# Q14：`tsconfig.json` 中的核心配置项有哪些？

- `compilerOptions`：
  - `target`：编译目标 JS 版本（ES5、ES6 等）。
  - `module`：模块系统（CommonJS、ESNext）。
  - `strict`：开启所有严格检查。
  - `outDir` / `rootDir`：输出与源码目录。
  - `esModuleInterop`：允许默认导入 CommonJS 模块。
  - `skipLibCheck`：跳过声明文件检查提效。
  - `paths` + `baseUrl`：路径别名。
  - `declaration`：生成 `.d.ts` 文件。
- `include` / `exclude` / `files`：指定编译范围。
- `moduleResolution`：模块解析策略（`node` / `classic` / `bundler`）。
