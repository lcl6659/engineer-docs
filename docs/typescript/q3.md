# Q3：`interface` 和 `type` 的主要区别

| 区别点 | `interface` | `type` |
|-------|------------|--------|
| 声明合并 | 同名接口自动合并 | 类型别名不可重复 |
| 扩展方式 | `extends` 继承 | 使用交叉类型 `&` |
| 可用范围 | 主要用于描述对象形状 | 可表示联合类型、元组、基本类型别名 |
| 实现 | 类可以 `implements` 接口 | 类不能 `implements` 联合类型 |
| 计算属性 | 无法 | 可以使用 computed 值 |

**建议**：优先使用 `interface` 描述对象形状，用 `type` 表示联合、交叉或复杂类型别名。
