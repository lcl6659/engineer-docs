# Q9：映射类型（Mapped Types）和条件类型（Conditional Types）

- **映射类型**：基于已有类型创建新类型，遍历属性并修改。
  ```typescript
  type Readonly<T> = { readonly [P in keyof T]: T[P] };
  type Partial<T> = { [P in keyof T]?: T[P] };
  ```
  结合 `+`、`-` 修饰符控制只读、可选等。

- **条件类型**：`T extends U ? X : Y`，根据类型关系选择分支。
  ```typescript
  type IsString<T> = T extends string ? true : false;
  type Extract<T, U> = T extends U ? T : never;
  ```

**内置工具类型**多是这两种类型的应用（`Partial`、`Required`、`Readonly`、`Pick`、`Omit`、`Record`、`Exclude`、`Extract`、`NonNullable`、`ReturnType`、`Parameters` 等）。
