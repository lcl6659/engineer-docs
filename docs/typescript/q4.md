# Q4：`any`、`unknown`、`never` 和 `void` 的区别

- **`any`**：关闭类型检查，可赋值给任何类型，也可接受任何类型，不安全，应尽量避免。
- **`unknown`**：安全的 top type。任何值都可赋值给 `unknown`，但 `unknown` 只能赋值给 `any` 或 `unknown`，除非经过类型守卫或断言。
- **`never`**：表示永远不会到达的代码路径（如抛出异常的函数、死循环），或是永远为空的联合类型类型；是 bottom type，可赋值给任何类型，但没有任何类型可赋给 `never`（除了 `never` 本身）。
- **`void`**：函数无返回值，严格模式下只接受 `undefined`。
