# Q8：类型守卫（Type Guards）有哪些方式？

用于在条件块内缩小变量的联合类型范围：

- **`typeof`**：`typeof value === 'string'`
- **`instanceof`**：`value instanceof Date`
- **`in`**：`'property' in obj`
- **字面量检查**：`if (x.type === 'success')`
- **自定义类型谓词**：
  ```typescript
  function isFish(pet: Fish | Bird): pet is Fish {
    return (pet as Fish).swim !== undefined;
  }
  ```
- **断言函数**（TypeScript 3.7+）：`asserts value is string`
