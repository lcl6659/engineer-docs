# Q9：Vue Router 的导航守卫有哪些？

导航守卫用于在路由切换时进行拦截、权限控制、数据预载等。

**全局守卫**：
- `beforeEach(to, from, next)`：全局前置守卫，常用于身份验证。
- `beforeResolve(to, from, next)`：解析守卫，在组件内守卫和异步路由组件解析之后调用。
- `afterEach(to, from)`：全局后置钩子，无 `next`，适合做页面标题修改等。

**路由独享守卫**：
- `beforeEnter(to, from, next)`：在路由配置中直接定义。

**组件内守卫**（选项式 API）：
- `beforeRouteEnter(to, from, next)`：在进入组件前调用，获取不到 `this`。
- `beforeRouteUpdate(to, from, next)`：同一组件被复用时（如动态路由参数变化）。
- `beforeRouteLeave(to, from, next)`：离开当前组件前，可用于保存表单等。
