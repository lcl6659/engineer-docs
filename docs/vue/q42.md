# Q42：`tsconfig.json` 中重要的编译选项

- `target`：编译后的 ECMAScript 版本。
- `module`：模块系统（ESNext / CommonJS）。
- `strict`：开启所有严格检查。
- `esModuleInterop`：允许 `import` 导入 CommonJS 模块。
- `skipLibCheck`：跳过声明文件类型检查，提升速度。
- `paths` + `baseUrl`：配置路径别名。
- `outDir` / `rootDir`：输出目录和源码根目录。
- `include` / `exclude`：指定编译范围。
- `declaration`：生成 `.d.ts` 声明文件。
- `moduleResolution`：模块解析策略（`node` / `bundler`）。
