# Q22：Vue 虚拟 DOM 的 Diff 算法是如何工作的？

Vue 遵循虚拟 DOM 的同层比较原则，采用**深度优先、双端比较**算法，减少时间复杂度。

**同层节点比较流程**：

1.  **优先处理简单的头尾比较**：  
    Vue 为旧子节点数组和新子节点数组各设置 4 个指针：`oldStartIdx`、`oldEndIdx`、`newStartIdx`、`newEndIdx`。依次进行 4 种判断：
    - 旧头 vs 新头（复用，指针后移）
    - 旧尾 vs 新尾（复用，指针前移）
    - 旧头 vs 新尾（复用，旧头移动到尾部）
    - 旧尾 vs 新头（复用，旧尾移动到头部）

2.  **无法匹配时使用 key 建立映射表**：  
    若以上四种都不匹配，为新头节点在旧节点列表中按 `key` 查找相同节点。找到则移动其位置并复用；找不到则新建节点插入。

3.  **收尾**：  
    指针相遇后，多余的新节点批量添加，多余的旧节点批量删除。

这种双端比较结合 key 查找的方式，能将常见列表变动（顺序调换、新增、删除）的复杂度控制在 O(n)。
