# Q21：Vue 的模板编译过程是怎样的？

Vue 模板编译是将模板字符串转换为渲染函数的过程，主要在构建阶段（使用 `vue-loader` 或 `vue-template-compiler`）或运行时（仅完整版含编译器）执行。

**流程分三步**：

1.  **解析（parse）**  
    将模板字符串通过正则表达式进行词法分析，切割为 Token 流（开始标签、结束标签、文本、属性等），然后生成 AST（抽象语法树）。这个过程会记录指令、属性、插值表达式等信息。

2.  **优化（optimize）** — Vue 2 标记静态节点  
    遍历 AST，标记所有静态节点（不依赖响应式数据，不会改变的节点）。这样在 Diff 时可以跳过静态子树比较，提升性能。Vue 3 更进一步，使用了补丁标记（Patch Flags）和静态提升等优化。

3.  **代码生成（code generation）**  
    将优化后的 AST 转换为可执行的代码字符串，如 `render` 函数。Vue 2 生成类似 `with(this){ return _c('div', ...) }` 的函数，而 Vue 3 生成更高效的 `createVNode` 调用。最终渲染函数会被缓存，数据变化时重新执行生成新虚拟 DOM。
