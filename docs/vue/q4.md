# Q4：Vue 组件间通信的方式有哪些？

1. **props / emits**（父子通信）：父传子通过 props，子传父通过 `$emit` 触发事件。
2. **v-model**：父子组件双向绑定的语法糖，结合 props `modelValue` 和 emits `update:modelValue` 实现。
3. **ref**：父组件通过 `ref` 获取子组件实例，直接调用其方法或访问数据。
4. **provide / inject**：祖先组件提供数据，所有后代组件都可注入使用，适合跨层级传递。
5. **事件总线**（Vue 2 常用 `$bus`）：利用 Vue 实例作为中央事件总线，适合任意组件通信。Vue 3 推荐使用第三方库如 `mitt`。
6. **Vuex / Pinia**：全局状态管理，适合复杂应用的共享状态。
7. **`$attrs` 和 `$listeners`**（Vue 2）：传递未在 props 中声明的属性和事件监听器。Vue 3 移除了 `$listeners`，统一到 `$attrs`。
8. **`<slot>` 插槽**：父组件向子组件插入内容，实现内容分发。
