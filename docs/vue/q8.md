# Q8：Vue Router 的路由模式和原理

Vue Router 支持三种模式：

- **Hash 模式**：`createWebHashHistory()`。URL 中以 `#` 开头，`#` 后的部分不会发送到服务端，易于部署。通过 `hashchange` 事件监听路由变化。
- **History 模式**：`createWebHistory()`。利用 HTML5 History API（`pushState`、`replaceState`）实现无刷新的 URL 跳转。需要服务端配置，把所有路径 fallback 到 `index.html`，避免 404。
- **Memory 模式**：`createMemoryHistory()`。不操作 URL，适合 Node 环境和 SSR。

**路由工作原理**：  
当 URL 变化时（Hash 变化或 History push），Vue Router 会匹配到对应的路由配置，渲染指定组件到 `<router-view>`。
