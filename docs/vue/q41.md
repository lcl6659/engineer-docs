# Q41：常见工具类型（Utility Types）的使用

- `Partial<T>`：所有属性变为可选。
- `Required<T>`：所有属性变为必选。
- `Readonly<T>`：所有属性变为只读。
- `Pick<T, K>`：从 T 选择一部分属性。
- `Omit<T, K>`：从 T 剔除一部分属性。
- `Record<K, T>`：构造一个对象类型，键为 K，值类型为 T。
- `Exclude<T, U>` → 从联合类型排除 U。
- `Extract<T, U>` → 提取可赋值给 U 的联合成员。
- `NonNullable<T>` → 排除 null/undefined。
- `ReturnType<T>` → 获取函数返回类型。
- `Parameters<T>` → 获取函数参数元组。
