# Q13：`ref` 与 `reactive` 的区别与使用场景

| 对比点 | `ref` | `reactive` |
|-------|-------|------------|
| 包装类型 | 可包装**任意类型**（原始值用 `.value` 包装） | 只能包装对象（数组也可） |
| 访问方式 | `.value` 获取/修改 | 直接访问属性，无需 `.value` |
| 模板解包 | 模板中自动解包 `.value` | 直接使用 |
| 解构问题 | 解构后仍可保持响应性（需搭配 `toRefs`） | 直接解构会失去响应性 |
| 原理 | 内部也是通过 `reactive` 实现（对对象） | 基于 Proxy，深度响应式 |

**建议**：当需要原始类型或需要重新赋值整个值时用 `ref`；处理对象且希望对属性直接操作时用 `reactive`。一般单值用 `ref` 足够灵活。
