# Q1：Vue 的核心特性有哪些？

Vue 是一款渐进式 JavaScript 框架，核心特性包括：

- **响应式数据绑定**：数据变化时视图自动更新，通过响应式系统追踪依赖。
- **组件化**：UI 拆分为可复用的组件，每个组件拥有自己的视图、数据和逻辑。
- **虚拟 DOM**：在内存中维护虚拟节点树，通过高效的 Diff 算法最小化真实 DOM 操作。
- **模板语法**：提供声明式的模板语法，将 DOM 绑定到底层数据，也支持 JSX。
- **指令系统**：`v-if`、`v-for`、`v-model` 等指令简化常见操作。
- **渐进式**：可以逐步采用，从简单的库到完整的生态（路由、状态管理、SSR 等）。
- **组合式 API**：更好的逻辑复用和代码组织方式。
