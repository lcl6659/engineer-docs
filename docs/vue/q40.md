# Q40：类型守卫（Type Guards）有哪些方式？

类型守卫能缩小变量的联合类型范围：

- **`typeof`**：`typeof value === 'string'`
- **`instanceof`**：`value instanceof Date`
- **`in`**：`'name' in obj`
- **自定义类型谓词**：函数返回 `value is SomeType`，如 `function isCat(animal: Animal): animal is Cat { ... }`
- **相等性**：`if (x.y !== undefined)`
- **字面量判断**：`if (x.type === 'success')`
