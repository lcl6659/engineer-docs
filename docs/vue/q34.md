# Q34：Tree Shaking 的原理和实现条件

Tree Shaking 指移除 JavaScript 中未引用的代码（dead code）。

**原理**：  
ESM 的 `import`/`export` 是静态的，编译时就能分析出哪些导出被使用，哪些未使用。打包工具（Webpack/Rollup）结合压缩工具（Terser），将未使用的导出标记为无用并删除。

**条件**：
- 必须使用 ES Modules 语法（不能混用 CommonJS）。
- 代码必须开启生产模式（`mode: 'production'`），启用压缩和副作用标记。
- 在 `package.json` 中声明 `"sideEffects": false` 或指定有副作用的文件列表，避免工具误删必要的代码（如 polyfill、CSS 引入）。
