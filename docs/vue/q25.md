# Q25：Vue 3 响应式系统深入解析：`reactive`、`ref`、`effect` 的原理

Vue 3 基于 `Proxy` 和 `Reflect` 实现响应式。

- **`reactive(obj)`**：  
  内部用 `Proxy` 包裹对象，在 `get` 时调用 `track()` 收集依赖（当前激活的 `effect`），在 `set` 和 `deleteProperty` 时调用 `trigger()` 通知依赖更新。采用懒代理，嵌套对象在访问时才会递归包裹成 `reactive`。

- **`ref(rawValue)`**：  
  内部创建了一个对象，包含 `get value()` 和 `set value()`，本质是对基本类型值的包装。如果 `rawValue` 是对象，会调用 `reactive` 处理。同样会在 `get` 时 `track`，`set` 时 `trigger`。

- **`effect(fn)`**：  
  创建一个副作用函数，函数执行时，所有被访问的响应式数据都会将其作为依赖收集。当依赖变化时，副作用被重新执行。Vue 的组件渲染函数本身就是一个 `effect`，因此数据变 -> 视图自动更新。

这种依赖追踪是自动、精确的，只触发真正用到的组件更新。
