# Q26：计算属性 `computed` 的缓存机制是如何实现的？

`computed` 接收一个 getter 函数，返回一个只读的响应式 `ref` 对象。

- 内部维护 `_value`（缓存结果）和 `_dirty`（标志缓存是否失效）。
- 首次获取 value 或依赖变化时，`_dirty` 为 `true`，执行 getter 得到新值，并重置 `_dirty` 为 `false`。
- 当依赖的数据触发 `set` 时，它会将 `_dirty` 置为 `true` 并通知 `computed` 的依赖更新，但并不立即计算，直到下次访问 value 时才重新计算。
- 多次访问只要依赖未变，均直接返回 `_value`，体现了缓存的特性。这比普通方法更高效，避免不必要的计算。
