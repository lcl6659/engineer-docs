# Q35：Source Map 的作用和常见类型

Source Map 建立一个映射关系，将打包压缩后的代码对应到源代码，方便调试。

常见类型（webpack `devtool`）：
- **`eval`**：每个模块用 `eval()` 执行，末尾带 `//# sourceURL`，速度快，但无法准确对应行列。
- **`cheap-module-source-map`**：生成不带列信息的 source map，仅定位到行，构建快，适合开发。
- **`source-map`**：生成完整的 `.map` 文件，定位精准，构建最慢，适合生产（可仅用于错误上报）。
- **`hidden-source-map`**：生成 map 但不引用，通常上传到监控平台。
