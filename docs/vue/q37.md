# Q37：HMR（热模块替换）的原理

HMR 能够在应用运行时替换、添加、删除模块，无需完全刷新页面。

**Webpack HMR 流程**：
- Webpack Dev Server 启动时，注入一个 HMR runtime 到客户端。
- 源码变化时，Webpack 重新编译产生更新的模块（增量更新），并通过 WebSocket 推送 `hash` 事件。
- 客户端请求 `manifest`（记录变更模块列表），然后拉取变更的模块代码。
- 客户端 HMR runtime 处理更新，对于接受自更新的模块（`module.hot.accept()`）直接替换，否则冒泡寻找能处理的父模块。

Vite 通过 ESM 的 `import()` 动态更新，利用浏览器原生能力，更快。
