# Q15：`nextTick` 的作用与原理

`nextTick` 在下次 DOM 更新循环结束后执行回调。Vue 异步更新 DOM，当数据变化时视图不会立即刷新，而是进入队列，并在下一个事件循环“tick”中批量更新。

**用法**：
```javascript
import { nextTick } from 'vue';
// 修改数据...
await nextTick();
// 此时可获取更新后的 DOM
```
常用于数据修改后需要操作最新的 DOM，比如获取元素尺寸、滚动位置。

**原理**：  
Vue 内部优先使用微任务（Promise.then）来实现延迟回调，兼容降级到 `setTimeout`。收集所有数据变更，在微任务清空前批量更新视图。
