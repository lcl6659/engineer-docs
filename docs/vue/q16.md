# Q16：插槽（slot）的种类及使用场景

- **默认插槽**：无需命名，子组件中用 `<slot></slot>` 定义位置，父组件将内容直接放在标签内。
- **具名插槽**：`<slot name="header">`，父组件通过 `<template v-slot:header>` 分发内容，多个插槽可安排在不同位置。
- **作用域插槽**：子组件通过 `<slot :data="item">` 将数据传给父组件，父组件通过 `v-slot="slotProps"` 接收并使用，常用于列表渲染中定制每一项内容。

**应用**：封装可复用的布局组件（Header、Body、Footer）、表格组件中自定义列渲染等。
