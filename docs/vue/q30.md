# Q30：Webpack 的核心概念和工作原理

Webpack 是一个静态模块打包器，从入口出发，递归构建依赖图，将各模块打包成 bundle。

**核心概念**：
- **Entry**：入口起点。
- **Output**：打包输出位置。
- **Loader**：转换非 JS 文件（如 css、图片）成为模块。
- **Plugin**：执行范围更广的任务，如打包优化、资源管理、注入环境变量。
- **Module**：一切皆模块。
- **Chunk**：代码块，由一个或多个模块组成。

**流程**：合并配置 → 创建 Compiler → 执行插件 `apply` → 从 entry 开始调用 Loader 转译模块 → 递归构建依赖图 → 生成 Chunk → 输出文件。
