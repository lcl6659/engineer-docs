# Q27：`watch` 和 `watchEffect` 的实现差异

- **`watchEffect`** 内部会创建一个 `effect`，并在其中运行用户回调。该 `effect` 会自动追踪回调中访问的所有响应式数据。当任何依赖变化时，会重新运行回调。它默认立即执行。
- **`watch`** 接收显式的监听源（ref、reactive、getter 等），内部会通过 `effect` 访问这些源以收集依赖，但通过传参控制 `lazy: true`，不会立即执行回调。它能够提供新值和旧值，通过闭包保留上次的值进行比较。
- 它们都使用了 `effect` 底层能力，区别在于依赖收集方式和参数处理。
