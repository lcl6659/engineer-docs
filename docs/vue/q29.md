# Q29：CommonJS、AMD、ESM 模块化规范的区别

| 规范 | 使用环境 | 加载方式 | 语法 | 特点 |
|------|---------|---------|------|------|
| CommonJS | Node.js | 同步加载 | `require` / `module.exports` | 运行时加载，输出值的拷贝（对基本类型）。依赖在代码执行时动态加载。 |
| AMD | 浏览器（RequireJS） | 异步加载 | `define(['a'], callback)` | 主要用于浏览器，依赖前置，提前执行。 |
| ESM (ES Modules) | 现代浏览器 / Node 13+ | 编译时确定依赖，异步加载 | `import` / `export` | 静态分析，输出值的引用，支持 Tree Shaking。 |

ESM 是标准方向，现代工具链全面支持。
