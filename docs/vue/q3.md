# Q3：Vue 组件的生命周期钩子有哪些？各阶段用途是什么？

生命周期分为创建、挂载、更新、卸载四个阶段，每个阶段提供了对应钩子。

**Vue 2 生命周期钩子**（选项式）：
- `beforeCreate`：实例初始化之后，数据观测/事件配置之前。
- `created`：实例创建完成，可访问 data、computed、methods，但 DOM 未挂载。常用于数据获取。
- `beforeMount`：挂载开始前，模板已编译，但尚未渲染到 DOM。
- `mounted`：实例挂载到 DOM，可访问真实 DOM 节点。适合操作 DOM、启第三方库。
- `beforeUpdate`：数据变化导致重新渲染前。
- `updated`：重新渲染完成后，避免在此钩子中修改数据以防死循环。
- `beforeDestroy`：实例销毁前，用于清除定时器、取消订阅。
- `destroyed`：实例销毁完成。
- `activated` / `deactivated`：配合 `<keep-alive>` 使用，组件激活/停用时触发。
- `errorCaptured`：捕获子组件错误。

**Vue 3 组合式 API 对应方式**：
- `setup()` 替代了 `beforeCreate` 和 `created`。
- `onBeforeMount`、`onMounted`、`onBeforeUpdate`、`onUpdated`、`onBeforeUnmount`、`onUnmounted`。
- 不再有 `destroyed`，统一使用 `unmounted`。
