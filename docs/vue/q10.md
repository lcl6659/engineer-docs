# Q10：Vuex 的核心概念与工作流程

Vuex 是 Vue 2 的官方状态管理库，基于 Flux 模式。

**核心概念**：
- **State**：单一状态树，存储共享数据。
- **Getter**：类似 computed，派生状态。
- **Mutation**：**同步**修改 state 的唯一方式，通过 `commit` 调用。
- **Action**：可异步操作，最终通过 `commit` mutation 来改变 state。
- **Module**：将 store 分割为模块，避免状态树臃肿。

**流程**：  
组件 `dispatch('action')` → Action 进行异步操作后 `commit('mutation')` → Mutation 改变 State → 视图响应更新。
