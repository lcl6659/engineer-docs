# Q12：Vue 3 组合式 API 与选项式 API 的对比

- **选项式 API**：逻辑分布在 `data`、`methods`、`computed`、`watch` 等选项里，当组件庞大时，同一功能的代码被拆分在不同部分，维护困难。
- **组合式 API**：通过 `setup()` 函数组织代码，可将同一功能的逻辑组合在一起，利于复用（自定义 hook）。提供更灵活的响应式系统（`ref`、`reactive` 等）。
- **优点**：更好的逻辑组织和复用、Tree-shaking 友好、TypeScript 支持更佳。
- **缺点**：学习曲线稍陡，但大型项目收益明显。

Vue 3 同时支持两者，但推荐组合式 API。
