# Q23：Vue 3 的静态提升（hoistStatic）和补丁标记（Patch Flags）分别是什么？

Vue 3 模板编译器做了多项静态分析优化，大幅提升更新性能：

- **静态提升（hoistStatic）**：  
  对于纯静态的虚拟节点（不绑定任何响应式数据），编译器会将创建 VNode 的代码提升到 `render` 函数外部，避免每次渲染都重新创建。这减少了不必要的 VNode 生成和内存分配，且 Diff 时可直接复用。

- **补丁标记（Patch Flags）**：  
  编译器在为动态绑定的元素生成 VNode 时，会附加一个数字标记位（如 `1` 表示动态文本，`2` 表示动态 class，`4` 表示动态 style，`16` 表示动态 props 等）。运行时 Diff 时，只会检查带有相应标记的属性，跳过未变化的静态属性，实现**靶向更新**（targeted update），极大减少比较成本。
