# Q18：Vue 中的性能优化方法

1. **合理使用 v-if / v-show**：频繁切换用 v-show，不常用用 v-if。
2. **列表 key**：使用稳定的唯一 key，避免索引。
3. **计算属性缓存**：替代模板中复杂的表达式。
4. **组件懒加载**：路由级别或异步组件 `defineAsyncComponent`。
5. **keep-alive 缓存**：保留组件状态减少重建开销。
6. **避免滥用全局状态**：状态尽可能靠近使用组件。
7. **虚拟列表**：长列表只渲染可视区域（如 `vue-virtual-scroller`）。
8. **`v-once` 和 `v-memo`**：标记只渲染一次或条件性缓存子树。
9. **事件销毁**：在 `onBeforeUnmount` 中移除事件监听、定时器。
10. **生产构建**：去除开发警告，Tree-shaking 多余代码。
