# Q7：Vue 中的 `computed` 与 `watch` 的区别

| 对比点 | `computed` | `watch` |
|-------|-----------|--------|
| 作用 | 根据已有数据计算出一个**派生值** | 监听某个数据的变化，执行**副作用** |
| 缓存 | 依赖不变时，多次访问直接返回缓存结果 | 无缓存，每次触发就执行回调 |
| 返回值 | 必须有返回值，可作为数据在模板中使用 | 不需返回值，执行操作（异步请求、DOM 操作等） |
| 默认行为 | 立即计算，且追踪依赖 | 默认惰性，数据变化才执行，可通过 `immediate: true` 改变 |
| 适用场景 | 格式化、过滤、总和等衍生状态 | 数据变化时需要响应操作，如请求数据、处理复杂逻辑 |
