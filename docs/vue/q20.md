# Q20：Vue 与 React 的简要对比

| 对比点 | Vue | React |
|-------|-----|-------|
| 模板 vs JSX | 推荐模板语法（也支持 JSX） | JSX 为主 |
| 数据流 | 双向绑定（v-model）、单向数据流 | 单向数据流，显式 setState |
| 响应式 | 自动依赖追踪，数据可变 | 需不可变数据，手动优化 |
| 状态管理 | Vuex / Pinia | Redux / Zustand / Context |
| 学习曲线 | 相对平滑，渐进式 | 稍陡，需理解 JSX 和函数式理念 |
| 生态 | 官方路由、状态管理一体化 | 社区方案众多，需组合 |
| 适用 | 快速开发，中小型企业应用多 | 大型项目、生态广阔 |
