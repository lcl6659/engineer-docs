# Q11：Pinia 与 Vuex 的区别，为何 Vue 3 推荐 Pinia？

Pinia 是 Vue 新的官方状态管理库，可视为 Vuex 5。

| 对比点 | Vuex | Pinia |
|-------|------|-------|
| 模块化 | 嵌套 module，结构较复杂 | 扁平化多个 store，模块天然分离 |
| 类型支持 | 对 TS 支持较弱 | 完整 TypeScript 支持，自动推导 |
| API | `mutations` 和 `actions` 分离 | 无 mutations，统一用 `actions`（同步异步均可） |
| 体积 | 较大 | 更轻量 |
| 去中心化 | 单一 Store，结构固定 | 按需创建多个 Store |
| 调用 | `store.dispatch` | 直接调用 `store.myAction()` |

**为什么推荐 Pinia**：更简洁的 API、出色的 TS 体验、无需命名空间、不再区分 mutation 和 action、支持组合式 API。
