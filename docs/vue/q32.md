# Q32：Webpack 性能优化有哪些？

- **速度优化**：
  - 使用 `thread-loader` 或 `happypack` 多进程构建。
  - 减少 Loader 作用范围（`include` / `exclude`）。
  - 缓存：`cache-loader` 或 Webpack 5 内置持久化缓存。
  - 合理配置 `resolve.extensions`、`resolve.alias`。
- **体积优化**：
  - Tree Shaking（开启 `mode: 'production'`）。
  - 代码分割：`splitChunks` 提取公共模块、异步加载。
  - 压缩：`TerserPlugin`、`CssMinimizerPlugin`。
  - `CompressionWebpackPlugin` 开启 Gzip。
  - 按需引入第三方库（如 lodash 使用 `lodash-es` + Tree Shaking）。
