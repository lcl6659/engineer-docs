# Q28：`nextTick` 的实现原理

Vue 异步执行 DOM 更新。当修改数据时，Watcher 会被推入一个队列，并在同一个事件循环中缓冲。`nextTick` 会在 DOM 更新完成后执行传入的回调。

**原理**：  
Vue 内部定义一个 `nextTick` 函数，将回调放入微任务（`Promise.then`）或宏任务（`setImmediate`/`setTimeout`）中，取决于环境支持。  
这样，同步的多次数据修改 → 将 flush 队列放入微任务 → 微任务清空 → DOM 更新完成 → `nextTick` 回调执行（因为同在一个微任务序列的最后）。  
因此 `await nextTick()` 确保获取更新后的 DOM。
