# Q23：Refs 转发（forwardRef）

`React.forwardRef` 允许组件将接收到的 ref 向下传递到内部的 DOM 元素或类组件实例。

```jsx
const Input = React.forwardRef((props, ref) => (
  <input ref={ref} {...props} />
));
```

常用于封装可复用的输入组件，或高阶组件中保留 ref 传递。

---

Refs 转发（`forwardRef`）是 React 提供的一种技术，允许父组件**通过 ref 直接访问子组件中的 DOM 元素或组件实例**。它解决了默认情况下 ref 无法穿透函数组件的问题，常用于需要直接操作子组件内部元素（如聚焦输入框、获取尺寸、触发动画等）的场景。

## 1. 为什么需要 refs 转发？

- **函数组件没有实例**：给函数组件直接添加 `ref` 属性，默认会收到 `null`（开发环境还会报警告），因为函数组件不能像类组件那样被实例化。
- **封装与透传**：当你封装一个可复用的组件（如输入框、按钮库），希望使用者能直接访问内部的真实 DOM 或具体组件实例来控制焦点、测量等行为时，就需要将外部的 `ref` 传递到内部的适当节点上。

## 2. 基本用法

`React.forwardRef` 接收一个**渲染函数**，该函数的参数是 `(props, ref)`，返回 JSX。然后将这个 ref 附加到内部的 DOM 元素或类组件实例上。

```jsx
import React, { forwardRef, useRef } from 'react';

// 定义一个函数组件，使用 forwardRef 包裹
const FancyInput = forwardRef((props, ref) => {
  return <input ref={ref} className="fancy-input" {...props} />;
});

function Parent() {
  const inputRef = useRef(null);

  const focusInput = () => {
    inputRef.current.focus(); // 直接调用子组件内部 input 的 focus 方法
  };

  return (
    <>
      <FancyInput ref={inputRef} placeholder="点击按钮聚焦我" />
      <button onClick={focusInput}>聚焦输入框</button>
    </>
  );
}
```

## 3. 多个 ref 转发的场景

有时你希望转发多个 ref，或者将 ref 挂载到不同的元素。可以配合 `useImperativeHandle` 来定制暴露给父组件的实例值。

```jsx
const CustomForm = forwardRef((props, ref) => {
  const inputRef = useRef();
  const buttonRef = useRef();

  // 只暴露 focusInput 和 scrollToButton 方法，而不是整个 ref 链
  useImperativeHandle(ref, () => ({
    focusInput: () => inputRef.current.focus(),
    clickButton: () => buttonRef.current.click()
  }));

  return (
    <div>
      <input ref={inputRef} />
      <button ref={buttonRef}>提交</button>
    </div>
  );
});

function Parent() {
  const formRef = useRef();
  return (
    <>
      <CustomForm ref={formRef} />
      <button onClick={() => formRef.current.focusInput()}>聚焦输入框</button>
      <button onClick={() => formRef.current.clickButton()}>触发表单按钮</button>
    </>
  );
}
```

## 4. 在 TypeScript 中使用

需要指定 ref 对应的 DOM 元素类型。

```tsx
const FancyInput = forwardRef<HTMLInputElement, { placeholder?: string }>(
  (props, ref) => <input ref={ref} {...props} />
);
```

## 5. 高阶组件（HOC）中的 ref 转发

当使用 HOC 时，ref 不会被自动传递给被包裹组件。必须使用 `forwardRef` 来处理。

```jsx
function logProps(Component) {
  const LoggedComponent = forwardRef((props, ref) => {
    useEffect(() => {
      console.log('Props:', props);
    });
    return <Component ref={ref} {...props} />;
  });
  return LoggedComponent;
}

const EnhancedButton = logProps(MyButton);
```

## 6. 注意事项

- **尽量少用**：直接 DOM 操作会打破 React 声明式模型，优先使用状态和 props。
- **避免过度转发**：不要暴露不必要的内部实现细节。
- **与 `useImperativeHandle` 搭配**：可以限制父组件能调用的方法，增强封装性。
- **类组件已内置**：在类组件上直接使用 `ref`，ref 将指向组件实例，无需 forwardRef。

## 7. 对比普通 ref 与 forwardRef

| 场景                         | 使用方式                             |
| ---------------------------- | ------------------------------------ |
| 类组件上直接使用 ref         | `<Child ref={myRef} />`，ref 得到实例 |
| 函数组件上直接使用 ref       | 无效，需用 forwardRef 转发到内部元素  |
| 需要限制父组件可调用的方法   | forwardRef + useImperativeHandle    |
| HOC 包装后的组件 ref 透传    | 必须用 forwardRef 包裹 HOC 内部函数   |

## 总结

- **`forwardRef`** 是让函数组件能够接收外部 ref 并转发给内部 DOM 或类组件的工具。
- 常与 **`useRef`**（创建 ref）和 **`useImperativeHandle`**（限制暴露接口）配合使用。
- 主要解决**组件封装与 DOM 可访问性**之间的矛盾，使封装后的组件依然能被父组件直接控制焦点、滚动等行为。
