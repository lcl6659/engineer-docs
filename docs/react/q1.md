# Q1：React 的核心理念与特点

- **声明式**：React 让你只需描述 UI 应该是什么样子，当数据变化时，它会高效地更新和重新渲染恰当的组件。
- **组件化**：UI 被拆分成独立、可复用的组件，每个组件封装了自己的结构和逻辑。
- **虚拟 DOM**：在内存中维护一棵轻量级的虚拟 DOM 树，状态变化时生成新的虚拟树，通过 Diff 算法计算出最小变更，再批量更新真实 DOM，极大提升性能。
- **单向数据流**：数据从父组件通过 props 流向子组件，数据流动清晰，容易追踪和调试。
- **一次学习，随处编写**：可开发 Web、移动端（React Native）、桌面端等。
