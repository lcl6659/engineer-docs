# Q5：类组件与函数组件的区别

| 比较点 | 类组件 | 函数组件 |
|-------|--------|---------|
| 定义方式 | 继承 `React.Component`，需实现 `render` | 普通的 JavaScript 函数，接收 props 返回 JSX |
| 状态管理 | `this.state` 和 `this.setState` | 使用 Hooks（如 `useState`、`useReducer`） |
| 生命周期 | 完整的生命周期方法 | 使用 `useEffect` 等 Hooks 来模拟 |
| `this` 问题 | 需要处理 `this` 绑定问题 | 没有 `this`，完全规避了相关困扰 |
| 性能 | 实例化开销大一些 | 轻量，无实例化开销 |
| 未来趋势 | 逐渐被函数组件 + Hooks 替代，新特性优先于函数组件 | 官方主推，功能更强大 |
