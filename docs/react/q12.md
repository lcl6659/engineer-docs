# Q12：`useContext` 与 Context API 如何跨组件传值

Context 用于在组件树中共享全局数据，无需逐层 props 传递。

1. 创建：`const MyCtx = React.createContext(defaultValue)`
2. 提供：`<MyCtx.Provider value={data}>`
3. 消费：
   - 函数组件：`const data = useContext(MyCtx)`
   - 类组件：`static contextType = MyCtx` 或 `<MyCtx.Consumer>`

**注意**：Provider 的 value 变化时，所有使用该 Context 的组件都会重渲染。对于高频更新的数据，应拆分多个 Context，或用状态管理库进行细粒度订阅。
