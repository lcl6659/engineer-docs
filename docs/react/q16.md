# Q16：React 中的合成事件

React 封装了浏览器原生事件，形成**合成事件（SyntheticEvent）**。

- **目的**：抹平不同浏览器的事件差异，提供一致的 API。
- **原理**：React 17 时代事件委托在 `document` 上，React 18 委托在根容器上。
- **特点**：使用驼峰命名（如 `onClick`），事件对象可复用（旧版需 `e.persist()`，18 后废弃）。
- **与原生事件区别**：阻止冒泡可使用 `e.stopPropagation()`，但阻止的是 React 事件冒泡；原生事件绑定在 DOM 上需注意执行顺序。
