# Q10：`useRef` 的作用与用法

`const ref = useRef(initialValue)` 返回一个可变对象，其 `.current` 属性在整个生命周期中保持不变，修改它不会触发重新渲染。

**主要用途**：
1. **访问 DOM 元素**：绑定到 JSX 的 `ref` 属性上，获取真实 DOM 节点进行操作（focus、测量等）。
2. **保存可变值**：存放与视图无关但需要跨渲染保持不变的数据（如定时器 ID、上一次的状态）。
3. **解决闭包陷阱**：将最新 state/props 同步到 ref，在异步回调中通过 `ref.current` 获取最新值。
