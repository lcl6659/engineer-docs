# Q25：Redux 核心概念

**三大原则**：单一数据源、State 只读（通过 action 修改）、使用纯函数 reducer 执行更新。

**工作流程**：视图 dispatch(action) → Reducer 根据 action 类型返回新 state → Store 更新 → 视图重新渲染。

**现代 Redux Toolkit**：使用 `configureStore`、`createSlice`（内置 Immer 允许“可变”写法），以及 React-Redux 的 `useSelector`、`useDispatch` Hooks。

---

Redux 是一个用于 JavaScript 应用（特别是 React）的**状态管理库**，它通过**单一数据源**、**状态只读**、**纯函数修改**三大原则，让应用状态变得可预测、易调试。下面是 Redux 的基础使用方法。

## 核心概念

- **Store**：存储整个应用状态的单一对象（一个应用只有一个 Store）。
- **Action**：描述“发生了什么”的普通 JavaScript 对象（必须带有 `type` 字段）。
- **Reducer**：纯函数，接收当前 `state` 和 `action`，返回新的 `state`。
- **Dispatch**：发送 Action 的唯一方法，通知 Redux 执行 Reducer 更新状态。
- **Subscribe**：监听状态变化，可更新 UI（但在 React 中通常用 `react-redux` 的 `connect` 或 hooks 代替）。

## 三大原则

1. **单一数据源**：整个应用的 state 存储在一个对象树中（便于调试、持久化）。
2. **State 是只读的**：只能通过触发 action 来改变 state，避免意外修改。
3. **使用纯函数修改**：reducer 必须纯函数，不能有副作用，不能直接修改原 state。

## 基础使用步骤（原生 Redux）

### 1. 安装

```bash
npm install redux
```

### 2. 创建 Reducer

```js
// counterReducer.js
const initialState = { count: 0 };

function counterReducer(state = initialState, action) {
  switch (action.type) {
    case 'INCREMENT':
      return { ...state, count: state.count + 1 };
    case 'DECREMENT':
      return { ...state, count: state.count - 1 };
    default:
      return state;
  }
}
```

### 3. 创建 Store

```js
// store.js
import { createStore } from 'redux';
import counterReducer from './counterReducer';

const store = createStore(counterReducer);
export default store;
```

### 4. 在应用中分发 Action 并监听变化

```js
// index.js 或组件中
import store from './store';

// 订阅状态变化（通常不直接做）
store.subscribe(() => {
  console.log('State updated:', store.getState());
});

// 分发 Action
store.dispatch({ type: 'INCREMENT' });
store.dispatch({ type: 'DECREMENT' });
console.log(store.getState()); // { count: 0 }
```

## 与 React 配合（不使用 Redux Toolkit 的原始方式）

需要安装 `react-redux`：

```bash
npm install react-redux
```

### 提供 Store

```jsx
// index.js
import React from 'react';
import ReactDOM from 'react-dom';
import { Provider } from 'react-redux';
import store from './store';
import App from './App';

ReactDOM.render(
  <Provider store={store}>
    <App />
  </Provider>,
  document.getElementById('root')
);
```

### 在组件中使用

```jsx
// Counter.js
import React from 'react';
import { useSelector, useDispatch } from 'react-redux';

function Counter() {
  const count = useSelector(state => state.count);
  const dispatch = useDispatch();

  return (
    <div>
      <h1>{count}</h1>
      <button onClick={() => dispatch({ type: 'INCREMENT' })}>+</button>
      <button onClick={() => dispatch({ type: 'DECREMENT' })}>-</button>
    </div>
  );
}
```

## 常见问题与最佳实践

- **Action 类型常量**：将 action type 定义为常量，避免拼写错误。
- **Action Creator**：封装 action 对象的创建函数。
- **组合 Reducers**：使用 `combineReducers` 管理多个 reducer。
- **不可变性**：始终用扩展运算符或 `Object.assign` 返回新对象，不可直接修改原 state。
- **异步操作**：原生 Redux 不支持异步，需中间件如 `redux-thunk` 或 `redux-saga`。

## 现代推荐：Redux Toolkit

官方推荐使用 **Redux Toolkit** 简化配置、自动处理不可变性（基于 Immer）、集成异步 thunk。用法如下：

```js
import { configureStore, createSlice } from '@reduxjs/toolkit';

const counterSlice = createSlice({
  name: 'counter',
  initialState: { count: 0 },
  reducers: {
    increment: state => { state.count += 1; },
    decrement: state => { state.count -= 1; }
  }
});

export const { increment, decrement } = counterSlice.actions;
const store = configureStore({ reducer: counterSlice.reducer });
```

## 总结

- Redux 提供 **可预测的状态管理**，适合中大型应用。
- 核心流程：**View → dispatch(action) → reducer → new state → View 更新**。
- 基础 API：`createStore`、`combineReducers`、`applyMiddleware`。
- 推荐使用 **Redux Toolkit + React-Redux** 进行实际开发。
