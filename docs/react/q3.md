# Q3：虚拟 DOM 是什么？其工作原理及 Diff 算法概述

**虚拟 DOM**：是真实 DOM 的一个轻量级 JavaScript 对象表示，它包含了标签名、属性、子节点等信息，形成一棵虚拟树。

**工作原理**：
1. 用虚拟 DOM 生成真实 DOM 并挂载。
2. 状态变化时，创建一棵新的虚拟 DOM 树。
3. 使用 Diff 算法对两棵虚拟树进行差异比较。
4. 找到差异后，只对不同的地方进行真实 DOM 的批量更新。

**Diff 算法三大策略**（将 O(n³) 降为 O(n)）：
1. **Tree Diff**：只比较同级节点，跨层级移动视为删除并新建。
2. **Component Diff**：组件类型不同则直接删除原组件及子树；组件类型相同则继续递归比较。
3. **Element Diff**：同一层级的子元素通过 **key** 属性来判断是否可复用，可实现移动、复用，避免大量删除和创建。
