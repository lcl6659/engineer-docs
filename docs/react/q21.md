# Q21：`React.lazy` 与 `Suspense`

**`React.lazy(() => import('./Component'))`**：实现组件的动态导入，达到代码分割和按需加载。

**`<Suspense fallback={<Loading/>}>`**：在懒加载组件加载时显示 fallback UI，提升用户体验。

React 18 中 Suspense 得到强化，且开始支持数据获取场景，配合 React Server Components 可优雅处理异步数据流。

---

`React.lazy` 和 `Suspense` 是 React 16.6 引入的特性，用于实现**组件级别的代码分割（Code Splitting）**和**懒加载（Lazy Loading）**，从而优化应用的初始加载性能。它们允许你将组件打包成独立的 chunk，仅在需要时才加载。

## 核心概念

- **`React.lazy`**：一个函数，接收一个**动态 `import()`**，返回一个可被 Suspense 包裹的 React 组件。该组件会在首次渲染时自动加载对应的模块。
- **`Suspense`**：一个组件，用于包裹懒加载组件，并显示**回退 UI**（如 loading 指示器），直到懒加载的组件被加载完成。

## 基本用法

```jsx
import React, { Suspense } from 'react';

// 使用 React.lazy 懒加载组件
const LazyComponent = React.lazy(() => import('./LazyComponent'));

function App() {
  return (
    <div>
      <Suspense fallback={<div>Loading...</div>}>
        <LazyComponent />
      </Suspense>
    </div>
  );
}
```

## 详细示例

```jsx
// LazyComponent.js
export default function LazyComponent() {
  return <div>我是懒加载的组件</div>;
}

// App.js
import React, { Suspense, useState } from 'react';

const OtherComponent = React.lazy(() => import('./OtherComponent'));
const AnotherComponent = React.lazy(() => import('./AnotherComponent'));

function App() {
  const [show, setShow] = useState(false);

  return (
    <div>
      <button onClick={() => setShow(true)}>显示懒加载组件</button>
      <Suspense fallback={<div>加载中...</div>}>
        {show && <OtherComponent />}
      </Suspense>
      {/* Suspense 可以包裹多个懒加载组件 */}
      <Suspense fallback={<div>加载另一组组件...</div>}>
        <AnotherComponent />
      </Suspense>
    </div>
  );
}
```

## 适用场景

- **按路由拆分**：不同路由的组件单独打包，仅在访问该路由时加载。
- **大型组件**：如富文本编辑器、图表库等，不是首屏必需的模块。
- **条件渲染**：仅在用户触发特定操作（点击、弹窗）后才加载的组件。

## 与路由结合（React Router）

```jsx
import { BrowserRouter, Routes, Route } from 'react-router-dom';
import { Suspense, lazy } from 'react';

const Home = lazy(() => import('./routes/Home'));
const About = lazy(() => import('./routes/About'));

function App() {
  return (
    <BrowserRouter>
      <Suspense fallback={<div>页面加载中...</div>}>
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="/about" element={<About />} />
        </Routes>
      </Suspense>
    </BrowserRouter>
  );
}
```

## 注意事项

| 注意点                     | 说明                                                         |
| -------------------------- | ------------------------------------------------------------ |
| **必须配合 Suspense**      | `React.lazy` 组件必须渲染在 `Suspense` 组件内部，否则会报错。 |
| **fallback 是必需的**      | `Suspense` 的 `fallback` 属性接受任何 React 元素，用于展示加载中状态。 |
| **服务端渲染（SSR）兼容**  | `React.lazy` + `Suspense` 在 SSR 中不直接可用，需使用其他方案如 `Loadable Components`。 |
| **多次懒加载**             | 可以嵌套使用 `Suspense`，每个懒加载组件独立触发加载。       |
| **避免闪烁**               | 如果组件加载极快（< 200ms），可能不需要显示 fallback，React 内部会优化。 |
| **错误处理**               | 懒加载模块加载失败（网络错误等）时，需要配合**错误边界**捕获并展示错误 UI。 |

```jsx
// 错误边界 + 懒加载示例
<ErrorBoundary>
  <Suspense fallback={<div>Loading...</div>}>
    <LazyComponent />
  </Suspense>
</ErrorBoundary>
```

## 原理简述

- 调用 `React.lazy` 返回一个特殊的 React 组件对象，它的状态是 `pending`。
- 首次渲染该组件时，React 会执行传入的 `import()` 函数，返回一个 Promise。
- `Suspense` 会捕获这个 Promise，并渲染 `fallback` 内容。
- Promise resolve 后，React 重新渲染懒加载组件。

## 对比传统动态 import

| 方式                     | 优点                                     | 缺点                     |
| ------------------------ | ---------------------------------------- | ------------------------ |
| **手动 `import().then`** | 完全控制加载时机和状态                   | 需要手动管理 loading、error、渲染 |
| **`React.lazy` + Suspense** | 声明式、自动处理加载状态、与 React 渲染周期集成 | 不支持 SSR、错误处理需搭配 Error Boundary |

## 总结

- **`React.lazy`** + **`Suspense`** 是 React 官方推荐的代码分割和懒加载方案，简化了动态加载组件的复杂度。
- 适用于客户端渲染的 React 应用，能显著减少首屏 bundle 体积。
- 配合路由库使用时，能够实现**路由级别的代码分割**，提升用户体验。
- 记得用**错误边界**兜底加载失败的情况，避免白屏。
