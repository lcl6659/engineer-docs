# Q24：React Router v6 基础

React Router 是 React 应用客户端路由的标准库。

- `<BrowserRouter>`：使用 HTML5 history API。
- `<Routes>` 和 `<Route path="/" element={<Home />} />`。
- 嵌套路由使用 `<Outlet />`。
- `useNavigate()` 用于编程式导航。
- `useParams()` 获取动态路由参数。
- `<Link>` 和 `<NavLink>` 实现声明式导航。



---

React Router v6 是一个重大更新，它不仅让 API 更简洁，更从根本上改变了构建 React 应用路由的方式，引入了强大的数据加载与变更功能。

### 📍 核心概念
React Router v6 的核心是数据模式。它基于 **`createBrowserRouter`** 创建路由，结合 **`loader`**（路由加载时获取数据）、**`action`**（处理表单提交）和 **`errorElement`**（处理错误），让数据和 UI 保持同步。

### 🚀 主要 API 变化
从 v5 升级到 v6，主要 API 变化如下：

| 方面 | v5 | v6 |
| :--- | :--- | :--- |
| **容器组件** | `<Switch>` | `<Routes>` |
| **渲染方式** | `component` / `render` / `children` 属性 | `element` 属性，接收 JSX 元素 |
| **嵌套路由** | 需在组件中手动解析和渲染 | 原生支持，通过父组件的 `<Outlet />` 组件渲染子路由 |
| **路由钩子** | `useHistory` | `useNavigate` |
| **重定向** | `<Redirect />` 组件 | `<Navigate />` 组件或 `redirect` 工具函数 |

### ⚙️ 核心功能详解
*   **声明式路由**：使用 `<Routes>` 和 `<Route>` 定义路由，路径匹配规则更智能（支持相对路径与自动排序），**路径唯一，否则仅首个匹配的生效**。静态路由配置用 **`createBrowserRouter` + `<RouterProvider>`** 替代 `BrowserRouter + Routes`。
*   **嵌套路由与布局**：通过 `<Outlet />` 组件精准定义子路由的渲染位置。结合布局（Layout）组件，使导航和内容区域分离。
*   **数据加载 (loaders)**：路由组件渲染前自动并行执行 `loader`，预加载所需数据，通过 `useLoaderData` hook 获取，彻底解决了"组件渲染 -> 请求数据"的性能问题。
*   **数据变更 (actions)**：用内置 `<Form>` 组件替代普通表单，提交时自动调用路由配置的 `action` 处理数据。`action` 完成后调用 `redirect` 跳转页面，实现流畅的流程。
*   **延迟数据 (defer)**：允许部分数据先加载并展示框架页面，耗时数据稍后加载，用 `<Await />` 组件配合 `Suspense` 展示加载状态，避免页面长时间白屏。
*   **错误处理 (errorElement)**：路由配置中的 `errorElement` 专门捕获 `loader`、`action` 或组件渲染中的错误，避免应用崩溃。用 **`useRouteError`** hook 获取错误信息并展示降级 UI。
*   **代码分割**：结合 `React.lazy` 和 `Suspense`，仅在用户访问时加载对应路由组件，有效减小首屏体积。
*   **导航与 Hooks**：`<Link>` 和 `useNavigate` 用于导航；`useParams` 获取路由参数；`useLocation` 获取当前 location 对象；`useNavigation` 获取路由状态（如 `loading`）以展示加载指示。

### ⚠️ 常见陷阱与最佳实践
*   **确保单一 Router 实例**：整个应用中只应存在一个 `BrowserRouter` 或 `RouterProvider`，重复会导致路由无法同步。
*   **正确处理重定向**：避免在根路径 `loader` 中无限重定向，使用 `index` 属性配合 `<Navigate>` 声明式处理默认路由。
*   **注意相对路径**：嵌套路由使用相对路径 (e.g., `to="settings"`)，从当前路由路径拼接完整 URL。
*   **统一使用 `element` 属性**：使用 `<Route element={<Component />} />` 渲染组件。

### 💎 总结
React Router v6 的核心是拥抱“数据即路由”的理念，将数据加载与导航深度整合。它不仅是一个路由库，更是一个完整的客户端数据框架的基础，是构建现代、高性能 React 应用的基石。
