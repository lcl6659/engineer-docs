# Q2：什么是 JSX？为什么在 React 中使用它？

JSX 是 JavaScript 的一种语法扩展，看起来类似 HTML，它允许在 JavaScript 中直接编写 UI 结构。JSX 最终会被 Babel 编译为 `React.createElement` 调用，生成虚拟 DOM 节点。

**使用原因**：
- **可读性强**：用类似 HTML 的结构描述 UI，比手写 `React.createElement` 更加直观和易于维护。
- **表达式嵌入**：可通过 `{ }` 嵌入任意 JavaScript 表达式，动态生成内容。
- **防止注入攻击**：React DOM 在渲染前会转义 JSX 中的所有值，有效避免 XSS。
- **编译优化**：JSX 是编译时的语法糖，可以与虚拟 DOM 渲染流程完美结合。
