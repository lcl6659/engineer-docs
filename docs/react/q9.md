# Q9：`useEffect` 完全指南

`useEffect(setup, dependencies?)` 管理副作用。

- **执行时机**：在浏览器完成布局与绘制之后**异步执行**，不阻塞屏幕更新（而 `useLayoutEffect` 在 DOM 变更后同步触发）。
- **清除函数**：setup 返回的函数会在组件卸载以及下一次 effect 执行前运行，用于清除定时器、取消订阅。
- **依赖数组**：
  - 不传：每次渲染后都执行。
  - `[]` 空数组：仅在挂载时执行，卸载时清除。
  - `[a, b]`：当依赖值变化时重新执行。
- **注意**：不要遗漏依赖，否则可能读到过期的闭包变量；不要将对象或函数直接放在依赖中（每次新引用），需借助 `useMemo`/`useCallback`。
