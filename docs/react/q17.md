# Q17：高阶组件（HOC）的概念与应用

**概念**：高阶组件是一个**函数**，接收一个组件，返回一个新的增强组件。

```javascript
const EnhancedComponent = higherOrderComponent(WrappedComponent);
```

**应用**：权限控制、埋点、数据获取、条件渲染，复用逻辑。

**注意**：
- 不要修改原始组件，使用组合。
- 透传不相关的 props。
- 通常以 `with` 开头命名，如 `withRouter`。
- 可配合 `hoist-non-react-statics` 解决静态方法丢失问题。
