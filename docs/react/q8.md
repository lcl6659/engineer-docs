# Q8：`useState` 使用细节及原理

`const [state, setState] = useState(initialState);`

- **惰性初始化**：若初始状态计算昂贵，可传函数 `useState(() => compute())`，它仅在首次渲染执行。
- **更新方式**：`setState` 可传新值或更新函数 `(prevState) => newState`。React 使用 `Object.is` 比较，值相同时跳过渲染。
- **批处理**：React 18 之前仅在事件处理中批处理，React 18 后自动批处理扩大到 setTimeout、原生事件等场景。
- **闭包陷阱**：在异步操作中直接使用 state 可能拿到旧值，应使用函数式更新 `setState(prev => prev + 1)` 或用 `useRef` 保存最新值。
