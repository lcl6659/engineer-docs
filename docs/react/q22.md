# Q22：React 18 的重要新特性

1. **自动批处理**：不仅事件处理，setTimeout、Promise 等多次 setState 也会合并为一次渲染。
2. **并发特性**：`startTransition` 将更新标记为低优先级，`useTransition` 返回 pending 状态。
3. **`useDeferredValue`**：延迟更新某个值，让出主线程给高优先级更新。
4. **`useId`**：生成跨服务端和客户端一致的唯一 ID。
5. **新的 Suspense**：支持服务端流式渲染和选择性注水。
6. **并发渲染**：React 可以中断渲染，优先更新高优先级部分，保持 UI 响应。
