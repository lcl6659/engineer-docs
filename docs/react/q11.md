# Q11：`useMemo` 与 `useCallback` 详解

两者都用于缓存，避免不必要的计算或子组件重渲染。

- **`useMemo(() => computeValue, deps)`**：缓存一个**计算结果**。只有 deps 变化时才重新计算，否则返回缓存的旧值。适用于昂贵计算或需要稳定引用的对象/数组。
- **`useCallback(fn, deps)`**：缓存一个**函数引用**。仅当 deps 变化时返回新的函数，配合 `React.memo` 可以避免子组件因函数引用变化而不必要地重渲染。

**注意**：不要提前过度优化，只在出现性能瓶颈或作为其他 Hook 的稳定依赖时才使用。
