# Q15：React 性能优化手段

1. **避免不必要的渲染**：使用 `React.memo`、`PureComponent`。
2. **缓存值与函数**：`useMemo`、`useCallback` 提供稳定引用。
3. **正确的 key**：帮助 Diff 算法复用 DOM。
4. **代码分割**：`React.lazy` + `Suspense` 按需加载。
5. **虚拟列表**：处理长列表，只渲染可视区域。
6. **避免内联对象/函数**：减少子组件 props 变化。
7. **状态下沉**：将状态放在尽可能低层的组件中，减少更新波及范围。
8. **Context 优化**：拆分 Context，或使用状态管理库避免不相关更新。
