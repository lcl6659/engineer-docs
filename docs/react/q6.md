# Q6：React 类组件生命周期详解

生命周期分为三个阶段：

**挂载阶段**  
1. `constructor(props)`：初始化 state，绑定方法。  
2. `static getDerivedStateFromProps(props, state)`：从 props 派生出 state（很少使用）。  
3. `render()`：产生 JSX。  
4. `componentDidMount()`：组件已挂载到真实 DOM，适合发起网络请求、添加订阅。

**更新阶段**  
1. `static getDerivedStateFromProps(props, state)`。  
2. `shouldComponentUpdate(nextProps, nextState)`：性能优化关键，决定是否重渲染，默认返回 true。  
3. `render()`。  
4. `getSnapshotBeforeUpdate(prevProps, prevState)`：获取更新前 DOM 信息，返回给 `componentDidUpdate`。  
5. `componentDidUpdate(prevProps, prevState, snapshot)`：更新后操作 DOM、请求数据。

**卸载阶段**  
- `componentWillUnmount()`：清除定时器、取消订阅、防止内存泄漏。

**错误处理**  
- `static getDerivedStateFromError(error)`：捕获子组件错误并更新 state 展示降级 UI。  
- `componentDidCatch(error, info)`：记录错误日志。
