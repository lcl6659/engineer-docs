# Q10：Vite 是什么？它解决了什么问题？

### Vite 核心

Vite 是一个**前端构建工具**，旨在为现代 Web 项目提供更快的开发体验。它由两部分组成：
- **开发服务器**：基于浏览器原生 ES Modules（`script` + `type="module"`）和 `esbuild` 预构建依赖，提供极快的冷启动和热更新。
- **生产构建**：使用 Rollup 打包，输出高度优化的静态资源。

**Vite 解决的核心痛点**：
- **传统打包器（Webpack）的开发服务器启动慢**：需要先打包整个应用，随着项目体量增大，启动时间线性增长。Vite 则利用浏览器原生支持 ESM 的能力，只按需编译请求的模块，冷启动几乎瞬时完成。
- **HMR 效率低**：即使只有小改动，也可能需要重新构建整个相关模块链；Vite 的 HMR 只精确更新修改的模块，性能不随模块数量增加而下降。
