# Q26：如何分析 Webpack 构建性能？有哪些常用工具和指标？

### 性能分析实战

**工具**：
- **内置 Profile**：运行 `webpack --profile --json > stats.json`，生成统计分析文件，上传到 Webpack 官方分析工具（`webpack.github.io/analyse`）或 `webpack-bundle-analyzer`。
- **Speed Measure Plugin**：`speed-measure-webpack-plugin` 插件，可以测量每个 Loader 和 Plugin 的耗时，输出彩色表格。
- **Bundle Analyzer**：`webpack-bundle-analyzer` 可视化包大小和构成，定位体积大的模块。
- **Performance Hints**：`performance: { hints: 'error' }` 可设置在包体积超过限制时抛出错误。
- **`timefix` 插件（已废弃）**：了解即可。

**关键指标**：
- 总构建时间。
- 各 Loader 耗时（占比）。
- 各 Plugin 耗时。
- 输出包大小，重复模块数量。
- 代码分割后的 Chunk 依赖关系是否合理。
