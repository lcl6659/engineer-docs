# Q39：Rolldown 是什么？它与 Rollup 有什么关系？

Rolldown 是由 Vue.js 作者尤雨溪发起的，用 **Rust** 编写的 **JavaScript 打包器**，旨在兼容 Rollup 的 API 和插件生态，同时提供**极致的性能**。

- **背景**：Vite 目前生产构建使用 Rollup，但 Rollup 是 JavaScript 编写，构建大型项目时速度仍不如 esbuild、swc 等原生语言工具。Rolldown 被创建为 Rollup 的一个 Rust 版本，计划未来作为 Vite 的生产构建引擎。
- **设计目标**：保持与 Rollup 的 API 和插件系统高度兼容，让现有 Rollup 插件能够轻松迁移。
- **现状**：已处于积极开发中，已发布多个 alpha 版本，但尚未完全替代 Rollup。它是 Vite 生态的重要拼图，旨在统一开发和生产的极速体验。
