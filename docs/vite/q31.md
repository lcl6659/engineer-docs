# Q31：Rollup 的配置中，`input`、`output` 各有哪些关键选项？

- **`input`**：入口文件路径（字符串或对象，多入口）。
  - 单入口：`input: 'src/main.js'`
  - 多入口：`input: { app: 'src/app.js', admin: 'src/admin.js' }`（会输出多个 bundle）

- **`output`**：可以是对象或数组（同时产出多种格式）：
  - `file`：输出文件名（单入口时用）。
  - `dir`：输出目录（多入口或多 chunk 时用，与 `file` 互斥）。
  - `format`：必选项，取值：
    - `'es'` / `'esm'`：ES Module 文件，供打包工具消费。
    - `'cjs'`：CommonJS，供 Node.js 使用。
    - `'amd'`：异步模块定义。
    - `'umd'`：通用模块定义，兼容浏览器全局变量、AMD、CommonJS。
    - `'iife'`：立即执行函数，适合浏览器通过 `script` 标签直接引入。
  - `name`：当输出格式为 `umd` 或 `iife` 时，需要指定全局变量名称。
  - `globals`：`umd`/`iife` 格式下，声明外部依赖的全局变量映射，例如 `{ jquery: '$' }`。
  - `exports`：控制如何导出模块（`'auto'`、`'default'`、`'named'`、`'none'`）。
  - `sourcemap`：生成 Source Map 的方式。
  - `plugins`：输出阶段专用插件（如压缩、清理）。

**示例**：
```javascript
export default {
  input: 'src/index.js',
  output: [
    { file: 'dist/my-lib.esm.js', format: 'es' },
    { file: 'dist/my-lib.cjs.js', format: 'cjs' },
    { file: 'dist/my-lib.umd.js', format: 'umd', name: 'MyLib', globals: { react: 'React' } }
  ],
  external: ['react'], // 外部化依赖
  plugins: [...]
};
```
