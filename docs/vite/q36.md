# Q36：Rollup 的 `external` 选项的作用是什么？为什么打包库时必须设置？

`external` 选项用于将某些模块标记为**外部依赖**，不打包进最终产物。也就是说，依赖的导入语句会被保留在输出中，由消费者（使用你的库的项目）来提供。

**为什么必须设置**：
- 如果你正在开发一个库，它依赖了 `react`，你**不希望**将整个 React 的代码打包进你的库中。否则，消费者的项目里会出现两份 React（你的库一份，消费项目一份），导致体积膨胀、多实例错误。
- 通过 `external: ['react']`，Rollup 会保留 `import React from 'react'` 这条语句，消费者自己的打包器（如 Webpack）会进行处理。

**支持通配符**：`external: [/node_modules/]`。
**结合 `output.globals`**：当输出 UMD/IIFE 格式时，需要通过 `globals` 指定外部依赖在全局作用域中的名称，以便在浏览器中正确引用。
