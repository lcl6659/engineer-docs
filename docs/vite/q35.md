# Q35：Rollup 如何进行代码分割（Code Splitting）？

Rollup 支持通过**动态导入** (`import()`) 进行代码分割。当你在代码中使用 `import('./module.js')` 时，Rollup 会自动将该模块及其依赖分割成独立的 chunk，并在运行时按需加载。

**配置要点**：
- **输出目录**：必须使用 `output.dir` 而不是 `output.file`，因为会生成多个 chunk 文件。
- **格式**：`output.format` 必须支持代码分割，如 `es`、`amd`、`system`，但不能是 `iife` 或 `umd`（因为它们不支持外部 chunk 加载）。
- **实验性功能**：目前 ES 模块格式的代码分割已是正式功能。
- **自定义 chunk 名称**：可以通过 `output.chunkFileNames` 控制 chunk 命名模式，或使用魔法注释 `/* webpackChunkName: "xxx" */`（其实 Rollup 使用 `import(/* @rollup-ignore */ './module')` 配合 `output.manualChunks` 更常见）。

**手动分割**：通过 `output.manualChunks` 函数可以将特定模块提取到指定 chunk 中，类似 Webpack 的 `cacheGroups`：
```javascript
output: {
  dir: 'dist',
  format: 'es',
  manualChunks: {
    vendor: ['react', 'react-dom'],
    utils: ['lodash']
  }
}
```
