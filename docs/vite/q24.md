# Q24：Vite SSR 与传统 SSR（如 Next.js、Nuxt.js）有何不同？

- **传统框架**（Next.js、Nuxt.js）将构建、路由、数据获取等高度集成，开发者大多按约定书写。它们内部用 Webpack 或自己的打包器。
- **Vite SSR** 更底层：提供基础的原生 ESM 支持，开发者手动搭建 Node 服务器、路由、数据预取等。灵活性极高，但需要更多手动配置。
- **性能方面**：Vite 的 SSR 开发模式下，模块按需编译，服务端启动和 HMR 都超快，而传统框架全量打包，启动较慢。
- **生态集成**：Vite SSR 通常结合插件（如 `vite-plugin-ssr`）来实现自动化，接近框架体验。
