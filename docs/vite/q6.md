# Q6：如何提升 Webpack 的构建速度？

- **减少 Loader 处理范围**：用 `include` 和 `exclude` 限定查找区域（如只处理 `src` 目录，排除 `node_modules`）。
- **缓存**：
  - Webpack 5 内置了持久化缓存（`cache: { type: 'filesystem' }`），二次构建速度大幅提升。
  - 对 Loader 使用 `cacheDirectory`（如 `babel-loader?cacheDirectory`）。
- **多进程/并行构建**：
  - 使用 `thread-loader` 将后续 Loader 的工作分配到 worker 池。
  - 使用 `parallel-webpack` 或社区工具。
- **优化解析**：
  - 减少 `resolve.modules` 中的路径数量。
  - 使用 `resolve.alias` 配置路径别名，减少解析时间。
  - 合理设置 `resolve.extensions`，尽量减少后缀匹配种类。
- **DLL（动态链接库）**：将不常变动的第三方库预先编译（Webpack 5 中逐渐被 SplitChunks 和持久化缓存取代）。
- **使用更快的编译工具**：如将 `babel-loader` 替换为 `esbuild-loader` 或 `swc-loader`，利用 Go/Rust 编写的编译器提速。
- **减少插件开销**：仅在必要阶段启用插件，开发环境关闭优化类插件（如压缩、分析）。
