# Q17：Vite 的插件机制是怎样的？与 Rollup 插件的关系

Vite 插件扩展了 Rollup 插件的接口，增加了 Vite 特有的钩子（如 `config`、`configureServer`、`transformIndexHtml`），同时兼容大部分 Rollup 插件。

**插件钩子分类**：
- **通用钩子**：Rollup 钩子（如 `resolveId`、`load`、`transform`），在开发和生产都执行。
- **Vite 特有钩子**：
  - `config()`：修改 Vite 配置。
  - `configureServer(server)`：配置开发服务器，可添加自定义中间件。
  - `transformIndexHtml(html)`：转换 `index.html`。
  - `handleHotUpdate(ctx)`：自定义 HMR 更新逻辑。

**开发时插件执行顺序**：Vite 使用 esbuild 预编译，但插件仍基于 Rollup 接口。生产构建直接使用 Rollup，插件工作方式与 Rollup 一致。
