# Q34：Rollup 如何处理 CommonJS 模块？`@rollup/plugin-commonjs` 做了什么？

Rollup 默认只能处理 ES Modules。当项目依赖包含 CommonJS 模块（如 `require`、`module.exports`）时，必须使用 `@rollup/plugin-commonjs`。

**该插件的工作流程**：
1. **检测**：判断 `node_modules` 中的模块是否使用 CommonJS 语法。
2. **转换**：将 CommonJS 代码转换为 ES Module 语法。它会把 `require('./foo')` 转换为 `import foo from './foo'`，把 `module.exports` 转换为 `export default` 或 `export` 命名导出。
3. **处理动态 require**：对于动态的 `require`（如 `require(varName)`），插件会将其包装成一个运行时辅助函数，因为静态导入要求路径是字符串字面量。
4. **命名导出支持**：即使原始 CJS 只有 `module.exports`，插件也会尝试分析对象的属性，生成命名导出，使 Tree Shaking 可用（引入 `namedExports` 配置）。

**使用示例**：
```javascript
import commonjs from '@rollup/plugin-commonjs';
export default {
  plugins: [commonjs()]
};
```
