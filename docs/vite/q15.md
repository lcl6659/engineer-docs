# Q15：Vite 是如何处理 CSS 的？CSS Modules 和样式注入

Vite 对 CSS 有内置支持：
- **普通 CSS**：直接导入，Vite 会自动注入到页面内联 `style` 中（HMR 支持）。
- **CSS Modules**：任何以 `.module.css` 结尾的 CSS 文件被视为 CSS Modules，导入后返回一个对象，类名被哈希化以防止冲突。
- **PostCSS**：自动读取 `postcss.config.js`，应用相关插件（如 Autoprefixer）。
- **预处理器**：支持 Sass、Less、Stylus，只需安装对应预处理器即可直接使用。
- **CSS 代码分割**：生产构建时，Vite 会将组件中的 CSS 提取到独立文件，按需加载。
