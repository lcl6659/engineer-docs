# Q9：Webpack Module Federation（模块联邦）是什么？解决了什么问题？

Module Federation 是 Webpack 5 引入的特性，允许多个独立的构建（微前端应用）在运行时共享模块，无需重新部署。

**核心概念**：
- **Host（主机）**：消费远程模块的应用。
- **Remote（远程）**：暴露模块给其他应用使用的应用。
- **Shared（共享）**：主机和远程可以共享相同的依赖（如 React），避免重复加载。
- **配置方式**：在 `plugins` 中使用 `ModuleFederationPlugin` 定义暴露和消费的模块。

**解决的问题**：
- 传统微前端往往需要复杂的胶水代码，模块联邦天然支持运行时加载依赖和组件。
- 多个团队独立开发、独立部署应用，却能共享公共库，避免全局状态同步困扰。

**示例**：
```javascript
// Remote 应用
new ModuleFederationPlugin({
  name: 'app1',
  filename: 'remoteEntry.js',
  exposes: { './Button': './src/Button' }
});
// Host 应用
new ModuleFederationPlugin({
  name: 'host',
  remotes: { app1: 'app1@http://localhost:3001/remoteEntry.js' }
});
```
