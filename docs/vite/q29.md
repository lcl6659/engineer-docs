# Q29：Rollup 是什么？它的主要特点和适用场景是什么？

Rollup 是一个 **JavaScript 模块打包器**，专门针对 ES Modules 设计，能够将小段代码编译成更大、更复杂的库或应用程序。它的核心理念是 **Tree Shaking** 和 **扁平化打包**，特别适合构建 JavaScript 库。

**主要特点**：
- **天然支持 ES Modules**：Rollup 基于 ESM 的静态结构，能够进行高效的 Tree Shaking（自动移除未使用的代码）。
- **输出多种格式**：支持输出 IIFE、CommonJS、UMD、AMD、ESM 等多种格式，通过 `output.format` 配置，一个库可以同时分发多种格式。
- **极致的扁平化**：所有模块被拍平到一个或多个 bundle 中，避免 Webpack 式的模块包裹函数，代码更简洁、可读性更好。
- **插件机制**：拥有丰富的插件生态，但核心轻量，通过插件扩展各种能力（如编译 TypeScript、处理 CSS、压缩等）。
- **代码分割**：支持动态导入 (`import()`) 进行代码分割，输出多个 chunk。

**适用场景**：
- **JavaScript 库/框架的打包**：例如 React、Vue、Lodash、D3 等知名库均使用 Rollup 构建。
- **追求极致体积和 Tree Shaking 的场景**：因为 Rollup 的 ESM 原生支持，生成的代码更易于被下游工具（如 Webpack）进一步 Tree Shake。
- **不太适合大型 Web 应用**：虽然可以，但在 HMR、代码分割、静态资源处理等方面没有 Webpack/Vite 方便，因此业务应用较少直接使用 Rollup，而是使用基于 Rollup 的上层封装（如 Vite）。
