# Q18：用什么方法优化 Vite 生产构建的体积和速度？

- **代码分割**：利用动态导入 `import()`，Vite 自动分包。
- **依赖优化**：`vite.config.js` 中 `build.rollupOptions.output.manualChunks` 自定义分包策略，将大型第三方库拆分为独立 chunk。
- **Tree Shaking**：生产构建默认开启，确保 `package.json` 中标记 `sideEffects`。
- **CSS 提取与压缩**：默认使用 `postcss` + `cssnano`，可开启 `build.cssCodeSplit`。
- **资源内联限制**：小图或字体可用 `build.assetsInlineLimit` 转为 base64 减少请求。
- **去除调试信息**：生产构建自动移除 `console` 和 `debugger`（需显式配置 `terserOptions`）。
- **利用持久缓存**：Vite 生产构建的依赖预构建结果可跨构建复用（`cacheDir`）。
- **升级至最新版**：持续获得性能提升。
