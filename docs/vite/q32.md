# Q32：Rollup 的插件机制是怎样的？有哪些常用插件？

Rollup 插件是一个对象，包含一个或多个钩子函数，用于在构建的不同阶段转换或处理模块。

**常用钩子**：
- **构建阶段**：
  - `options`：修改配置选项。
  - `buildStart`：构建开始时触发。
  - `resolveId`：自定义模块解析逻辑（如路径别名）。
  - `load`：返回模块的内容，可以接管文件读取。
  - `transform`：对每个模块源码进行转换（类似 Webpack Loader），最常用。
- **输出阶段**：
  - `renderStart`：输出开始时触发。
  - `renderChunk`：对每个 chunk 代码进行操作（如添加 banner，注入代码）。
  - `generateBundle`：生成 bundle 之后、写入磁盘之前，可修改输出内容。
  - `writeBundle`：写入磁盘后触发。

**常用官方插件**：
- `@rollup/plugin-node-resolve`：解析 `node_modules` 中的第三方模块。
- `@rollup/plugin-commonjs`：将 CommonJS 模块转换为 ESM，使 Rollup 能处理。
- `@rollup/plugin-babel`：使用 Babel 编译代码。
- `@rollup/plugin-typescript`：编译 TypeScript。
- `@rollup/plugin-terser`：压缩输出代码。
- `@rollup/plugin-json`：导入 JSON 文件。
- `@rollup/plugin-image`：导入图片并返回 base64 URL。
- `rollup-plugin-visualizer`：生成包体积可视化报告。
- `rollup-plugin-postcss`：处理 CSS。
