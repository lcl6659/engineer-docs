# Q16：Vite 中怎样配置路径别名和环境变量？

**路径别名**：
在 `vite.config.js` 中使用 `resolve.alias`：
```javascript
import { defineConfig } from 'vite';
import path from 'path';

export default defineConfig({
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src')
    }
  }
});
```

**环境变量**：
Vite 支持 `.env` 文件，只有以 `VITE_` 开头的变量会暴露给客户端代码（通过 `import.meta.env.VITE_XXX`）。这防止了服务端密钥泄露。
- `.env`：通用
- `.env.development`：开发模式
- `.env.production`：生产模式
- 服务端可使用 `process.env` 读取所有变量。
