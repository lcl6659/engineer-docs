# Q8：Webpack 中 Source Map 的常用类型及适用场景

Source Map 提供源代码与打包后代码的映射关系，方便调试。

| 类型 | 生成速度 | 精度 | 场景 |
|------|---------|------|------|
| `eval` | 很快 | 行内，可能映射不完整 | 开发环境极致速度 |
| `eval-cheap-source-map` | 较快 | 行级，无列，仅映射到转换后代码 | 开发环境，调试时不看列 |
| `eval-cheap-module-source-map` | 适中 | 行级，映射到原始源代码 | 开发环境推荐，兼顾速度和映射准确 |
| `source-map` | 最慢 | 最全（行列，原始源代码） | 生产环境（上传到监控平台） |
| `hidden-source-map` | 慢 | 同上但浏览器不加载 | 生产环境，不暴露源码但可上传监控 |
| `nosources-source-map` | 慢 | 可定位行列，但不含源码内容 | 生产环境，避免暴露源码 |

趋势：Vite 使用 `esbuild` 生成 Source Map，速度快很多。
