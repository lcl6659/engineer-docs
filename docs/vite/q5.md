# Q5：什么是 Tree Shaking？Webpack 中如何开启并使用？

Tree Shaking 是移除 JavaScript 上下文中未引用代码（Dead Code）的过程，依赖于 ES6 的静态模块结构（`import`/`export`）。

**Webpack 开启条件**：
1. 使用 ES Modules（`import` / `export`）语法，而不是 CommonJS。
2. 在 `webpack.config.js` 中设置 `mode: 'production'`（生产模式默认开启）。
3. 确保没有编译器将 ES6 模块转换为 CommonJS（Babel 的 `@babel/preset-env` 需设置 `modules: false`）。
4. 在 `package.json` 中配置 `"sideEffects": false`，或指定包含副作用的文件列表（如 CSS 文件、polyfill）。这告诉 Webpack 哪些文件可以安全地 pruning。

**注意事项**：
- 如果代码有副作用（如导入时执行全局修改），即使没有被导出使用，也不能被移除，需要标记在 `sideEffects` 中。
- Tree Shaking 只能在静态结构下工作，无法处理动态引用。
