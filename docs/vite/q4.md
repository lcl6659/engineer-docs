# Q4：Webpack 中如何配置代码分割（Code Splitting）？有哪几种方式？

代码分割可以将代码拆分为多个 bundle，实现按需加载和并行加载，优化首屏速度。

**三种主要方式**：

1. **入口起点（Entry Points）**：通过配置多个入口手动分割代码。
   ```javascript
   module.exports = {
     entry: {
       app: './src/app.js',
       admin: './src/admin.js'
     }
   };
   ```
   缺点：存在公共模块重复打包问题。

2. **防止重复（SplitChunksPlugin）**：将公共依赖提取到共享 chunk。
   ```javascript
   optimization: {
     splitChunks: {
       chunks: 'all',
       minSize: 20000,   // 最小体积，小于此不分割
       cacheGroups: {
         vendors: {
           test: /[\\/]node_modules[\\/]/,
           priority: -10,
           name: 'vendors'
         },
         common: {
           minChunks: 2,  // 被引用次数
           priority: -20,
           reuseExistingChunk: true
         }
       }
     }
   }
   ```

3. **动态导入（Dynamic Imports）**：使用 `import()` 语法，Webpack 会自动将被导入的模块分离到一个独立 Chunk，在需要时加载。
   ```javascript
   button.addEventListener('click', () => {
     import('./module').then(module => {
       module.default();
     });
   });
   ```
   这是最常见的代码分割方式，配合框架的路由懒加载使用。
