# Q25：Vite SSR 中如何处理 CSS 和静态资源？

在 SSR 场景中：
- **CSS**：服务端渲染时，CSS 通常需要收集并内联到 HTML 中，或提取为独立文件，在客户端激活前引入。
  - Vite 开发时，通过 `renderToString` 后，`useSSRContext()` 中能拿到 CSS 代码，可直接以内联 `style` 注入 HTML。
  - 生产构建时，通过 `build.cssCodeSplit` 结合 Manifest 文件自动处理。
- **静态资源（图片、字体等）**：SSR 期间，Vite 的 `transformIndexHtml` 和构建策略会将资源路径替换为带哈希的绝对路径。需要使用 `assetsInclude` 进行配置。
- **实践**：使用 `vite-plugin-ssr` 这类成熟插件可简化这些处理。
