# Q20：如何编写一个自定义的 Webpack Loader？有哪些核心要素？

Loader 是导出单一函数的 Node.js 模块。Webpack 调用这个函数，将源文件内容作为参数传入，经过处理后返回转换后的内容。

**核心要素**：
- **同步 Loader**：返回转换后的内容（字符串或 Buffer）。若有错误，使用 `this.callback(err, result, sourceMap, meta)`。
- **异步 Loader**：使用 `const callback = this.async();` 在函数体内获取回调，操作完成后调用 `callback(err, result)`。
- **`this` 上下文**：提供大量有用方法，如 `this.cacheable()` 标识可缓存，`this.emitFile()` 产出文件，`this.resourcePath` 当前资源路径。
- **可链式调用**：多个 Loader 从右到左（或下到上）串联。前一个 Loader 的输出作为下一个 Loader 的输入。

**示例 —— 一个移除 `console.log` 的 Loader**：
```javascript
module.exports = function (source) {
  // 标记可缓存
  this.cacheable();
  // 替换 console.log
  const result = source.replace(/console\.log\(.*?\);?/g, '');
  return result;
};
```

**使用**：
```javascript
module: {
  rules: [
    { test: /\.js$/, use: ['remove-console-loader'] }
  ]
}
```
