# Q21：如何编写一个自定义的 Webpack Plugin？

Plugin 是带有 `apply` 方法的类，通过监听 Webpack 生命周期钩子来执行任务。

**核心步骤**：
1. 定义一个类，实现 `apply(compiler)` 方法。
2. 在 `apply` 内部，通过 `compiler.hooks` 订阅合适的钩子事件。`compiler` 贯穿整个构建过程。
3. 常用钩子：
   - `compile`：开始编译。
   - `compilation`：新的 compilation 创建（可使用 compilation 钩子）。
   - `emit`：输出文件之前（可修改输出内容）。
   - `done`：构建完成。
4. 通过 `compilation` 对象可以访问模块、chunk、资源文件 (`assets`) 等信息。

**示例 —— 一个生成版权注释的 Plugin**：
```javascript
class CopyrightPlugin {
  constructor(options) { this.options = options; }

  apply(compiler) {
    compiler.hooks.emit.tapAsync('CopyrightPlugin', (compilation, callback) => {
      // 遍历所有即将输出的资源
      const assets = compilation.assets;
      for (let filename in assets) {
        if (filename.endsWith('.js')) {
          const source = assets[filename].source();
          const newSource = `/*! ${this.options.banner} */\n${source}`;
          compilation.assets[filename] = {
            source: () => newSource,
            size: () => newSource.length
          };
        }
      }
      callback();
    });
  }
}

// 使用
plugins: [new CopyrightPlugin({ banner: '版权所有' })]
```
