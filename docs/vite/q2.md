# Q2：Webpack 的构建流程是怎样的？

Webpack 的构建是**事件驱动**的，核心流程如下：

1. **初始化参数**：合并配置文件和命令行参数，生成最终配置对象。
2. **创建 Compiler**：用合并后的配置实例化 `Compiler` 对象，并注册所有配置的插件。Compiler 贯穿整个构建生命周期。
3. **开始编译**：调用 `compiler.run()` 开始构建。触发 `beforeRun` 和 `run` 钩子。
4. **确定入口**：根据 Entry 配置找到所有入口文件。
5. **编译模块**：从入口文件出发，调用匹配的 **Loader** 对模块进行转译，然后递归地解析该模块所依赖的其他模块，直到所有模块都被处理。每个模块都会生成对应的 `Module` 对象。
6. **完成模块编译**：所有模块处理完毕后，得到每个模块的编译后内容和依赖关系。
7. **输出资源（Seal）**：根据入口和模块依赖图，组装成包含多个 `Chunk` 的输出结构。此阶段进行代码优化（如 Tree Shaking、代码压缩）。
8. **写入文件（Emit）**：根据 Output 配置，将每个 Chunk 的内容写入文件系统。在写入前，可以通过插件钩子修改输出内容。

在这个过程中，多个钩子（Hooks）被触发，插件可以在特定阶段介入，实现各种定制功能。
