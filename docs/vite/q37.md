# Q37：Rollup 的 `watch` 模式是如何工作的？与 Vite/Webpack 的 Dev Server 有何不同？

Rollup 提供了 `--watch` 或 `rollup -w` 选项开启监听模式。

- **原理**：通过文件系统监听（`chokidar`）检测源文件变动，当文件变化时重新执行构建流程，将新产物写入磁盘。
- **与 Dev Server 区别**：Rollup 的 watch 只是**增量重新构建并写文件**，本身不启动开发服务器、不提供 HMR、不服务静态资源。你要配合其他工具（如 `rollup-plugin-serve`、`rollup-plugin-livereload` 或使用 `browser-sync`）来获得类似体验。

Vite 和 Webpack Dev Server 则集成了 WebSocket、模块热替换，并且将模块保留在内存中，速度更快。因此，Rollup 在应用开发时体验不如 Vite，这也是为什么 Vite 使用了 Rollup 的生产构建能力，但开发服务完全自研。
