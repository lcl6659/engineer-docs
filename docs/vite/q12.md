# Q12：Vite 的预构建（Pre-bundling）做了什么？为什么需要它？

Vite 启动时，会使用 **esbuild** 对 `node_modules` 中的依赖进行预构建，生成到 `node_modules/.vite` 目录。

**作用**：
- **转换 CJS/UMD 为 ESM**：许多 npm 包是 CommonJS 或 UMD 格式，浏览器无法直接执行，需要转换为 ES Modules。
- **减少模块请求数**：当一个库包含多个内部文件（如 `lodash` 包含数百个函数文件），Vite 将其合并为少量 ESM 模块，减少浏览器发起的请求数量，避免网络瀑布。
- **缓存**：预构建结果被缓存，只有在依赖变化（`package-lock.json` 变化）时才重新构建，二次启动近乎秒开。
