# Q1：Webpack 是什么？它的核心概念有哪些？

### Webpack 核心

Webpack 是一个现代 JavaScript 应用的**静态模块打包器（Static Module Bundler）**。它会从入口开始，递归地构建一个依赖图（Dependency Graph），将项目中的所有模块（JS、CSS、图片、字体等）打包成一个或多个 bundle，供浏览器使用。

**核心概念**：
- **Entry（入口）**：Webpack 构建依赖图的起点。可以有一个或多个入口（多页应用）。
- **Output（输出）**：告诉 Webpack 打包后的文件输出到哪里，以及如何命名。
- **Loader（加载器）**：让 Webpack 能够处理非 JavaScript 文件（如 CSS、图片、TypeScript、JSX）。本质是一个转换函数，将源文件转换为有效模块。
- **Plugin（插件）**：用于执行更广泛的任务，如打包优化、资源管理、注入环境变量等。插件通过钩子机制触及 Webpack 编译的整个生命周期。
- **Module（模块）**：Webpack 中一切皆模块，每个文件都是一个模块。
- **Chunk（代码块）**：由多个模块组合而成，用于代码分割（Code Splitting）。一个 Chunk 可能对应一个最终的输出文件。
