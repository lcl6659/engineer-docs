# Q23：Vite 如何支持 SSR（服务端渲染）？整体流程是怎样的？

### Vite SSR（服务端渲染）

Vite 对 SSR 提供了一等支持，允许使用类似开发时的按需编译能力，在服务端渲染组件或页面。

**流程**：
1. **构建层面**：Vite 针对 SSR 提供独立的构建配置（`build.ssr`）。服务端入口通常是一个 Node.js 程序，通过 `createSSRApp` 渲染 Vue/React 组件为字符串。
2. **开发时**：Vite 开发服务器将浏览器端和服务器端模块都转译成 ESM，Node 进程通过 `createServer` 获取 `viteDevServer` 实例，使用 `ssrLoadModule` 来加载页面组件（类似浏览器请求，处理 HMR）。
3. **生产时**：先运行 `vite build --ssr` 产出服务端 bundle（CommonJS），然后用 `vite build` 产出客户端 bundle。Node 服务器直接加载服务端 bundle 并调用渲染。
4. **数据获取与脱水注水**：
   - 服务端在渲染前获取数据，将数据注入到 `window.__INITIAL_STATE__` 中（脱水）。
   - 客户端激活时读取该全局变量更新状态（注水）。

**示例（Vue）**：
```javascript
// server.js
import { createSSRApp } from 'vue';
import { renderToString } from '@vue/server-renderer';

async function render(url) {
  const app = createSSRApp(App);
  const html = await renderToString(app);
  return html;
}
```
