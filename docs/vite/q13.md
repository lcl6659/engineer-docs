# Q13：Vite 的生产构建为什么选择 Rollup？

开发时 Vite 利用浏览器 ESM，不需要打包，但在生产环境为了性能，仍需打包优化。Vite 选择 **Rollup** 作为生产构建引擎：

- **完善的 ESM 支持**：Rollup 天然基于 ES Modules，能生成最佳的 Tree Shaking 结果。
- **丰富的生态插件**：Rollup 插件可复用，社区成熟。
- **对库和应用的优化**：Rollup 对代码分割、Tree Shaking 和输出格式的支持非常优秀，适合现代前端项目。

Vite 相当于将开发时的极速体验用 esbuild + ESM，将生产时的精细优化交给了 Rollup。
