# Q22：编写 Loader 和 Plugin 分别需要注意哪些调试技巧？

- **Loader 调试**：
  - 可以通过 `this.callback` 返回错误，或在控制台 `console.log`（开发环境可见）。
  - 借助 `loader-utils` 的 `getOptions` 获取配置参数。
  - 使用 `schema-utils` 验证选项。
  - 编写测试用例，使用 `webpack` 的 Node API 运行编译并检查输出。
- **Plugin 调试**：
  - 充分利用 `compiler.hooks` 的生命周期顺序，结合 `console.log` 输出各个阶段信息。
  - 使用 `compiler.getInfrastructureLogger()` 输出结构化日志。
  - 借助 `compilation.getStats()` 分析模块图。
  - IDE 中可以直接调试 Node 进程，加入 `--inspect-brk` 启动 Webpack 即可断点。
