# Q11：Vite 的开发服务器为什么这么快？

1. **按需编译（On-demand Compilation）**：利用浏览器原生的 ES Modules，Vite 不需要打包整个应用。当浏览器请求某个 JS/TS/CSS 文件时，Vite 即时编译并返回。避免了传统打包器那庞大的提前打包步骤。
2. **依赖预构建（Pre-bundling）**：用 **esbuild**（Go 编写，极快）将 CommonJS/UMD 模块转换为 ESM 格式，并合并分散的模块（如 lodash 上百个文件），减少请求瀑布。
3. **esbuild 编译器**：TypeScript、JSX 等转换由 esbuild 完成，速度比传统 Babel 快 10~100 倍。
4. **精简的插件系统**：Vite 插件基于 Rollup 接口，相比 Webpack 拥有更少的钩子开销，同时在开发时仅应用最小必要的转换。
5. **缓存**：编译结果被 HTTP 头部缓存（304），且 Vite 内部缓存模块转换结果。
