# Q28：大型项目的构建速度优化策略总结（Webpack/Vite 通用思路）

1. **减少文件处理范围**：通过 `include/exclude` 限制 Loader 作用域。
2. **缓存利用**：Webpack 持久化缓存 (`cache.type: 'filesystem'`)，Vite 预构建缓存和浏览器 HTTP 缓存。
3. **并行处理**：使用多进程加载/压缩（thread-loader, esbuild, swc）。
4. **更高效的编译器**：替换 Babel 为 `esbuild-loader` 或 `@swc/jest`；Vite 已经使用 esbuild 预构建。
5. **按需编译/加载**：利用动态导入 (`import()`) 做路由懒加载。
6. **依赖瘦身**：分析包体积，移除未使用的依赖，使用 `lodash-es` 等具名导出。
7. **外部化不常变动的库**：使用 Externals 或 CDN。
8. **合理的 Source Map 策略**：开发环境用 `eval-cheap-module-source-map`，生产环境用 `source-map` 但不暴露给浏览器。
9. **分包策略**：通过 SplitChunks 或 Vite 的 `manualChunks` 提取公共代码，避免重复打包。
10. **监控与 CI**：设置性能预算（Performance Budget），在 CI 中自动警告体积超限。
