# Q11：JavaScript 的数据类型有哪些？`typeof` 和 `instanceof` 的区别？

**数据类型**
- **基本类型（7种）**：`Number`, `String`, `Boolean`, `undefined`, `null`, `Symbol`, `BigInt`。数据存储于栈内存，按值访问。
- **引用类型**：`Object`（包含 `Array`, `Function`, `Date`, `RegExp` 等）。存储于堆内存，变量保存的是指向堆内存的引用地址。

**`typeof` 运算符**
- 能准确判断基本类型，但有两个著名“陷阱”：
  - `typeof null === 'object'` （历史遗留 bug）
  - `typeof function(){} === 'function'` （在对象里特殊处理）
- 无法细分 `Array`、`Date`、正则等，它们都返回 `'object'`。

**`instanceof` 运算符**
- 用于检测构造函数的 `prototype` 属性是否出现在某个实例对象的原型链上。
- `[] instanceof Array` 为 `true`，`new Date() instanceof Object` 也为 `true`。
- 适合判断引用类型的归属，但对基本类型（字面量）不能直接判断，如 `'hello' instanceof String` 为 `false`。
- 可以通过 `Object.prototype.toString.call()` 准确获取类型：`[object Array]`。
