# Q24：手写防抖（debounce）和节流（throttle）

以下为补充的高频手写代码题。

**防抖**  
事件触发 n 秒后才执行，如果在一个周期内再次触发，则重新计时。适用场景：搜索框输入、窗口 resize。

```javascript
function debounce(func, wait, immediate = false) {
  let timer;
  return function (...args) {
    const context = this;
    if (timer) clearTimeout(timer);
    if (immediate) {
      const callNow = !timer;
      timer = setTimeout(() => { timer = null; }, wait);
      if (callNow) func.apply(context, args);
    } else {
      timer = setTimeout(() => { func.apply(context, args); }, wait);
    }
  };
}
```

**节流**  
持续触发事件，每隔一段时间只执行一次。适用场景：滚动加载、mousemove。

```javascript
function throttle(func, wait) {
  let lastTime = 0;
  return function (...args) {
    const now = Date.now();
    if (now - lastTime >= wait) {
      lastTime = now;
      func.apply(this, args);
    }
  };
}
// 或者用定时器版本
```
