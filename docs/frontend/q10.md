# Q10：移动端 1px 边框为什么会变粗？如何解决？

**问题原因**：  
在高清屏（Retina）下，`window.devicePixelRatio > 1`（比如 DPR=2）。意味着 1 个 CSS 像素会用 2×2 个物理像素来渲染。当设置 `border: 1px` 时，实际显示的是 2 个物理像素的宽度，所以看起来边框更粗。

**常见解决方案**：
1.  **伪元素 + `transform: scale`（最常用）**  
    为元素添加伪元素 `::after`，设为 `border: 1px`，然后通过 `transform: scale(0.5)` 缩放（当 DPR=2 时），并以 `transform-origin` 调整位置。此方法兼容性好且简单。
2.  **Viewport 的 `initial-scale`**  
    在 meta 标签中，根据 DPR 设置 `initial-scale=0.5`、`maximum-scale=0.5`，并配合 CSS 写 `1px`。但全局缩放会影响整个页面，可能干扰其他布局。
3.  **图片实现**  
    用 `border-image` 或 `background-image` 引入半透明线条。缺点是颜色修改不便。
4.  **使用 `box-shadow` 模拟**  
    `box-shadow: 0 0 0 0.5px #000`，但半像素渲染在不同浏览器上表现有差异。
