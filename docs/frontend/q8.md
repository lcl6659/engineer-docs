# Q8：Flex 布局常见属性及 `flex: 1` 的含义

Flex 布局是一维布局模型，容器和项目都有对应属性。

**容器属性（父元素）**：
- `flex-direction`：主轴方向（`row` | `column`）。
- `flex-wrap`：是否换行。
- `justify-content`：主轴对齐。
- `align-items`：交叉轴单行对齐。
- `align-content`：多根轴线的对齐方式。

**项目属性（子元素）**：
- `flex-grow`：放大比例，默认 0，有剩余空间也不放大。
- `flex-shrink`：缩小比例，默认 1，空间不足时会缩小。
- `flex-basis`：项目初始主轴尺寸，默认 `auto`（元素本来的大小）。
- `flex`：简写属性，推荐使用。
- `align-self`：可覆盖父元素的 `align-items`。

**`flex: 1` 的秘密**  
`flex: 1` 是 `flex: 1 1 0%` 的简写。意为：
- `flex-grow: 1`：有剩余空间就放大。
- `flex-shrink: 1`：空间不足就缩小。
- `flex-basis: 0%`：项目在分配空间前的基础尺寸为 0。  
这使得所有设置 `flex: 1` 的子元素会**严格按照比例均分容器剩下的所有空间**，而忽略内容自身宽度，非常适合等分布局。
