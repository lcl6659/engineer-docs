# Q9：Grid 布局与 Flex 布局的区别

| 特性 | Flexbox | Grid |
|------|---------|------|
| **维度** | 一维布局（行或列） | 二维布局（行与列同时） |
| **控制力** | 基于轴线，内容驱动 | 基于网格，固定或弹性轨道 |
| **适用场景** | 导航栏、组件内元素排列、居中 | 复杂页面整体布局、等分网格、重叠元素 |
| **对齐** | 主/交叉轴对齐 | 行/列两条轴都提供 `justify/align` 属性 |
| **重叠** | 较难实现元素重叠 | 可以使用 `grid-area` 轻松实现重叠 |

简单说：**Flex 擅长处理一个方向上的排列和空间分配，Grid 擅长处理同时有行和列的二维布局**。两者可以互补，经常在组件内部用 Flex，在页面大框架用 Grid。
