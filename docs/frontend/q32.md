# Q32：用 `setTimeout` 模拟 `setInterval`

`setInterval` 具有累积效应，模拟版可控制间隔稳定。

```javascript
function mySetInterval(fn, delay) {
  let timer = null;
  function interval() {
    fn();
    timer = setTimeout(interval, delay);
  }
  timer = setTimeout(interval, delay);
  return {
    clear: () => clearTimeout(timer)
  };
}
```
