# Q16：异步编程的演进：回调、Promise、async/await

**回调函数**  
早期处理异步，但容易产生“回调地狱”，代码难以维护，错误处理复杂。

**Promise**  
解决了回调地狱和信任问题。
- 三种状态：`pending`（待定）、`fulfilled`（已兑现）、`rejected`（已拒绝），状态一旦变化就不可逆。
- 实例方法：`.then()` 返回新 Promise 实现链式调用；`.catch()` 捕获错误；`.finally()` 执行收尾。
- 静态方法：`Promise.all()`（全部成功才成功）、`Promise.race()`（一个完成就决定）、`Promise.allSettled()`（所有都落定）、`Promise.any()`（任一成功）。
- 缺点：依旧有链式调用，不够优雅，且错误需要用 `.catch` 捕获。

**async/await**  
ES7 引入，是 **Generator + Promise 的语法糖**。用同步的方式写异步代码。
- `async` 函数返回 Promise。
- `await` 会暂停函数执行，等待 Promise 结果。
- 错误用 `try/catch` 包裹，更加直观。
- 注意 `await` 循环中的并行与串行处理。
