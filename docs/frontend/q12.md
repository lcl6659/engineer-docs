# Q12：原型与原型链是什么？

- **原型对象**：每一个函数在创建时都会有一个 `prototype` 属性，指向该函数（作为构造函数）创建的所有实例对象共享的*原型对象*。
- **`__proto__`（隐式原型）**：每个对象（除 null 外）都有 `__proto__` 属性，指向它构造函数的 `prototype`。  
  实例的 `__proto__ === 构造函数.prototype`。
- **原型链**：当访问一个对象的属性或方法时，如果自身没有，就会沿着 `__proto__` 向上查找，直到找到或到达 `null`。这条链路就叫原型链。
- **终点**：`Object.prototype.__proto__ === null`。
- **作用**：实现了 JavaScript 的继承机制。所有对象都继承了 `Object.prototype` 上的方法（如 `toString()`），数组实例则共享 `Array.prototype` 上的方法。

**经典图景**：
```
function Person() {}
let p = new Person();
// p.__proto__ === Person.prototype
// Person.prototype.__proto__ === Object.prototype
// Object.prototype.__proto__ === null
```
