# Q12：原型与原型链是什么？

- **原型对象**：每一个函数在创建时都会有一个 `prototype` 属性，指向该函数（作为构造函数）创建的所有实例对象共享的*原型对象*。
- **`__proto__`（隐式原型）**：每个对象（除 null 外）都有 `__proto__` 属性，指向它构造函数的 `prototype`。  
  实例的 `__proto__ === 构造函数.prototype`。
- **原型链**：当访问一个对象的属性或方法时，如果自身没有，就会沿着 `__proto__` 向上查找，直到找到或到达 `null`。这条链路就叫原型链。
- **终点**：`Object.prototype.__proto__ === null`。
- **作用**：实现了 JavaScript 的继承机制。所有对象都继承了 `Object.prototype` 上的方法（如 `toString()`），数组实例则共享 `Array.prototype` 上的方法。

**经典图景**：
```
function Person() {}
let p = new Person();
// p.__proto__ === Person.prototype
// Person.prototype.__proto__ === Object.prototype
// Object.prototype.__proto__ === null
```

## 原型与原型链（详解）

在 JavaScript 中，原型（prototype）和原型链（prototype chain）是实现继承、共享属性和方法的核心机制。理解它们，才能真正掌握 JavaScript 的面向对象编程。

---

### 一、为什么需要原型？

假设我们创建多个相同类型的对象（比如多个“人”对象），每个对象都有 `sayHello` 方法。如果每个对象都单独存储一个 `sayHello` 函数，会浪费大量内存。

**解决方案**：把公共的方法放到一个共享的地方，每个对象通过某种引用找到它。  
这个共享的地方就是**原型对象**。

---

### 二、核心概念：`prototype` 与 `__proto__`

1. **`prototype`**：  
   每个**函数**（除了箭头函数）天生自带一个 `prototype` 属性。  
   这个属性是一个对象，用来存放**通过该函数创建的实例** 共享的属性和方法。

2. **`__proto__`**（隐式原型）：  
   每个**对象**（包括函数对象）都有一个 `__proto__` 属性（ECMAScript 规范中叫 `[[Prototype]]`），指向它的构造函数的 `prototype`。  
   > 注：`__proto__` 是浏览器实现的非标准属性，实际开发中推荐用 `Object.getPrototypeOf()` 和 `Object.setPrototypeOf()`。

3. **`constructor`**：  
   每个 `prototype` 对象内部都有一个 `constructor` 属性，指向该构造函数本身。

---

### 三、一个例子帮你理清关系

```javascript
// 构造函数
function Person(name) {
  this.name = name;
}
// 在原型上添加共享方法
Person.prototype.sayHello = function() {
  console.log(`Hello, I'm ${this.name}`);
};

// 创建实例
const p1 = new Person('Alice');
const p2 = new Person('Bob');

console.log(p1.sayHello === p2.sayHello); // true - 共享同一个方法
```

**关系图（文字描述）**：
- `p1.__proto__` === `Person.prototype`
- `Person.prototype.constructor` === `Person`
- `Person.prototype.__proto__` === `Object.prototype`
- `Object.prototype.__proto__` === `null`（原型链的终点）

```text
p1 ---> Person.prototype ---> Object.prototype ---> null
        ^
        |
     (constructor: Person)
```

---

### 四、什么是原型链？

**当访问一个对象的属性时，如果该对象自身没有这个属性，JavaScript 引擎会沿着 `__proto__` 链向上查找，直到找到该属性或到达原型链的终点（`null`）。**

这个查找的链条就是 **原型链**。

**示例**：
```javascript
function Animal() {}
Animal.prototype.eat = function() { console.log('eating'); };

function Dog() {}
Dog.prototype = Object.create(Animal.prototype); // 继承
Dog.prototype.bark = function() { console.log('barking'); };

const d = new Dog();
d.bark();   // 自身有 → 打印 barking
d.eat();    // 自身没有 → 沿原型链找到 Animal.prototype.eat → 打印 eating
d.toString(); // 自身没有 → Dog.prototype → Animal.prototype → Object.prototype.toString
```

**查找路径**：  
`d` → `Dog.prototype` → `Animal.prototype` → `Object.prototype` → `null`

---

### 五、原型链的最终终点

所有普通对象的原型链终点是 `Object.prototype`，而 `Object.prototype.__proto__` 是 `null`。  
`null` 没有任何属性，查找到此结束，如果依然没找到则返回 `undefined`。

---

### 六、原型链的作用

1. **实现继承**：子类可以共享父类原型上的方法，避免重复代码。
2. **动态扩展**：随时可以在原型上添加方法，所有实例立即生效（包括已创建的）。
3. **节省内存**：公共方法只存一份。

---

### 七、常见误区与注意点

1. **`__proto__` 不等于 `prototype`**：
   - `prototype` 是函数才有的属性。
   - `__proto__` 是所有对象都有的，指向其构造函数的 `prototype`。

2. **原型链的性能**：沿链查找属性比直接访问自身属性慢，深层嵌套会影响性能。

3. **不要滥用 `Object.prototype` 扩展**：会污染全局原型，可能引发冲突。

4. **判断属性是自身还是继承来的**：
   - `hasOwnProperty()`：返回 true 表示是对象自身属性，不沿原型链查找。
   - `in` 操作符：会沿原型链查找。

   ```javascript
   p1.hasOwnProperty('name');        // true
   p1.hasOwnProperty('sayHello');    // false
   'sayHello' in p1;                 // true
   ```

5. **创建对象且不希望有原型**：可以用 `Object.create(null)`，这样 `__proto__` 为 `null`。

---

### 八、如何设置原型链继承（ES5 方式）

```javascript
function Parent(age) {
  this.age = age;
}
Parent.prototype.sayAge = function() {
  console.log(this.age);
};

function Child(name, age) {
  Parent.call(this, age);   // 继承实例属性
  this.name = name;
}
// 继承原型方法
Child.prototype = Object.create(Parent.prototype);
Child.prototype.constructor = Child;  // 修复 constructor 指向

const c = new Child('Tom', 10);
c.sayAge(); // 10
```

ES6 中使用 `class` / `extends` 语法糖，底层仍然是基于原型链。

### 九、原型与原型链的经典面试题

```javascript
function Foo() {}
const f = new Foo();

console.log(f.constructor === Foo);           // true
console.log(Foo.prototype.constructor === Foo);// true
console.log(f.__proto__ === Foo.prototype);   // true
console.log(Foo.prototype.__proto__ === Object.prototype); // true
console.log(Object.prototype.__proto__);      // null
console.log(Foo.__proto__ === Function.prototype); // true（函数也是对象）
console.log(Function.prototype.__proto__ === Object.prototype); // true
```

### 十、总结

| 概念 | 解释 |
|------|------|
| **原型** | 一个对象，用于存放共享属性和方法。每个函数都有 `prototype` 属性指向它。 |
| **隐式原型 `__proto__`** | 每个对象都有的内部链接，指向其构造函数的 `prototype`。 |
| **原型链** | 对象通过 `__proto__` 串联起来的链式结构，用于属性/方法查找。 |
| **作用** | 实现继承、属性共享、节省内存。 |

理解原型和原型链后，你就掌握了 JavaScript 对象系统的核心，也能轻松看懂基于原型的继承代码、调试属性访问问题。
