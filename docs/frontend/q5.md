# Q5：盒模型有哪些？`box-sizing` 如何使用？

盒模型是 CSS 布局的基石，由内而外：`content`（内容） → `padding`（内边距） → `border`（边框） → `margin`（外边距）。

- **W3C 标准盒模型（content-box）**  
  `box-sizing` 默认为 `content-box`。此时，`width` 和 `height` 只包括内容区域，元素的实际占用宽度 = `width + padding + border + margin`。

- **IE 怪异盒模型（border-box）**  
  `box-sizing: border-box`。`width` 和 `height` 包括了内容、内边距和边框的尺寸。实际内容宽度 = `width - padding - border`。这种模式更符合直觉，便于控制元素整体尺寸，简化布局计算。

**最佳实践**：通常我们会在全局样式中设置 `*, *::before, *::after { box-sizing: border-box; }` 以避免尺寸计算混乱。
