# Q14：`this` 指向的确定规则

`this` 是函数内部的特殊关键字，指向调用它的上下文。其值不是在定义时确定，**而是在函数调用时根据调用方式决定的**，但有特殊情况：

1.  **全局下**：严格模式下 `this` 为 `undefined`，非严格模式指向 `window`（浏览器）。
2.  **作为对象方法调用**：指向该对象（谁调用指向谁）。
3.  **作为普通函数调用**：严格模式 `undefined`，非严格 `window`。
4.  **箭头函数**：没有自己的 `this`，会捕获**定义时**外层作用域的 `this`，且一经绑定不可用 `call/apply/bind` 改变。
5.  **`call` / `apply` / `bind`**：显式绑定 `this`。`bind` 会返回一个新函数，永久绑定。
6.  **作为构造函数（`new`）**：`this` 指向新创建的实例对象。
7.  **事件处理函数**：指向绑定事件的 DOM 元素。

**优先级**：`new` 绑定 > 显式绑定 > 隐式绑定 > 默认绑定（其中箭头函数是词法绑定，优先级不适用）。
