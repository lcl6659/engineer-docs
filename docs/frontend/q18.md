# Q18：HTTP 协议各版本及常用状态码

**版本差异**
- **HTTP/1.0**：需要请求头 `Connection: keep-alive` 才能保持连接，默认短连接。
- **HTTP/1.1**：引入持久连接、管线化（队头阻塞问题仍在）、增加 Host 头、缓存机制增强。
- **HTTP/2**：基于二进制分帧，实现多路复用（同连接并发请求/响应，解决队头阻塞）、头部压缩（HPACK）、服务器推送。
- **HTTP/3**：基于 QUIC（UDP），0-RTT 握手，彻底解决 TCP 层面的队头阻塞，改进移动网络性能。

**常用状态码**
- **2xx 成功**：200 成功，201 已创建，204 无内容。
- **3xx 重定向**：301 永久移动，302 临时移动，304 未修改（走缓存）。
- **4xx 客户端错误**：400 请求语法错误，401 未认证，403 禁止访问，404 未找到，405 方法不允许。
- **5xx 服务器错误**：500 内部错误，502 网关错误，503 服务不可用。
