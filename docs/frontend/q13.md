# Q13：作用域与闭包详解

**作用域**  
决定了变量的可访问范围。分为：
- **全局作用域**：任何地方都能访问。
- **函数作用域**：只在函数内部可访问。
- **块级作用域**：ES6 提供的 `let` 和 `const` 使得 `{ }` 内部形成作用域。

**闭包**  
**定义**：当一个函数能够记住并访问它被创建时的词法作用域，即使它在其他地方执行，这个函数连同这段作用域引用就构成了闭包。

**经典例子**：
```javascript
function outer() {
  let count = 0;
  return function inner() {
    count++;
    console.log(count);
  };
}
const fn = outer();
fn(); // 1
fn(); // 2
```
即使 `outer` 执行完了，其内部变量 `count` 仍保留在 `inner` 函数的作用域链中，不会被垃圾回收。

**应用**：
- **数据私有化/模块化**：隐藏变量，只暴露接口。
- **函数工厂**：柯里化。
- **经典 for 循环问题**：用闭包保存 `i` 的值，或用 `let` 创建块级作用域解决。

**注意**：闭包可能造成内存泄漏（变量未释放），需合理管理生命周期。
