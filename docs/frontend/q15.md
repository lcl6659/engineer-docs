# Q15：事件循环（Event Loop）机制详解

JavaScript 是单线程的，需要事件循环来处理异步操作。

- **执行栈**：同步代码在主线程上执行，形成一个执行栈。
- **任务队列**：异步任务完成后，回调函数进入队列等待执行。分为：
  - **宏任务队列**：script 整体、`setTimeout`、`setInterval`、I/O、UI 渲染、`postMessage` 等。
  - **微任务队列**：`Promise.then/catch/finally`、`MutationObserver`、`queueMicrotask`。

**事件循环流程**：
1. 执行一个宏任务（初始是 script 主代码）。
2. 执行过程中产生的微任务进入微任务队列。
3. 当前宏任务执行完毕后，**清空微任务队列**中的所有任务。
4. 浏览器判断是否需要渲染更新（通常一帧一次）。
5. 从宏任务队列中取出下一个宏任务，重复上述过程。

**常见考点**：为什么 `Promise` 的回调比 `setTimeout` 早？因为 `Promise.then` 是微任务，在下一个宏任务之前就清空了。
