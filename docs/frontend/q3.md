# Q3：`<script>` 标签的 async 与 defer 有什么区别？

解析 HTML 时，遇到普通 `<script>` 会停止解析，下载并执行 JS，执行完再继续解析。`async` 和 `defer` 改变了这一行为。

| 类型 | 下载时机 | 执行时机 | 执行顺序 | 对解析阻塞 |
|------|---------|---------|---------|----------|
| **无属性** | 立即下载 | 下载后立即执行 | 文档中顺序 | 阻塞解析，直到执行完 |
| **defer** | 立即下载，异步 | 在 HTML 解析完成后，`DOMContentLoaded` 事件前执行 | 按文档顺序执行 | 不阻塞解析 |
| **async** | 立即下载，异步 | 下载完成后立即执行，可能在任何时刻 | 无法保证顺序，谁先下完谁执行 | 执行时会阻塞解析 |

- `defer` 适用于互相依赖且需要操作 DOM 的脚本，确保在 DOM 构建完毕后按顺序执行。
- `async` 适合独立脚本，如统计、广告，不需要依赖其他脚本和 DOM 结构。
