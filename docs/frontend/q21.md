# Q21：Cookie、localStorage、sessionStorage、IndexedDB 对比

| 特性 | Cookie | localStorage | sessionStorage | IndexedDB |
|------|--------|-------------|---------------|-----------|
| **存储大小** | 约 4KB | 约 5MB | 约 5MB | 大容量（数百MB） |
| **生命周期** | 可设过期时间；若不设，会话期有效 | 永久，除非手动清除 | 标签页关闭即清除 | 永久，需手动删除 |
| **与服务器通信** | 每次 HTTP 请求自动携带在 Cookie 头中 | 不自动发送 | 不自动发送 | 不自动发送 |
| **作用域** | 同源，可设 path | 同源 | 同源且同一标签页 | 同源 |
| **易用性** | 操作麻烦，需封装 | 同步 API，简单 | 同步 API，简单 | 异步 API，强大，支持事务和索引 |
| **应用场景** | 维持登录状态、少量标识 | 持久化用户设置、主题 | 临时表单数据 | 离线应用、大量结构化数据 |

注意：Cookie 设置 `HttpOnly` 可防 XSS 读取，`Secure` 只在 HTTPS 传输，`SameSite` 防 CSRF。
