# Q7：CSS 中水平垂直居中的各种方法

**水平居中**
- **行内元素/文本**：父元素 `text-align: center`。
- **块级元素**：自身 `margin: 0 auto`（需设定宽度）。
- **Flexbox**：父元素 `display: flex; justify-content: center`。
- **绝对定位**：`position: absolute; left: 50%; transform: translateX(-50%)` 或配合 `margin-left` 负自身一半宽度。

**垂直居中**
- **单行文本**：`line-height` 等于容器高度。
- **Flexbox**：父元素 `display: flex; align-items: center`。
- **Grid**：父元素 `display: grid; align-items: center`（或用简写 `place-items: center`）。
- **绝对定位 + transform**：`top: 50%; transform: translateY(-50%)`。
- **表格单元格**：父元素 `display: table-cell; vertical-align: middle`。

**水平垂直同时居中**
- **Flexbox**：父元素 `display: flex; justify-content: center; align-items: center`。
- **Grid**：`display: grid; place-items: center`。
- **绝对定位 + transform**：`position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%)`。
