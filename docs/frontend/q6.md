# Q6：BFC（块级格式化上下文）是什么？触发条件和应用场景？

BFC 是一个独立的渲染区域，规定了其内部的布局规则，并且**内部元素的布局不会影响外部的元素**。

**触发 BFC 的条件**（任选其一即可）：
- `float` 不为 `none`
- `position` 为 `absolute` 或 `fixed`
- `overflow` 不为 `visible`（如 `hidden`, `auto`, `scroll`）
- `display` 为 `inline-block`、`flex`、`grid`、`table-cell`、`flow-root` 等

**BFC 的布局规则**：
1. 内部的 Box 在垂直方向，一个接一个放置。
2. BFC 的区域不会与 float 元素重叠。
3. 属于同一个 BFC 的相邻 Box 的垂直 margin 会发生重叠（外边距折叠）。
4. 计算 BFC 的高度时，浮动元素也会参与计算（清除浮动）。

**常见应用场景**：
- **解决外边距折叠**：将两个相邻元素置于不同 BFC，可避免 margin 重叠。
- **清除浮动（高度塌陷）**：给父元素触发 BFC（如 `overflow: hidden`），能使其包裹住浮动的子元素。
- **两栏自适应布局**：固定一侧浮动，另一侧触发 BFC（如 `overflow: auto`），它就自动不重叠，占满剩余空间。
