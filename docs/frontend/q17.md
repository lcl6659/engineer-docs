# Q17：ES6+ 重要新特性详解

- **`let` 与 `const`**  
  - 块级作用域，无变量提升，存在暂时性死区（TDZ），不能重复声明。  
  - `const` 必须初始化，且基本类型值不可变，引用类型可修改内部属性。

- **箭头函数**  
  - 没有自己的 `this`、`arguments`、`super`，不能用作构造函数。  
  - 语法更简洁，适合非方法函数和回调。

- **解构赋值**  
  - 数组和对象可以模式匹配式地提取值，如 `const { name, age } = obj`。

- **模板字符串**  
  - 反引号 `` 支持多行和变量嵌入 `${expression}`。

- **展开运算符** `...`  
  - 可展开可迭代对象，用于数组拼接、函数参数、对象浅拷贝合并。

- **Class 语法**  
  - 本质是原型继承的语法糖，但有了 `constructor`、`extends`、`super` 等，让继承更清晰。

- **模块化 (ESM)**  
  - `import`/`export`，支持静态分析、tree-shaking，输出的是值的**引用**（CommonJS 输出值的拷贝）。ESM 是编译时加载。

- **新增数据结构**  
  - `Map`：键值对集合，键可以是任意类型，有序。  
  - `Set`：成员唯一，可去重。  
  - `WeakMap`/`WeakSet`：键只能为对象，弱引用，不会被 GC 阻止，不可遍历。
- **Proxy 与 Reflect**  
  - 代理对象，可拦截操作，实现响应式等元编程。
- **Promise、async/await、BigInt** 等。
