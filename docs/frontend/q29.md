# Q29：数组去重与扁平化

**去重**
```javascript
// Set
[...new Set(arr)];
// filter
arr.filter((item, index) => arr.indexOf(item) === index);
```

**扁平化**
```javascript
function flatten(arr, depth = 1) {
  if (depth < 1) return arr.slice();
  return arr.reduce((acc, val) => {
    if (Array.isArray(val)) {
      acc.push(...flatten(val, depth - 1));
    } else {
      acc.push(val);
    }
    return acc;
  }, []);
}
// 完全扁平化：arr.flat(Infinity)
```
