# Q20：什么是跨域？如何解决？

**同源策略**：浏览器最重要的安全机制，要求协议、域名、端口号完全相同。三者任一不同即为跨域。跨域时，请求可以发出，但浏览器会拦截响应，除非使用了跨域方案。

**常用解决方案**：
1.  **CORS（跨域资源共享）**  
    主流方案，由服务端设置响应头：
    - `Access-Control-Allow-Origin: *` 或特定域。
    - 复杂请求时，会先发出一个 `OPTIONS` 预检请求，确认允许再发正式请求。可配 `Access-Control-Allow-Methods` 等。

2.  **JSONP（JSON with Padding）**  
    利用 `<script>` 标签没有跨域限制的特点。通过动态创建 `<script>`，在 URL 后加 `?callback=handle`，服务端返回 `handle(data)` 的脚本，页面则调用 `handle` 函数拿到数据。**只支持 GET 请求，有安全隐患，需前后端配合。**

3.  **代理服务器**  
    开发环境常用 devServer 的 `proxy` 配置，将 API 请求转发到目标服务器，绕过浏览器同源限制。生产环境也用 Nginx 反向代理。

4.  **其他**：`WebSocket`（不受同源限制）、`postMessage`（不同窗口间通信）、`document.domain + iframe`（仅限主域相同）。
