# Q23：前端性能优化的整体方案

**网络/加载优化**
- 代码压缩：JS/CSS/HTML 压缩，开启 Gzip/Brotli。
- 图片优化：使用 WebP/AVIF，响应式图片 `srcset`，懒加载（`loading="lazy"` 或 IntersectionObserver），雪碧图。
- 缓存策略：设置强缓存+协商缓存，文件名 Hash 变化更新。
- CDN 加速资源分发。
- 按需加载：路由懒加载、组件动态 import。
- 预加载/预连接：`<link rel="preload">` 提前载入关键资源，`preconnect` 缩短握手时间，`prefetch` 预先获取将来资源。
- 服务端渲染（SSR）或预渲染，首屏加速。

**渲染/交互优化**
- 避免强制同步布局（布局抖动），如循环中读 `offsetHeight` 后又改样式。
- 使用 `will-change` 或 `transform: translate3d(0,0,0)` 创建独立合成层，避免重排重绘。
- 动画使用 `requestAnimationFrame`，而不是定时器。
- 长列表启用虚拟滚动。
- 事件处理使用防抖（输入搜索）和节流（滚动事件）。

**框架层面**
- Vue/React：合理拆分组件，`React.memo`/`PureComponent`、`shouldComponentUpdate` 避免不必要渲染，Vue中用 `computed` 和 `v-once`。
- 列表正确使用 `key`，防止就地复用导致状态错误。
