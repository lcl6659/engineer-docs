# Q4：DOCTYPE 的作用是什么？

`<!DOCTYPE html>` 不是 HTML 标签，而是一句给浏览器的指令。作用是**告诉浏览器以标准模式（Standards Mode）渲染页面，而不是怪异模式（Quirks Mode）**。

- **标准模式**：浏览器按照 W3C 标准规范进行渲染，盒模型为 W3C 盒模型（`box-sizing: content-box`）。
- **怪异模式**：为了兼容旧版网页，浏览器会模拟老版本浏览器的行为（如 IE6 的盒模型 `border-box`），这会导致不同浏览器下页面表现不一致。
- 如果遗漏 DOCTYPE 或写法不正确，就可能触发怪异模式，产生不可预期的布局问题。HTML5 只需要 `<!DOCTYPE html>`。
