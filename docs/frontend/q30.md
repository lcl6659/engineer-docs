# Q30：手写 `bind`、`call`、`apply`

在 JavaScript 中，`call`、`apply` 和 `bind` 都用于改变函数内部的 `this` 指向，但它们的执行方式和参数传递有所不同。

### 1. `call`
- **立即执行**函数。
- 参数：第一个参数是 `this` 要指向的对象，后面依次传入原函数需要的参数（逗号分隔）。

```js
function greet(greeting, punctuation) {
  console.log(greeting + ', ' + this.name + punctuation);
}
const person = { name: 'Alice' };
greet.call(person, 'Hello', '!'); // Hello, Alice!
```

### 2. `apply`
- **立即执行**函数。
- 参数：第一个参数是 `this` 要指向的对象，第二个参数是一个**数组**（或类数组对象），数组元素作为参数传给原函数。

```js
greet.apply(person, ['Hi', '?']); // Hi, Alice?
```

### 3. `bind`
- **不立即执行**，而是返回一个**绑定了 this 的新函数**（可后续调用）。
- 参数：第一个参数是 `this` 要指向的对象，后续参数可以预先指定（柯里化）。

```js
const boundGreet = greet.bind(person, 'Hey');
boundGreet('...'); // Hey, Alice...
// 也可以调用时再传剩余参数
const boundGreet2 = greet.bind(person);
boundGreet2('Yo', '!'); // Yo, Alice!
```

### 核心区别总结

| 特性               | `call`        | `apply`       | `bind`                     |
|-------------------|---------------|---------------|----------------------------|
| **执行时机**       | 立即执行       | 立即执行       | 返回新函数，不立即执行       |
| **参数传递**       | 逗号分隔列表   | 数组（或类数组）| 可以预先传参，也可调用时传    |
| **返回值**         | 函数执行结果   | 函数执行结果   | 绑定了 `this` 的新函数       |

### 使用场景
- **`call` / `apply`**：需要立即调用且改变 `this`，如借用数组方法（`[].slice.call(arguments)`）。
- **`apply`** 适合参数已是数组的情况（如 `Math.max.apply(null, [1,2,3])`）。
- **`bind`**：需要固定 `this` 但延迟执行（如事件处理函数、`setTimeout` 回调）。

**call**
```javascript
Function.prototype.myCall = function(context, ...args) {
  context = context || window;
  const fnSymbol = Symbol('fn');
  context[fnSymbol] = this;
  const result = context[fnSymbol](...args);
  delete context[fnSymbol];
  return result;
};
```

**apply**
```javascript
Function.prototype.myApply = function(context, argsArr) {
  context = context || window;
  const fnSymbol = Symbol('fn');
  context[fnSymbol] = this;
  let result;
  if (argsArr) {
    result = context[fnSymbol](...argsArr);
  } else {
    result = context[fnSymbol]();
  }
  delete context[fnSymbol];
  return result;
};
```

**bind**
```javascript
Function.prototype.myBind = function(context, ...args1) {
  const fn = this;
  return function F(...args2) {
    // 如果是new调用，this指向实例
    return fn.apply(this instanceof F ? this : context, args1.concat(args2));
  };
};
```
