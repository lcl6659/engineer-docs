# Q27：`http` 模块中如何处理上传文件？

原生 `http` 模块解析文件上传相对复杂，因需要解析 `multipart/form-data` 格式的请求体。面试中重点阐述原理。

**原理**：
- 客户端通过 `<form enctype="multipart/form-data">` 或 `FormData` 发送带有文件的 POST 请求。
- 请求头 `Content-Type` 类似 `multipart/form-data; boundary=----WebKitFormBoundary...`。
- 请求体被 `boundary` 分隔成多个部分，每个部分包含头部（Content-Disposition 等）和内容。

**处理方式**：
- 通常借助第三方库如 `busboy`、`formidable`、`multer`（Express 中间件）解析。
- 核心库会监听 `req` 流，根据 `boundary` 逐段解析出字段和文件，将文件内容写入临时文件或提供可读流。

**简单示例（formidable）**：
```javascript
const formidable = require('formidable');
const server = http.createServer((req, res) => {
  if (req.url === '/upload' && req.method === 'POST') {
    const form = new formidable.IncomingForm();
    form.parse(req, (err, fields, files) => {
      // fields 为普通字段，files 包含文件信息（临时路径、大小等）
      res.end('上传成功');
    });
  }
});
```
