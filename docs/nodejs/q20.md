# Q20：Node.js 和浏览器端 JavaScript 的主要差异

| 区别 | 浏览器 | Node.js |
|------|--------|---------|
| 全局对象 | `window` | `global` |
| 模块系统 | 原生 ESM（现代浏览器） | CommonJS + ESM |
| 文件系统 | 无（受限沙盒） | `fs` 模块，可读写文件 |
| 网络 | `XMLHttpRequest` / `fetch` + 跨域限制 | `http`/`https` 模块，可创建 TCP 服务器 |
| DOM/BOM API | 完整可用 | 无 |
| 进程/线程 | Web Workers（有限） | `child_process`、`cluster`、`worker_threads` |
| 部署 | 静态文件托管 | 服务端进程持续运行 |
