# Q5：Node.js 的模块加载机制是怎样的？

**CommonJS 加载流程**：
1. 解析路径，如果是核心模块直接返回，否则转为绝对路径。
2. 检查缓存 `Module._cache`，有则直接返回。
3. 创建模块实例并缓存。
4. 执行模块代码（包裹在函数 `(function(exports, require, module, __filename, __dirname) { ... })` 中），填充 `exports`。
5. 返回 `module.exports`。

**查找顺序**（如 `require('moduleA')`）：
- 先尝试核心模块。
- 再按 `node_modules` 层级逐级向上查找。

**文件扩展名解析顺序**：`.js` → `.json` → `.node`（若无扩展名依次尝试）。
