# Q9：如何解决 Node.js 中的回调地狱（Callback Hell）？

回调地狱是层层嵌套的回调函数，导致代码难以阅读和维护。解决方案：

1.  **Promise**：将回调异步操作封装为 Promise，通过 `.then().catch()` 链式调用。
2.  **async/await**：基于 Promise 的语法糖，用同步的风格写异步代码，通过 `try/catch` 捕获错误。
3.  **模块化拆分**：将深层嵌套拆分为命名函数。
4.  **使用工具**：如 `async.js` 库提供 `waterfall`、`parallel` 等控制流。

现代 Node.js 已全面支持 async/await，成为主流解决方案。
