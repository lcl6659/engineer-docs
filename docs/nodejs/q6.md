# Q6：Express 和 Koa 的区别

Express 和 Koa 都是 Node.js Web 框架，Koa 由 Express 原班人马打造，更轻量，充分利用 async/await。

| 特性 | Express | Koa |
|------|---------|-----|
| 中间件模型 | 线性回调，基于 `(req, res, next)` | 洋葱圈模型，基于 `async (ctx, next)` |
| 错误处理 | 需要单独错误处理中间件 | 使用 `try/catch` 或全局错误监听更自然 |
| 内置功能 | 自带路由、静态文件等 | 极度精简，需插件实现大部分功能 |
| 响应方式 | 通过 `res.send()` / `res.json()` | 通过 `ctx.body` 赋值 |
| 异步支持 | 回调式，需 `try/catch` 或 Promise | 原生 async/await |
