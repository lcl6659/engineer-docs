# Q4：CommonJS 与 ESM 在 Node.js 中的区别

Node.js 默认使用 **CommonJS**，但也支持 ESM（需 `.mjs` 后缀或在 `package.json` 中设置 `"type": "module"`）。

| 差异点 | CommonJS | ESM |
|-------|----------|-----|
| 加载方式 | 同步 `require()` | 异步 `import()`，静态 `import` |
| 输出 | 值的拷贝（基本类型） | 值的引用 |
| 动态导入 | `require` 可在任意位置 | `import()` 返回 Promise，静态 `import` 只能在顶层 |
| `this` 顶层指向 | `this` 指向当前模块的 `exports` | `this` 为 `undefined` |
| 文件扩展名 | `.js` / `.cjs` | `.mjs` / `.js`（开启 type:module） |
| 严格模式 | 非严格模式（可写 `'use strict'`） | 自动启用严格模式 |
