# Q30：`http.Server` 的 `upgrade` 事件是什么？如何升级为 WebSocket？

HTTP/1.1 支持协议升级，常见的是升级到 WebSocket 协议。`http.Server` 提供 `upgrade` 事件处理这类请求。

**触发条件**：
- 客户端发送带有 `Connection: Upgrade` 和 `Upgrade: websocket` 头的请求。
- 服务器端同意升级，返回 `101 Switching Protocols`。

**简易流程**：
```javascript
const server = http.createServer(/* request handler */);

server.on('upgrade', (req, socket, head) => {
  // 可以在这里处理 WebSocket 握手
  if (req.headers['upgrade'] !== 'websocket') {
    socket.destroy();
    return;
  }

  // 计算 accept key
  const crypto = require('crypto');
  const key = req.headers['sec-websocket-key'];
  const acceptKey = crypto.createHash('sha1')
    .update(key + '258EAFA5-E914-47DA-95CA-C5AB0DC85B11', 'binary')
    .digest('base64');

  const responseHeaders = [
    'HTTP/1.1 101 Switching Protocols',
    'Upgrade: websocket',
    'Connection: Upgrade',
    `Sec-WebSocket-Accept: ${acceptKey}`,
    '', ''
  ].join('\r\n');
  socket.write(responseHeaders);

  // 之后此 socket 即作为 WebSocket 连接使用，需要实现 WebSocket 帧协议
  socket.on('data', (data) => { /* 解析 WebSocket 帧... */ });
});
```

实际开发中会直接使用 `ws` 或 `socket.io` 这类库，它们封装了升级和帧处理。
