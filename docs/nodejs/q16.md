# Q16：Node.js 如何调用系统命令？`exec` 和 `spawn` 的区别

- **`exec`**：执行命令，缓冲区返回完整输出，适合执行较短命令，返回结果较小。
- **`spawn`**：以流的方式输出，适合处理持续输出大量数据的命令（如 `ls`、`find`），通过 `stdout`/`stderr` 流获取数据。
- **`execFile`**：直接执行文件，无 shell，比 `exec` 更安全。
- **`fork`**：衍生新的 Node.js 进程，并建立 IPC 通道，用于运行 JavaScript 模块，可通信。

示例：
```javascript
const { exec, spawn } = require('child_process');
exec('ls -la', (err, stdout, stderr) => {
  console.log(stdout);
});
const ls = spawn('ls', ['-la']);
ls.stdout.on('data', data => console.log(data.toString()));
```
