# Q11：请描述 Node.js 中进程（Process）与集群（Cluster）

Node.js 默认单进程，这意味着一个进程崩溃可能导致整个服务不可用，且无法充分利用多核 CPU。

- **`child_process` 模块**：允许创建子进程，运行系统命令或执行其他脚本。方法：`exec`、`spawn`、`fork`（专门用于衍生 Node 进程，建立 IPC 通信）。
- **`cluster` 模块**：用于搭建多进程集群，实现负载均衡。主进程（Master）通过 `cluster.fork()` 创建多个工作进程（Worker），共享同一端口。主进程负责分发连接（round-robin，轮询），工作进程处理请求。当一个工作进程挂掉时，主进程可自动重启。

**应用**：可用于充分利用 CPU、实现服务的高可用（如 pm2 的实现就是基于 cluster）。
