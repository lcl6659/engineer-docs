# Q3：`process.nextTick` 与 `setImmediate` 的区别

- **`process.nextTick`**：不属于事件循环的任何阶段，它在当前操作完成后、事件循环继续之前**立即执行**，属于微任务。会插入到当前阶段结束时执行，即使嵌套调用，也会在本轮循环中清空（可能饿死 I/O）。
- **`setImmediate`**：在事件循环的 **check 阶段**执行，属于宏任务。它保证在下一次事件循环迭代中执行。

**执行顺序示例**：
```javascript
setTimeout(() => console.log(1), 0);
setImmediate(() => console.log(2));
process.nextTick(() => console.log(3));
Promise.resolve().then(() => console.log(4));
// 输出顺序：3 4 1 2（可能 1 2 互换，取决于启动时性能）
```
