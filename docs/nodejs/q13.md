# Q13：Express 中间件原理和分类

Express 中间件是访问 `req`、`res` 和 `next` 的函数，能修改请求/响应对象，结束请求或调用下一个中间件。

**工作原理**：
- Express 内部维护一个中间件数组，请求到来时依次执行匹配的中间件，通过 `next()` 传递控制权。
- 中间件分为：
  - 应用级中间件：`app.use()`
  - 路由级中间件：`router.use()`
  - 错误处理中间件：必须有四个参数 `(err, req, res, next)`
  - 内置中间件：`express.static` 等
  - 第三方中间件：`cors`、`body-parser` 等
- 如果没有中间件调用 `res.send()` 或 `res.json()` 终结请求，请求会一直挂起。
