# Q18：Node.js 性能调优有哪些方法？

- **使用 cluster/pm2 利用多核**。
- **避免同步 API**（如 `fs.readFileSync`）在主请求处理中阻塞事件循环。
- **流式处理数据**，而非缓冲区全量处理。
- **缓存**：缓存数据库查询结果、模板渲染等。
- **合适的数据库查询**：使用索引、优化查询。
- **缩小中间件栈**：移除或缩短中间件链。
- **开启 gzip 压缩**。
- **设置 Node.js 内存限制**（`--max-old-space-size`）。
- **监控**：用 `clinic`、`0x` 生成火焰图分析 CPU 和内存瓶颈。
