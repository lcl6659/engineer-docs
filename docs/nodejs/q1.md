# Q1：Node.js 是什么？有哪些特点？

Node.js 是一个基于 Chrome V8 引擎的 **JavaScript 运行时**，它让 JavaScript 可以脱离浏览器运行在服务器端。

**核心特点**：

- **单线程 + 事件循环**：采用单线程模型处理请求，通过事件循环和异步非阻塞 I/O 实现高并发。
- **非阻塞 I/O**：I/O 操作（文件读写、网络请求）不会阻塞主线程，而是通过回调或 Promise 通知结果。
- **事件驱动**：当异步操作完成时，通过事件机制触发回调。
- **跨平台**：支持 Windows、macOS、Linux。
- **npm 生态**：拥有全球最大的开源库生态系统。
- **适合场景**：高并发、I/O 密集型应用（如 Web 服务器、实时通信、API 网关）；不适合 CPU 密集型计算（会阻塞主线程，但可通过 Worker Threads 改善）。
