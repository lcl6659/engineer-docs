# Q24：Node.js 的 `http` 模块架构和核心类

`http` 模块封装了 `net` 模块的 TCP 连接，遵循 HTTP 协议规范，提供创建 HTTP 服务器和客户端的能力。

**核心类**：
- **`http.Server`**：继承自 `net.Server`。通过 `http.createServer(requestListener)` 创建，监听 `request` 事件和 `connection` 事件。
- **`http.ClientRequest`**：由 `http.request()` 返回，是一个可写流，表示客户端发起的一个请求。
- **`http.ServerResponse`**：服务器端，是一个可写流，由 `http.Server` 在收到请求时创建，用于对客户端做出响应。
- **`http.IncomingMessage`**：服务器端 (`req`) 和客户端 (`res`) 都是此实例。它是一个可读流，提供请求/响应的状态行、头部和主体。

**请求处理流程**：
1. 服务器收到连接，解析 HTTP 请求报文，生成 `IncomingMessage` (req) 和 `ServerResponse` (res) 对象。
2. 发射 `request` 事件，传入 `req` 和 `res`。
3. 用户逻辑通过 `res.writeHead()` 设置状态码和头，`res.write()` 和 `res.end()` 写入响应体。
4. 底层会将响应序列化为 HTTP 响应报文并通过 TCP 连接发送回客户端。
