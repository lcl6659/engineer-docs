# Q8：简述 Node.js 的 Stream（流）及其类型

Stream 是处理流式数据（如文件读取、HTTP 请求响应）的抽象接口，它把数据分成小块逐块处理，而非一次加载到内存，适合大文件/大请求。

**四种基本类型**：
- **Readable**：可读流，如 `fs.createReadStream()`。
- **Writable**：可写流，如 `fs.createWriteStream()`。
- **Duplex**：双向流（可读可写），如 TCP socket。
- **Transform**：转换流（读入，转换后写出），如 `zlib.createGzip()`。

**常用事件与方法**：
- `data` / `end` / `error`（Readable）
- `write()` / `end()`（Writable）
- `pipe()`：将可读流管道连接到可写流，自动处理背压。

**背压（Backpressure）**：当写入速度跟不上读取速度时，可读流会暂停，等待可写流排空。`pipe()` 自动处理，手动用 `readable.pipe(writable)` 即可。
