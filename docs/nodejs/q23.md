# Q23：TCP 粘包和半包问题在 Node.js 的 `net` 模块中如何处理？

TCP 是**流式协议**，数据没有边界。多次 `write()` 可能会被合并成一个数据包发送（粘包），或者一个大数据包可能被拆分成多个小包到达（半包）。单纯的数据监听 `socket.on('data')` 收到的可能是任意长度的数据。

**解决方案**：应用层协议必须定义消息边界，常见方式：

1.  **固定长度**：每条消息固定字节数，不足补零或空格。
2.  **分隔符**：每条消息以特定字符结束（如换行 `\n`、空字符 `\0`），接收端按分隔符切分。代码可借助 `readline` 模块或在 `data` 事件中拼接 Buffer 并按分隔符分割。
3.  **长度前缀**：在消息头部固定字节（如 4 字节）表示消息体的长度。接收端先读取头部获取长度，再根据长度读取完整消息体。这是最通用和健壮的方式。

**示例（长度前缀方式）**：
```javascript
// 发送端：写入长度前缀 + 数据
function sendPacket(socket, message) {
  const body = Buffer.from(message, 'utf8');
  const header = Buffer.alloc(4);
  header.writeUInt32BE(body.length, 0);
  socket.write(Buffer.concat([header, body]));
}

// 接收端：解析长度前缀
let buffer = Buffer.alloc(0);
socket.on('data', (chunk) => {
  buffer = Buffer.concat([buffer, chunk]);
  while (buffer.length >= 4) {
    const length = buffer.readUInt32BE(0);
    if (buffer.length >= 4 + length) {
      const body = buffer.slice(4, 4 + length).toString('utf8');
      console.log('完整消息:', body);
      buffer = buffer.slice(4 + length);
    } else {
      break; // 等待更多数据
    }
  }
});
```
