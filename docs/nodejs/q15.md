# Q15：`require` 和 `import` 有什么区别？Node.js 中如何混用？

已在 Q4 部分提及，补充关键点：

- **本质**：`require` 是运行时同步加载；`import` 是编译时加载（静态分析）。
- **动态导入**：CommonJS 中 `require` 本身就是动态的；ESM 中动态导入使用 `import()`，返回 Promise。
- **混用**：Node.js 中，CommonJS 可以通过 `import()` 动态引入 ESM，但不能静态 `import` ESM 文件；ESM 文件可以通过 `import` 引入 CommonJS 模块（由 Node 自动处理为默认导出）。若 ESM 文件中需要 `require`，可用 `module.createRequire` 创建。
