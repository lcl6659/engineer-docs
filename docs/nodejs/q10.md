# Q10：Node.js 中 Buffer 是什么？什么时候用？

Buffer 是 Node.js 用来处理**二进制数据**的类，类似于整数数组，但内存分配在堆外，大小固定。当需要与 TCP 流、文件系统操作等交互时，数据通常是二进制形式，Buffer 提供操作这些二进制数据的能力。

**常用**：
- 读取文件：`fs.readFile` 不指定编码时返回 Buffer。
- 网络传输：HTTP 请求的 body 解析。
- 字符串与 Buffer 转换：`Buffer.from(str)` / `buf.toString()`。
- 拼接数据：`Buffer.concat([buf1, buf2])`。
