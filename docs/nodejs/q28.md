# Q28：HTTP 模块如何实现 Keep-Alive 和连接池？

**HTTP Keep-Alive**：
- HTTP/1.1 默认启用持久连接（`Connection: keep-alive`），即一个 TCP 连接可以处理多个请求/响应，减少 TCP 握手和挥手的开销。
- Node.js 的服务器端自动处理持久连接，除非明确设置 `res.setHeader('Connection', 'close')` 或在配置中关闭。
- 服务器通过 `server.keepAliveTimeout` (默认 5 秒) 控制空闲连接保持时间，超时自动关闭。

**客户端的连接池**：
- `http.Agent` 类管理客户端的连接持久性和池化。
- 默认情况下，`http.globalAgent` 为每个主机+端口维持连接池，限制并发连接数（`maxSockets` 无限，但实际受系统限制）。
- 可创建自定义 Agent 控制连接池大小，如 `new http.Agent({ keepAlive: true, maxSockets: 10 })`，并传入请求的 `agent` 选项。
- `keepAlive: true` 让连接完成后不被销毁，可供后续请求复用。

**示例**：
```javascript
const agent = new http.Agent({ keepAlive: true, maxSockets: 5 });
http.request({
  hostname: 'example.com',
  agent: agent
}, res => { /* ... */ });
```
