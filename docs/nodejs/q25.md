# Q25：如何使用 `http` 模块创建一个简单的 HTTP 服务器，并解析请求？

```javascript
const http = require('http');

const server = http.createServer((req, res) => {
  const { method, url, headers } = req;
  console.log(`收到 ${method} ${url}`);

  // 解析请求体 (流式读取)
  let body = [];
  req.on('data', (chunk) => {
    body.push(chunk);
  }).on('end', () => {
    body = Buffer.concat(body).toString();

    // 路由处理
    if (req.url === '/' && req.method === 'GET') {
      res.writeHead(200, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({ message: 'Hello World' }));
    } else if (req.url === '/data' && req.method === 'POST') {
      res.writeHead(200, { 'Content-Type': 'application/json' });
      res.end(JSON.stringify({ received: body }));
    } else {
      res.writeHead(404);
      res.end('Not Found');
    }
  });
});

server.listen(3000, () => {
  console.log('HTTP 服务器监听 3000 端口');
});
```

**请求对象 (`req`, `IncomingMessage`)**：
- `req.method`：请求方法。
- `req.url`：请求路径和查询字符串。
- `req.headers`：请求头对象（键全小写）。
- `req.on('data')` / `req.on('end')`：读取请求体。

**响应对象 (`res`, `ServerResponse`)**：
- `res.writeHead(statusCode, [headers])`：设置状态码和响应头。
- `res.write(chunk)`：写入响应体（可多次写入）。
- `res.end([data])`：结束响应，可选最后一次写入数据。
