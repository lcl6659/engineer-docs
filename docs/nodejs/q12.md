# Q12：Node.js 的错误处理机制

良好的错误处理是 Node.js 应用稳定运行的关键。

- **同步错误**：用 `try/catch` 捕获。
- **异步回调错误**：错误优先回调（error-first callbacks），第一个参数为 error，如 `fs.readFile(path, (err, data) => { if (err) throw err; })`。
- **Promise 错误**：`.catch()` 或 `try/catch` 包裹 `await`。
- **EventEmitter 错误**：监听 `error` 事件，`emitter.on('error', handler)`，否则会抛出全局错误使进程退出。
- **全局异常捕获**（终极手段，不应依赖）：
  - `process.on('uncaughtException')`：捕获未捕获的同步异常。
  - `process.on('unhandledRejection')`：捕获未处理的 Promise 拒绝。
  - 用于记录日志、优雅退出。

**原则**：尽量局部捕获处理，避免应用崩溃。使用域名（Domains，已废弃）或 `async_hooks` 追踪上下文。
