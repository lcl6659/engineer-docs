# Q21：Node.js 的 `net` 模块是什么？它提供了哪些能力？

`net` 模块是 Node.js 内置的用于创建基于流的 **TCP 服务器**和 **TCP 客户端** 的底层网络模块。所有高层协议如 HTTP、HTTPS、SMTP 等最终都基于 `net` 模块的 TCP 能力构建。

**主要能力**：
- **`net.createServer([options], connectionListener)`**：创建 TCP 服务器，监听连接事件。
- **`net.createConnection` / `net.connect`**：创建一个 TCP 客户端，连接远程服务器。
- 提供 `Server` 和 `Socket` 类：
  - `net.Server`：监听端口，发射 `listening`、`connection`、`close`、`error` 事件。
  - `net.Socket`：表示一个 TCP 或 Unix socket 连接，是一个全双工的 Duplex 流，可读可写。常用事件 `data`、`end`、`close`、`error`，方法 `write()`、`end()` 等。

**典型使用场景**：
- 实现自定义的 TCP 协议（如游戏服务器、IoT 设备通讯）。
- 构建代理服务器。
- 学习和理解 HTTP 模块的底层原理。
