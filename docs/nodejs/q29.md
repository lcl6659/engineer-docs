# Q29：在 Node.js 中如何实现一个 HTTP 代理服务器？

代理服务器接收客户端请求，转发给目标服务器，并将响应返回客户端。利用 `http` 模块可以轻松实现。

**基本步骤**：
1. 创建 HTTP 服务器。
2. 在 `request` 事件中，解析客户端请求，创建向目标服务器的代理请求（`http.request`）。
3. 将客户端的请求头（可修改）和请求体通过管道传递到代理请求。
4. 将目标服务器的响应状态码、响应头和响应体通过管道传递回客户端。

**简单示例**：
```javascript
const http = require('http');

const server = http.createServer((clientReq, clientRes) => {
  const options = {
    hostname: 'target.server.com',
    port: 80,
    path: clientReq.url,
    method: clientReq.method,
    headers: clientReq.headers
  };

  const proxyReq = http.request(options, (proxyRes) => {
    clientRes.writeHead(proxyRes.statusCode, proxyRes.headers);
    proxyRes.pipe(clientRes);
  });

  // 将客户端请求体流传给代理
  clientReq.pipe(proxyReq);

  proxyReq.on('error', (err) => {
    clientRes.writeHead(500);
    clientRes.end('代理出错');
  });
});

server.listen(8080);
```
对于 HTTPS 代理，需要使用 `https` 模块并结合 CONNECT 方法处理隧道。
